# 阶段 3 的第一块：每局洗牌与段间衔接的核心

2026-11-20。照[五十段风景公路](../research/scenic-50.md)第五节写成代码：`src/core/world/journey/`。

- 这是规则本身，还没有接进世界生成。
- 名单等审批 A，名单若有改动，只改数据表 `scenes.ts`，洗牌和衔接不用动。

## 做了什么

**数据表**（`scenes.ts`）：50 段，每段记下洗牌和衔接要用的东西：

- 气候带、长得像的"家族"（如红色荒漠、湿林、挪威山海、发夹弯）；
- 最美时节的白天平均温度、干湿、海拔、月份；
- 能用哪些门槛进出（隧道、垭口、雾墙、沙尘暴、暴风雪、雨幕、长桥），能不能和近邻渐变；
- 适不适合当开局；有没有夜景（极光、银河）或晨景（热气球、梯田朝霞、地热喷汽）；
- 从哪个现有地区长出来。

另记 6 个缓冲段（草原、森林、雪山、湖区、湿地、花田）的气候。

**洗牌**（`journey.ts` 的 `roundOrder`）：每一轮把 50 段一段段抽出来，每次从还没来过的段里随机挑，同时守三条规则：

1. **不撞脸**：同一家族的两段至少隔 3 段，紧挨着永远不行；
2. **不连续大跳**：连着两次门槛之后，下一段必须能用渐变或缓冲段接过去；
3. **软开局**：一局的第一段从温和的段落里挑。

另有两条：

- 抽不出来时先放宽第 2 条，再把第 1 条的间隔缩小，但不会缩到紧挨着。
- 剩得多的家族抽中的机会大一点，免得一轮快结束时只剩同一家族、只好挤在一起。

**夜景和晨景**：按"出发时刻＋匀速 70 km/h"推算的时钟，到某段时正是夜里，有夜景的段被抽中的机会翻倍；正是清晨，有晨景的段翻倍。这样世界仍然只由种子决定，不受你开得快慢影响。

**衔接**（`planJoin`）：按两段的温度、干湿、海拔、季节和气候带算出"相差多远"：

| 相差 | 衔接 | 长度 |
|---|---|---|
| 小 | 渐变：植物交错、地色过渡 | 1–1.5 km |
| 中 | 缓冲段：挑气候最接近两段中间的那个现有地区 | 1–3 km |
| 大 | 门槛：在两段都能用的门槛里挑；没有共同的，就用进入那段的方式（进沙漠是沙尘暴，进雨林是雨幕） | 0.8–1.2 km |

另外两条细则：

- 冷热差 22°C 以上时，门槛后面再接一段缓冲，留出降温（或升温）的过程，这时门槛共长约 2.5 km。
- 缓冲段不会比两头都湿（两片干地之间不放森林），也不会比两头都冷或都热。

存档只需要记种子和走到第几段。

## 实际洗出来什么样

200 个种子各洗 3 轮：

| 衔接 | 占比 |
|---|---|
| 渐变 | 8% |
| 缓冲段 | 60% |
| 门槛 | 31% |

- 门槛约每 3 段一次，大约每 20 分钟一次大换场。
- 同家族隔不到 3 段的只有 0.09%（紧挨着的 0.02%）；连着三次以上门槛的 0.6%。
- 都是在规则抽不出来时才放宽的。

## 验证

单元测试 `harness/sim/p3_journey.test.ts`，5 项通过：

- 数据表：50 段编号和名字各不重复，每段都有进出方式和季节；"并入"的正好是那 6 个现有地区。
- 每轮 50 段各一次；同一种子同一顺序，换种子顺序就不同，下一轮也是新的顺序。
- 200 个种子：开局都是温和段；同家族紧挨着的低于 0.1%，隔不到 3 段的低于 0.5%，连续门槛超过 2 次的低于 2%。
- 衔接：三种都会出现；门槛不超过 45%；缓冲段编号都存在；门槛种类来自两段都能用的，或进入那段的方式。
- 段落首尾相接，风景段长 5–7 km。
