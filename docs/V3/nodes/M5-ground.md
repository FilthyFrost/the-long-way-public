# M5 林下、田里和河滩上有什么

## 修订 11 的岩面、林下和砾滩

草甸上的花岗岩有偏粉的灰面、碎裂的肩线和半埋的脚石。各类岩石由三种轮廓变体和三档细节组成，石灰岩、玄武岩、砂岩和片理岩各有色调。大石留出亮顶、冷色侧面和裂缝；潮湿岩面带断续的苔色，雪落在向上的面上。河滩把圆砾摊开，颗粒间露出冲积细料。小石和蕨叶落在近处地形实际画出的三角面上，弯曲河岸的直线近似曾使它们埋入地面。

## 修订 9 的落点规则

同一种子开回原地，河滩上的扁石和林下的蕨仍在原处。河砾和碎石可以踩过去。高于约 68 厘米的块石占住地面，车和人共用它的碰撞体。砂岩鳍和层岩用窄长盒，圆块用圆柱近似边缘。

第二版世界按档案的海拔带选物种，再按地形落点。林冠下长蕨、落叶和松针，湿度与离水距离决定莎草，矮灌和垫状草本之间留出岩面。水稻只落在梯坎的平面上。每个八米方格至多抽取一个地被丛和一组石头，开阔侧保留低矮轮廓。岩石按本地岩性份额取样，坡面、岸边和塔峰脚有不同的出露概率。河床边是成组圆砾，坡面有碎石、冰碛、圆蚀花岗岩、柱状玄武岩、砂岩鳍、层岩和石灰岩脚。

草、花、扁叶、石片用程序生成三档几何，复用草木图集、实例批次、风、积雪和雾。花色与月份来自地区档案。旅程从六月一日开始，以存档经过的日数换月；南北半球各读自己的月份。落叶矮柳与越橘在秋季换色，冷月压低，干季草穗泛金。雪线以上先收起贴地小花。长在树冠和仙人掌冠上的花留给树冠模型。

现有 12 个区域与道路使用相同的景观类比。原版道路的海拔起点与研究地点不同，地被用参考路面的海拔加当地起伏换算。54 个原型的地被、灌木和花名都已检查，尚未成为可驾驶区域的原型只在目录和规则测试中覆盖。采集系统的可拾取植物仍沿用原来的点位。
