# 草地一圈画一次

2026-11-20。阶段 0 留下的绘制次数超标里，草是第二大头（每处 91–96 次）。

## 原来

草按 Painted Valley 的做法分四圈，跟着视点走：

| 圈 | 每块边长 | 块数 |
|---|---|---|
| 近 | 3 米 | 6×6 |
| 中 | 6.4 米 | 8×8 |
| 宽 | 16 米 | 8×8 |
| 远 | 41 米 | 8×8 |

- 每块是一个网格，草叶按"格子"实例化；
- 在视野内、又落在本圈距离带里的块各画一次。

## 现在

每圈只画一次（`render/meadowMaterial.ts`、`scene/meadow.ts`）：

- 每帧在 CPU 上挑出这一圈里"在视野内、又落在距离带里"的块，把它们的角点写进材质的一个数组（`uTiles`）；
- 这一圈一次画"块数 × 每块草叶数"个实例。着色器从实例编号算出这片草叶属于哪一块（编号除以每块草叶数），以及它在块里的第几个格子；
- 格子按一个打乱的顺序取（一个和格子总数互质的乘数）。草地密度调低、每块只画一部分格子时，取到的格子也均匀散在整块上。

每片草叶仍然按自己所在的世界格子长，样子和原来完全一样。

## 结果

| 地点 | 草的绘制次数 | 总绘制次数（含阴影） | 预算 400 |
|---|---|---|---|
| 森林 | 91 → 23 | 401 → 333 | 达标 |
| 草原 | 93 → 21 | 454 → 382 | 达标 |
| 雪山 | 96 → 27 | 358 → 289 | 达标 |
| 雪山远眺 | 95 → 25 | 377 → 307 | 达标 |
| 湖区 | 96 → 22 | 618 → 544 | 还超 |

- 草的三角形数不变（同样的草叶都画了）。驾驶位截图前后一样（`loop/shots/perf_gate/hull_*.png` 对比 `meadow1_*.png`）。
- 湖区还超：那里 4 辆车在屏幕上要 172 次，路边地点的物件 52 次。
- 实际开 6 公里：平均每帧 8.34 毫秒，P99 11.2 毫秒，和之前一样。

## 验证

- 类型检查、生产构建通过；全部单元测试 2,250 项通过。
- 性能检查五处：帧时和绘制次数都已在预算内，只剩湖区的绘制次数和各处的草花三角形还超。草花三角形是 M5 占位地被植物带来的，阶段 3 换掉。
