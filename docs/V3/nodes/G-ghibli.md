# G 纠偏：成片的树林、成组的石头、画出来的岩石、每个地方自己的云和光

2026-11-22。V1–V10 做完后用户看了青野的海蚀拱截图，反馈：

- 主角地貌（海蚀柱之类）建模粗糙、材质没有质感，远看像 low poly。要更多细节、更丰富的纹理、有层次。
- 同一个地区里有的树颜色深、有的浅；各种树几乎是随机乱放，不像现实里一片一片的；地上的植物和石头也是乱撒，像"很漂亮的地形上有很多不合时宜的补丁"。要按地区特色精心设计摆放。
- 整体表现力不如 Painted Valley，光影、色调离吉卜力越来越远。给了完全的自由，可以推翻重写。

做到一半用户又纠正了两点（以此为准）：

1. **云要优化，不是退回只有积云**：各种云型保留，不同生态地区放不同的云，也可以无云。
2. **光影不要机械地照 Painted Valley**：按生态地区、环境、天气各自设计更高级的光影。

## 调查：问题出在哪

用不带车舱和界面的自由机位（`D:/modcar-scratch/v1/probe/eye.mjs`）实拍了十来个地方，再对着代码查根因。

| 看到的 | 根因 |
|---|---|
| 同一片林子里有的树发亮、有的近乎黑紫 | 树冠有两套互不相同的上色梯度：没有自己颜色的树种（橡、椴、白蜡）用地区的四档色，而地区给的四档几乎是同一个颜色（明度只差 0.05–0.1，色相不变），整棵树是一块平的橄榄色；有自己颜色的树种（山毛榉、松、刺柏）走另一套梯度，把自己的颜色当成最亮一档，往下全是深蓝黑。两套并排就是一亮一黑 |
| 树、灌木、石头、花均匀地撒满 | 摆放是逐格掷骰子（`core/world/flora.ts decide`）：每个 8 米格子独立地按概率放一棵。每个树种各有各的噪声，五六个树种、三四种灌木互相穿插。疏林里每公顷 45 棵，林子内部只有三成格子有树，看上去是稀疏的随机点 |
| 草地上满是墓碑一样的竖石头 | 地面另有一套撒点（`groundField.ts`）：每个 8 米格子有最高 78% 的概率放一块石头；石灰岩地区的石头样式是 3.6 米高的"竖沟孤峰" |
| 海蚀柱、石柱像光滑的泥塑 | 车床式的环形网格，一圈 34–40 段，平滑法线，颜色画在顶点上——细节只有顶点那么密 |
| 天空像大理石花纹 | 卷云、卷积云、高积云、波状云各自掷骰子，常常三四层同时铺满整个天；每层都是不透明的平白图案 |
| 地面从高处看有砖纹 | 等高线笔触是等距的短划，成排地排在每个坡上；草甸的色点按格子排列 |

## 改了什么

### 树冠的颜色（G2）

- **一套梯度**：所有树冠都用同一个四档梯度，从它的"主色"推出来（`core/world/earth/palette.ts crownLadder`，着色器里是 `render/paint.ts rtLadder`，同一组数）。数值取自 Painted Valley 的树冠：暗部先失去红、保留蓝（叶丛的阴影是天光），亮部偏黄。暖色的主色（秋天的金、红）暗部走向红褐而不是蓝。暗部的蓝封顶，云杉不会发蓝。
- **树种之间只留很小的差别**：每种植物离地区主色的距离从 85% / 75% / 60%（明度 / 彩度 / 色相）降到 30% / 35% / 30%。
- **地区主色重调**：绿色系更清新、略偏蓝；干旱地区的叶子是银绿、草是麦金；去掉了绿和金中间那种卡其色（要么绿、要么金）。草地三档拉开到 Painted Valley 的幅度。

### 摆放：按构图来，不掷骰子（G3）

新文件 `core/world/layout.ts`，三个基本形：

- **林分**（`standAt`）：把土地切成 190 米左右、边缘弯曲的小片，每片有自己的编号。
- **团**（`clumpAt`）：每若干格里有一个圆形、边缘参差的团——草地里的小树丛、灌丛、露头、花带。
- **间距**（`spacedAt`）：互相保持距离的植物，一格里一棵。

规则（`core/world/flora.ts` 的规则多了 `stand`、`clump`、`spaced` 三个字段）：

- **树林**：一片林分一个优势树种（占近九成），外加一个伴生种；四分之一的林分是混交林。林子内部每公顷 100 棵上下，树冠相接；越靠林缘树越矮越疏；林子外面是空地。
- **林缘灌木带**：灌木沿林缘密密地围一圈，林下只有少量。灌木改在 4 米的格子上（新增一层 `LAYER_BRUSH`），才能彼此相接成丛。
- **按地区的格局**（`core/world/earth/flora.ts PATTERN`）：

  | 结构 | 格局 |
  |---|---|
  | 密林、疏林 | 成片的林分，林缘灌木带，林下幼树 |
  | 林地 | 一丛丛树林，草地上有小树丛和灌丛 |
  | 稀树草原 | 树彼此保持 40 米，刺灌丛成团 |
  | 草原、农田 | 开阔，偶尔一个小树丛，路边偶尔一棵大树 |
  | 灌丛 | 灌丛与空地相间的镶嵌 |
  | 荒漠 | 灌木均匀地相隔 12 米，中间是裸地，每隔几十米一棵高的 |
  | 苔原 | 矮灌木成片的垫子 |
  | 湿地 | 柳树丛，成床的芦苇 |

- **水边**：柳树、棕榈、红树成组地沿岸排，中间留出空岸；芦苇成床。
- **石头**（`groundField.ts`）：只出现在露头里——中间是基岩，周围是崩落的石块，越往外越小；坡上、山包上、地貌的侧面更容易有；陡坡下是碎石，河岸是卵石。其余地面是干净的。石灰岩的竖石只出现在喀斯特地貌的露头中央。
- **花**：成片的花带，一片一种颜色，带内像地毯，带与带之间几乎没有。草叶里的花（`scene/worldBuild.ts`）和地面的花丛用同一批花带。
- **低矮灌木、草丛**：成团出现，中间留空。
- 手写的旧地区（世界版本 1–4）一棵不动：新的构图只用于涌现地球的地方。

### 主角地貌的岩石（G5）

- **造型**（新文件 `scene/rockForms.ts`）：岩石按层理和节理碎成块。
  - 平面是多边形（角就是大节理），不是圆。
  - 一层层岩层：硬层突出、软层凹进，形成真的台阶和岩檐，自己投下阴影。
  - 每层被节理切成块，各自进出一点；十分之一的块崩落，留下暗的龛；一两道深槽纵贯半个柱身。
  - 岩层有几度倾角，层面起伏，节理逐层错开，不是砌砖。
  - 海蚀柱在水线处被浪掏进去，站在水下的岩裙上；脚下是崩落的石块。
  - 海蚀拱是同样的岩层和岩块砌成的一堵墙，中间一个门洞，两端一级级降到海里。
  - 石柱（砂岩）：岩层厚，岩块沿节理上下贯通成柱。
- **画法**（新文件 `render/rockMaterial.ts`）：逐像素，按世界坐标，远近都保持。
  - 岩层：两米多厚的薄层，三层左右并成厚层，每层自己的明暗和冷暖，层面一道断续的暗线。
  - 凿面：九米、三米、一米三种大小的面，各自朝向不同，之间是发丝一样的节理。
  - 风化：雨水的深色竖纹，偶尔的浅色水痕；槽里和岩檐下更深。
  - 海的痕迹：水线处湿黑，上面一圈深色的藻带，再上面是盐的白带。
  - 植被：顶上的草皮参差地垂过边缘，台阶上的苔藓，绿色岩石上成片挂着的植被。
  - 光：受光面是阳光色，背光面是岩石自己的阴影色乘天光，交界清晰；自己的台阶和岩块互相投影。

### 云（G1，按用户的纠正）

- **每种云重画**（`env/sky.ts`）：
  - 卷云：马尾云——一个钩状的头，拖着被高空风梳开的长丝；一群一群的，中间是蓝天。
  - 卷积云：一两片细密的波纹，成行，再碎成小粒，边缘变薄。
  - 高积云：一两条云带里的羊群云，向阳一侧白、其余蓝灰，边缘稀薄。
  - 波状云：参差的云卷。
  - 薄幕（卷层云）：带 22° 日晕。
  - 各层按"圆的地球"投影，远处的云贴着地平线变小变扁，不再是汇向一点的扇形线条。
- **一个天空一个主题**（`palette.ts skyOf`）：晴空、马尾云、羊群云、波纹、薄幕、波状云、晴天积云、热带塔状积云八种里按气候抽一种，最多再带一点卷云。干旱地区多晴空和卷云，湿热带多塔状积云，寒冷地区多薄幕和日晕，海岸多羊群云，山地多卷云和荚状云。

### 每个地方自己的光（G7，按用户的纠正）

`palette.ts PlaceLight`，由气候和地表算出，`env/colorScript.ts` 应用：

| 地方 | 光 |
|---|---|
| 炎热荒漠 | 太阳更硬、天光更少，阴影深而偏紫；地面的暖色反到阴影里；对比略高 |
| 湿热带 | 太阳被水汽柔化，天光更强，没有硬阴影；林下的阴影偏绿；色彩浓、对比柔；空气里容易出现光柱 |
| 雪地 | 雪把天光反进每一处阴影：阴影浅而蓝，色彩干净 |
| 高海拔 | 空气稀薄：太阳烈、天空暗，阴影深蓝 |
| 海岸 | 明亮的空气，阴影里带海的冷色 |
| 秋林 | 金色下面是偏紫的阴影，落叶的暖色反上来 |
| 树林、湿地 | 天光柔和，阴影偏绿，早晨有光柱 |

具体是：太阳和天光的强度、阴影的色调、地面反光的颜色（用这个地方地面自己的颜色）、收尾的对比度和饱和度、光柱出现的难易。两个地方交界处平滑过渡。

### 地面（G6）

- 等高线笔触间距不等、大部分留空、减淡一半，不再是砖纹。
- 草甸的色点不再按格子排，强度减半。
- 林下的地面更深，一片林子读成一个整体。

## 数字

- 新加 `harness/sim/g_composition.test.ts` 10 项：团、林分、间距的性质；林子里相邻的树多数同种、树都在林子里；灌木层在 4 米格子上；石头成组、大部分地面没有石头；花带内外相差八倍以上；树冠梯度对 Painted Valley 的主色给出它的四档；一个天空不叠两层云毯；荒漠、雪地、湿热带的光各有其特点。
- 原有 2386 项测试一项没改，全部通过（测高度函数开销的微基准在满负载时偶尔不过，单独跑通过）。
- 性能闸门 8 个测点 P95 6.9–9.9 ms（预算 11 ms），全部在预算内。第一遍测到沿河 11.3 ms、山地 10.9 ms，把密林的林下幼树、林缘灌木和岩石的环数减了一些后回到预算内。
- 世界修订号升到 24：树、灌木、石头都换了位置。

## 还没做

- 远山的轮廓是粗网格，远看是一段段直边（low poly）。要给远景地形加密或另画。
- 海蚀拱侧面的台阶偏规整；石峰（塔状喀斯特）用了新造型但还没单独审。
- 喀斯特的锥形山本身是光滑的圆锥：要加崖壁露头和山上的林子。
- 高积云的云粒边缘偏硬；卷云的钩不明显。
- 瀑布、冰川、远景主峰还是旧画法，没有用上新的岩石画法；路边崖壁（地形上的岩面）也没有。
- 光：只做了强度、色调、反光和收尾；雨林里穿过树冠的光柱、水面的波光还没有专门做。
