# 里程碑 2-B：地被换成工具箱长的

2026-11-20 夜。审批 B 按推荐通过以后的第二步：路边和林下的丛草、花、矮灌木、蕨，由工具箱来长。

## 原来

地被（`core/world/groundTables.ts` 的生态档案）是 M5 的占位模型：一笔一笔的叶片和多面体团块，荒漠里的灌木是一堆黑色的多面体。

## 现在

- **哪些换了**（`scene/crowns/crownData.ts` 的 `GROUND_KIT`）：

| 地被的形 | 工具箱的种类 |
|---|---|
| 草甸禾草、丛草、莎草 | 草甸草丛、金色丛草、针茅 |
| 林缘灌丛、杜鹃类、越橘、海岸灌丛 | 圆团灌木 |
| 矮柳矮桦、帚状石南 | 石楠（贴地的矮丛） |
| 鼠尾草、蒿、杂酚油灌木、刺灌丛 | 鼠尾草灌丛 |
| 罂粟类、雏菊类、星形小花、林下小花、穗状花、管状花 | 虞美人、雏菊、鲁冰花、郁金香 |
| 簇生花（帝王花、杜鹃花簇） | 帝王花 |
| 蕨 | 新做的林下蕨（`scene/flora/fern.ts`：一丛向外拱的蕨叶，尖端下垂） |

- **没换的**：苔藓、地衣、针叶毡、落叶、结皮、垫状草、水稻、石头，这些贴地的仍照原样。
- **怎么画**：由画树的那套来画（`crowns/crownView.ts`），每块地的地被作为"静止的一块"放进去一次：
  - 不像树那样每帧按远近重新分档、按视野剔除。一块地有几百棵，没必要每帧重算；
  - 近处的地块用近档模型，中间的地块用中档模型，只画高过草的（1 米以上）；
  - 不进阴影图；
  - 每种 3 个变体（小东西，每棵再各自缩放、转向、换色）；
  - 都用浅色调：小植物在阳光下，不该像大树冠里面那样深。
- 顺手修了一处：工具箱的"浅色"标记原来在世界里传不过去（樱花这样的树在世界里也偏暗），现在传过去了。
- 加 `?flora=m5` 仍是原来的地被。

## 草的面数回到预算内

预算里"草和花"是 120 万三角形，地被换进来以后，草地（Painted Valley 的草叶）加地被超了。草地减了一点：

- 最近的一圈（3 米内）每片草叶从 6 段弯折减到 5 段；
- 3–21 米那一圈从 3 段减到 2 段；
- 中间距离的地块只画 1 米以上的地被（原来 0.7 米）。

近看前后几乎分不出来（`D:/modcar-scratch/p2/meadow_trim.png`）。
