# 工具箱的第二批树种

2026-11-20。第一批 14 种之外，50 段风景和世界原有的树种家族还要 7 种（`src/game/scene/flora/trees2.ts`）：

| 种类 | 长相 | 用在 |
|---|---|---|
| 桉树 | 高而光滑的浅色树干，常带一点斜；大枝从高处升起；稀疏的窄叶在枝头一簇簇下垂，簇间都是天 | 赤土心（鬼桉）、火山花园（彩虹桉）；世界里的 eucalyptus |
| 垂柳 | 矮粗的干很快分成几根大枝，宽圆的冠，枝条像帘子一样一直垂到地面 | 风车圩的运河边；willow |
| 橄榄 | 两三根拧在一起的矮干，冠低而圆，一团团小的银绿叶 | 柏影丘、柠檬崖；olive |
| 红树 | 支柱根从树干上部拱出去、再插进泥里，冠低而密 | 红树潮径、珊瑚长桥；mangrove |
| 树蕨 | 一根细直的干，顶上一圈长长的蕾丝般的羽叶向外拱 | 苔谷、云崖道、火山花园；tree_fern |
| 刺柏 | 灌木似的针叶树：几根干，冠不规则、毛糙，鳞叶一团团 | 台地、荒漠边缘；juniper、dwarf_pine |
| 雪松 | 长长的平伸大枝托着一层层平展的叶片，宽阔分层，顶部较平 | cedar |

为了画垂柳的帘子，零件里加了一项：一团叶子里下垂的画卡可以比宽度长几倍（`kit.ts` 的 `hangLong`）。垂柳用 3 倍，一张卡就是一道垂到地上的枝帘。

## 进入世界

`?flora=kit` 打开时，世界里这几个家族也改由工具箱来长：

- eucalyptus、willow、olive、mangrove、tree_fern、juniper、cedar；
- dwarf_pine 也用刺柏的长法。

还剩陆均松（rimu）、智利火焰树、约书亚树三个家族照旧。

调了一轮：

- 第一版垂柳是个圆冠，没有垂帘。加了长的下垂画卡后，枝帘垂到地面；再把帘子收窄一些，让中间透出缝。
- 第一版雪松的平展叶片是平放的画卡，从树下仰看成了一片片黑色碎片。改成扁平的叶团，用松针图，层次就柔和了。
