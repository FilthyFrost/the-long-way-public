# V10 主角对准路前方、看得见的天气、几处小细节

接着 V9 做上次列的第 3、4 条里能快速见效的几件。

## 改了什么

- **瀑布对准路前方**（`core/world/earth/waterfalls.ts`）：
  - 找瀑布时，除了从路边垂直往外走，还往前偏 0.45 弧度各走一次；
  - 四条路线里，挑从 200 米前的路上看过去最接近正前方的那一道（落差封顶 200 米再乘以"正前方"的程度，不让一道侧面的高瀑布总是赢）。
  - 开到瀑布前，它更常挂在挡风玻璃里，而不是在侧窗外。
- **看得见主角的天气**（`core/world/earth/weather.ts` CLEAR）：靠"看得远"的地貌，天上飘的云和落下来的雨按地貌少三到四成：
  - 层状火山 1，角峰 0.9；
  - 方山、峡谷 0.8；
  - 星状沙山 0.7；
  - 新月形沙丘、纵向沙垄、花岗岩岛山、盐沼、盐湖、火山口湖、劣地、石柱与烟囱岩 0.6；
  - 桌状山、海蚀柱、冰川 0.5；
  - 海崖、U 形谷 0.4。
- **隧道洞口的拱石**（`scene/galleryBuild.ts`）：洞口那圈石头按段一深一浅排开，像一块块拱石，正中一块拱顶石最亮。
- **鱼怕人**（`scene/fishView.ts`）：人到了鱼群 7.5 米以内（离水面 3.5 米以内），鱼群往远处躲开，兜圈的速度快到四倍，之后慢慢平静下来。

## 数字

- 2385 项测试全部通过。世界修订号升到 23：瀑布换了位置。
- 性能闸门：这一轮测的时候，机器上有别的程序占着显卡（空闲时显卡占用 68%，开着四十多个浏览器进程），所有测点都超标。紧接着在同样的条件下跑上一版（V9），一样超标（P95 14.1–21.1 ms），这一版是 12.6–20.5 ms，两边持平。干净的数字等机器空下来再补。
