# 工具箱的树进入世界（开关 `?flora=kit`）

2026-11-20。审批 B 之前，先让你能在真实的世界里看工具箱长的树。

- 地址里加 `flora=kit`，世界里能对上号的树和灌木就改由工具箱来长。
- 不加就和原来一样，默认的游戏没有变。

## 怎么用

在局域网试玩的地址后面加上 `?flora=kit`：http://172.26.133.10:5173/modcar.html?flora=kit

- 存档照常接着玩，换的只是树的长法。
- 想换回原来的树，去掉这一段就行。

## 换了哪些

世界里原有约 55 个树种家族，工具箱有对应种类的就换成工具箱的长法（`src/game/scene/crowns/species.ts` 的 `KIT_OF`）：

| 工具箱种类 | 换掉的家族 |
|---|---|
| 云杉 | conifer、spruce、fir、douglas_fir、larch |
| 黄松 | conifer2、pine |
| 伞松 | stone_pine |
| 意大利柏 | cypress |
| 橡树 | broadleaf、broadleaf3、oak、linden、beech、maple、chestnut、camphor、giant_broadleaf、ash、marula、river_fig、southern_beech、desert_poplar |
| 白桦 | birch、aspen |
| 钻天杨 | poplar、broadleaf2 |
| 樱花的长法（换成该树自己的颜色） | fruit_tree、lemon |
| 椰子 | coconut_palm、fan_palm |
| 金合欢 | acacia、blackwood_acacia、palo_verde、mesquite |
| 毛竹 | bamboo |
| 巨柱仙人掌 | saguaro、cactus |
| 猴面包树 | baobab |
| 圆团灌木 | bush、bush_dry、bush_alpine、rhododendron |

没有对应种类的（橄榄、桉、柳、红树、陆均松、智利火焰树、树蕨、约书亚树、矮松、雪松、刺柏）照旧。

颜色、大小、位置都还是世界原来的：

- 地区的树色和秋色照常作用；
- 每棵树按植物表的高度缩放；
- 种在哪里不变。

## 接进去要改的三处

1. **材质**：工具箱的树用工具箱的叶片图集和"亮色"标记（`flora/material.ts`），其余的树照旧。
2. **远处的照片**：远处的树是从模型烘出来的照片。烘照片时判断"这里有没有叶子"，原来看的是世界那一张圆形叶簇图。工具箱的树改看自己的图集：在内存里存一张 512×512 的遮罩（`flora/atlas.ts` 的 `floraCover`）。
3. **影子**：阴影图切叶子影子用的是世界那一张圆形叶簇图。工具箱的树把每张叶片卡的贴图坐标换成卡自己的 0–1 范围，影子就和其他树一样切。

## 结果

同样的五个地点，驾驶位看（`harness/shots/p3_kit_world.mjs`，截图在 `loop/shots/p3_kit_world/`）。

**树冠的三角形少了 40–55%：**

| 地点 | 原来 | 工具箱 |
|---|---|---|
| 森林（往右看） | 22.3 万 | 12.9 万 |
| 森林（往前看） | 12.2 万 | 7.1 万 |
| 雪山（往前看） | 13.5 万 | 7.0 万 |
| 湖区（往左看） | 21.5 万 | 13.0 万 |
| 红岩荒漠（往左看） | 7.1 万 | 3.2 万 |

**性能检查**（`perf_gate.mjs --kit`）：

- 树：森林 0.15 → 0.09 M，雪山 0.15 → 0.08 M，湖区 0.16 → 0.11 M；
- 每帧略快：森林 8.83 → 8.51 ms，雪山 8.18 → 7.48 ms；
- 绘制次数不变：每个树种还是同样几次。

**看起来：**

- 森林、湖区、草原、红岩荒漠里，工具箱的树和原来的树放在同一处，整体气氛一致，近看各树种的长相更分明。
- 雪山上的云杉，积雪比原来的多、更白，远看整片林子像挂了霜。原因是工具箱的云杉枝层朝上的面多。
  - 我已经把枝层的光照往上弯得少一些，减轻了一些。
  - 白一点好不好，请你看了再定。

## 验证

- 类型检查、生产构建通过；全部单元测试通过。
- 工具箱的预算测试 30 项照旧通过。

## 还没做

- **种子变体**：每个物种现在仍是 2 个种子变体，和原来一样。
  - 每多一个变体就多几次绘制。
  - 8–16 个变体和"最近的十几棵各不相同"，要等阶段 3 的合批（一次画多种模型）做好再加。
- **其余树种**：工具箱还没有对应种类的那些树种，以后补。
- **地被**：丛草、花、灌木还没进世界。地面的草和花是另一套系统（`meadow.ts`、地被植物表），阶段 3 一起换。
