# 阶段 2：程序化植被工具箱（14 个样板，待审批 B）

2026-11-20。依据：[总方案](../PLAN.md)；植物原型清单见 [五十段风景公路](../research/scenic-50.md) 第七节。

## 做了什么

一套在游戏代码里长植物的工具箱（`src/game/scene/flora/`），照 Painted Valley 的画法：

- 树干和树枝是沿曲线扫出的圆管；
- 树冠一团一团：每团一个暗色的芯，外面插一圈叶片画卡，整团按一个球受光，顶上亮、底下暗、里面更暗；
- 叶片画卡是圆头笔触，画在一张 16 格的叶片图集上（`atlas.ts`）：云杉、橡、桦、蕨、松、樱花、柏、金合欢、圆叶、竹、棕榈羽叶、龙血树的剑叶丛、丛草、针茅、石楠、草本茎叶。

同一套零件按"骨架"长出不同的树。这次用它长了 28 种：

| 家族 | 种类 |
|---|---|
| 树（14 种） | 云杉、橡树、黄松、伞松、白桦、钻天杨、樱花、意大利柏、椰子、金合欢、龙血树、毛竹、巨柱仙人掌、猴面包树 |
| 丛草（4 种） | 草甸草丛、金色丛草、针茅、刺鬣草团 |
| 花（5 种） | 虞美人、金罂粟、郁金香、雏菊、鲁冰花 |
| 灌木（5 种） | 圆团灌木、石楠、鼠尾草灌丛、薰衣草、帝王花 |

每种都按自己的长法长，不只是换颜色：

- 云杉一层层裙摆收成尖塔；
- 橡树几根大枝"之"字形向外伸；
- 黄松下半截光干、上半截一簇簇针叶；伞松在高干上撑开平顶圆伞；
- 金合欢一层层平台；龙血树分叉再分叉，顶成一朵蘑菇；
- 竹子一丛竹竿像喷泉一样向外散开；
- 巨柱仙人掌是带棱的柱子，手臂先平伸再拐弯朝上；
- 猴面包树是大瓶子，顶上一圈像树根的短枝。

## 面数预算：每种都在预算内

工具箱的核心是一个"面数分配器"（`kit.ts` 的 `draw`）：

1. 先按近处或中景画出木头；
2. 再画每团的暗芯：大团用十二角球，小团用六角球，中景的小团不画；
3. 剩下的面全部分给叶片画卡，按每团大小分。卡少了就把每张画大，树冠保持饱满。
4. 木头和芯本身就超预算时，先去掉芯，再去掉最细的木头。

所以无论种子是什么，长出来的植物都不会超预算。单元测试（`harness/sim/p2_flora.test.ts`）用 12 个种子检查全部 28 种的近处和中景，还核对这里的预算和 `docs/V3/perf-budget.json` 一致。

远处（中景以外）沿用游戏现有的"树冠照片"做法，一棵树两个三角形；新树种接进去放在阶段 3。

对比上一轮：第一版云杉近处 14,990 面、橡树 10,568 面、黄松 6,902 面；世界里现有的树近处多在 2,500–5,000 面，竹子 6,380 面。

长一棵近处的树只要 0.2–1.1 毫秒（游戏里实测，八个种子的平均）。所以阶段 3 可以按计划让离你最近的十来棵树每棵都独一无二，每个物种另备 8–16 个种子变体。

## 调了四轮

1. **第一轮**的问题：
   - 云杉的暗芯太大，看不出层次；
   - 橡树冠太宽太空；
   - 伞松没撑开；
   - 樱花太紫太暗；
   - 金合欢叶子太细；
   - 花太小，被路边的长草淹没；金色丛草在阴影里成了暗红褐色。
2. **第二轮**的改法：
   - 植物材质加了"亮色"标记：花冠、草、花保持浅色调，阴影是柔和的浅影，不是树冠里那种深蓝绿；
   - 花头和丛草画得比真实大（画家的做法：真实大小的花从路上看只是一个点）；
   - 地被改种在路肩上。
3. **第三轮**：
   - 黄松的针叶簇沿枝条外半段长，不只长在枝头；
   - 伞松单独写了一种长法：高干分叉，大枝往上斜伸到一个平顶圆伞；
   - 竹子改成一丛竹竿像喷泉一样散开，叶子长在每根竹竿的外侧，竹竿露出来。
4. **第四轮**：
   - 仙人掌的手臂分在不同方向，不会全藏在柱子后面；
   - 石楠的紫色压淡一些；
   - 竹丛加密。

## 已知的不足（之后处理）

- **花远处消失**：植物材质里的花（第二颜色的部分）在 25–66 米之间按每朵各自的距离淡出。远处的花田要靠地面着色表现，阶段 3 做花田段时一起做。
- **影子形状**：新树的叶片影子用的是世界里那一张圆形叶簇图来切，不是各自的叶形；轮廓和明暗都对，细节不同。阶段 3 接入时给影子也用新图集。
- **云杉**：层次出来了，但下垂的枝帘还可以再细一些。
- **竹子**：还偏稀，正式做竹海时按成片的竹林做。
- **远处照片和种子变体**：新树种的远处照片、每个物种 8–16 个种子变体，阶段 3 接入世界时一起做。
