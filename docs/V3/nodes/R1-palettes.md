# R1 色调盘：每个地方一套颜色

方案：`plan/scenic-roads.md`。上一步：`E6-earth-sky.md`。

## 一句话

每个地方先算出一套色调盘，再让树、草、花、庄稼、灌丛、苔藓、地面、岩石、阳光和天空都从里面取色。

- 每种植物原有的颜色只用来和别的植物区分：白桦比橡树浅，云杉比松树深，橄榄比别的树灰。其余都听这个地方的。
- 雪地里所有树冠都是挂雪的墨绿、灰蓝，草是霜色。
- 炎热的荒漠里灌丛是鼠尾草的灰绿，草是枯黄。
- 湿热带的林子深而有光泽，秋天的林子红或金。
- 相邻两个地方的色调总有一点不同：一个偏暖偏亮，下一个偏冷偏深。

## 做了什么

| 部分 | 做法 |
| --- | --- |
| 色调盘 | `core/world/earth/palette.ts paletteOfPlace`（在 OKLab 感知色彩空间里算） |
| 主色 | 每种植被色调（深绿、绿、嫩绿、青绿、橄榄、灰、金、秋色……）一对主色：树的、草的。 |
| 按地方调主色 | 干旱：叶子变灰绿，草变枯黄。旱季：草变金黄。湿热带：叶子更深。冷：叶子偏蓝偏深。苔原：夏天绿，九、十月锈红，其余时候褐色。冷月份不下雪：草像干草。下雪：一切压成墨绿和霜色。冰原：没有绿色。 |
| 每个地方自己的一点 | 单数地方偏冷偏深，双数地方偏暖偏亮，幅度随机：色相 5–12°，饱和度 4–12%，亮度 1–4%。 |
| 植物取色 | 共五条规则：叶子、秋叶、草叶、花和果、树皮（另有地面的苔藓地衣，向土色和草色靠）。都是"相对参照色差多少，到这个地方就差多少"，饱和度不超过这个地方的上限。 |
| 接进游戏 | `scene/earthPaint.ts` 为每个地方、每种植物算好叶色和第二色：远处图集画的植物和近处手绘树冠都用它。秋天每七棵里有一棵还绿着，每五棵有一棵全金。地面小草、灌丛、花、石头在 `core/world/groundField.ts earthClump` 里取色。 |
| 地面 | 草地的三个色调是土色和草色按长草多少混出来的；落尘、枯草也用色调盘的土和枯草。暖色、冷色两种大色块也由色调盘给（金色苔草和橄榄苔藓，稀树草原的金和橄榄……）。 |
| 空气 | 每个地方的地平线、天顶、雾和太阳都有自己的色调（`env/colorScript.ts` 读 `palette.air`）：炎热的荒漠地平线暖、太阳白热；雪地偏冷蓝；高原天顶深蓝、远处清楚；湿热带雾气重；秋天阳光金黄；海边多雾。 |

## 顺手修掉的三个出戏的地方

1. **林线以上的高山草甸和苔原被画成了光秃秃的石头**（看起来像沙漠）。原来的规则是"林线以上全是岩石、不长草"。现在加了一条"裸地线"：草甸、苔原一直长到生长季平均温度降到 3 °C 的地方，大约在林线以上五百米，而且至少比路高 320 米。
2. **砂岩、页岩的地方，所有高出谷底的地面都被画成了层状岩石。** 现在只有干旱、光秃的地方，或者方山、峡谷、海崖、峰林这类地貌才这样画。长着植物的砂岩山就是绿的（或者按季节变色）。
3. **离河一米多高的谷底都被画成了沙滩。** 现在只有沙岸和荒漠的水边是大片沙滩，别处只在水边留一条。

另外，以前的截图脚本拍在两个地方交界的地方（每处 5 km 里有 3.5 km 在过渡），现在改拍每个地方的正中间。

## 数字

- 测试（`harness/sim/r1_palette.test.ts`，6 条旅程、240 个地方）：
  - 雪地里 12 种树的叶色饱和度都不超过 0.055，草都不超过 0.05；
  - 湿度低于 0.2 的地方，草都不是绿的，叶子饱和度都不超过 0.095；
  - 每个地方各种树的色相差都在 50° 以内，白桦总比云杉浅；
  - 相邻两个地方的色调盘，85% 以上明显不同；
  - 同一种松树在不同地方，饱和度差 0.05 以上、亮度差 0.12 以上；
  - 有植被的地方，裸地线都比路高 300 米以上。
- 全部测试 2340 项通过。

## 已知不足

- 苔原、热带雨林这些地方，近处的地被模型还太少，看起来空。R4–R5 补。
- 水的颜色还没有按地方调。
