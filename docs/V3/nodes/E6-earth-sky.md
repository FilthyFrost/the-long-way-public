# E6 天空和天气按地方变

方案：`plan/emergent-earth.md`；上一步：`E5-earth-director.md`。做完这一步停下，用户进游戏审。

## 一句话

每个地方的天气现在是它自己的：天空多云的程度看干湿；阵雨还是阵雪看这个月冻不冻；风看生态卡和海边；早晨的雾看湿度。云雾林整天都裹在雾里，海边的雾漠、冷湿的海岸也有整天的雾。炎热的荒漠空气里悬着一层沙尘，天是暖黄的。风暴也按地方来：雪地里是暴风雪，沙海里是沙墙，湿热带是雷暴，温带是雨和冰雹，云雾林和海边多雾。

## 做了什么

| 部分 | 做法 |
| --- | --- |
| 天气规则 | `world/earth/weather.ts weatherOfPlace` |
| 平常天气 | 云量 0.3 + 0.8×湿度（在云带里就是 1）。月均温低于 −1°，或生长季不化冻，就下雪不下雨；太干的地方不下雨。风 = 3×卡上的风，海边再加 1。晨雾：雾多的卡大多数早晨都有，而且浓；湿的地方 0.6，偏湿 0.35。 |
| 整天的雾（新加的 `haze`） | 在山的云带里（`cloudAt` 大于 0.3）：0.3 + 0.35×云带程度。荒漠海岸：0.3。温带雨林：0.15。冷湿的海岸：0.12。 |
| 空气里的沙尘（新加的 `dust`） | 湿度低于 0.2、月均温高于 15° 的地方：0.06 + 0.25×卡上的沙尘，沙地再加 0.04，最多 0.2。天空、雾、阳光都偏暖黄（`env/colorScript.ts` 本来就会按沙尘调色）。 |
| 风暴 | 有雪：暴风雪 60%、雪 30%、雾 10%。荒漠：沙地上沙暴 75%，不是沙地 45%，其余雷暴。云带：雨 30%、雾 70%。湿热带：雷暴 65%、雨 30%、雾 5%。海边：雷暴 35%、雨 30%、雾 35%。地中海的夏天：雷暴 30%、雨 70%。其余温带：雷暴 45%、冰雹 15%、雨 30%、雾 10%。 |
| 接入 | `env/weather.ts setRegionWeather`：地方做成区域时，把它的天气记在它的 id 下；天气系统照常按区域混合。 |

## 数字

- 测试（`harness/sim/e5_earth_director.test.ts` 后两条）：每个地方的天气都在合理范围内；下雪的地方不下雨、风暴里有暴风雪；太干的地方不下雨；干的地方有沙暴；云带里的地方整天有雾；天气系统里，云雾林在早上 6 点、10 点、下午 2 点、6 点的雾都不低于它整天的雾。

## 已知不足

- 光的颜色只通过雾、沙尘、云来变。各地太阳的颜色、天空的色调（比如高原那种特别深的蓝）还没有单独按地方调。
- 极光、银河、季风暴雨这些特别的天象，在 V3 总方案的阶段 4 里做。
