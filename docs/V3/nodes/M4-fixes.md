# M4 修正：声音、房车、下蹲、尿尿

玩家试玩 M4（声音版）后提的问题，逐条改了。原则：音效库里有的声音一律用库里的录音，不再用合成器做；录音还没加载完时宁可先不出声，也不拿合成声顶替。

## 改了什么

1. **尿尿的声音**
   - 原来是合成的"嘶嘶"声，像漏气。
   - 现在用音效库里 Arctic Drive 的录音，分开始、水流、结束三段。
   - 水流按脚下换录音：水泥（公路、砂石也用它）、金属、木头（含房车地毯）、雪地。泥土、草地、沙地用雪地那条软声。
   - 憋得久的时候（膀胱超过 40），尿开后一秒多会"啊——"一声舒气，从 Arctic Drive 的 8 条里随机挑。
2. **开车时的底噪**
   - 在 88 km/h 实测：发动机约占一半，其余是三样合成声——柏油路上的轮胎滚动声约 41%，随车速变大的风声约 20%，路面低频约 12%。三样全删了。
   - 柏油路和冰面不再有滚动声，车速风声和路面低频归零。天气的风照旧由音效库的风声铺底。
   - 砂石路的滚动声和打滑声换成 Arctic Drive 的砂石轮胎录音。
   - 土路、草地、沙地、雪地暂时还是合成的，因为库里没有这几种录音。
3. **起步时的轮胎声**
   - 原因：皮卡全油门起步时，后轮空转到车速的 6 倍，持续约 2 秒。当时放的是转弯打滑那种 1.2 kHz 的合成尖叫，所以又尖又薄。
   - 现在换成 Long Drive North 的柏油打滑录音。驱动轮空转时按 0.75 倍速播放，更低更厚，音量减三成。
   - 侧滑和抱死刹车照常用这条录音，音高按滑动速度变。
4. **房车**
   - 侧门开着时，直接走进去、走出来，不用按键；门关着走不进去。
   - 车厢里从门口直着往后走，会被顺势引着绕过柜子拐进过道，一直走到后排。原来会顶在柜子上走不动。
   - 按 E 上下车仍然可用。
5. **C 下蹲**
   - 步行时按 C 蹲下：视线从 1.62 米降到 1.10 米，走得慢、脚步轻。再按 C 站起，头上有空间才站得起来。
   - 坐在车里时，C 仍是切换视角。
   - 操作说明里加了这一条。
6. **尿尿的粒子**
   - 从腰部往前一步远落地，是一道半透明的黄色细流：一滴一滴拉成短线，连起来读成一道。
   - 落地处溅起小水点，地上留一块深色湿印，尿完后约 40 秒慢慢干掉。
   - 画法同车轮扬尘：受天光、日光和雾影响，不影响描边。
7. **喘气和心跳**
   - 原来的喘气声是合成的。现在用 Arctic Drive 的喘气录音：体力低于 20 开始一口一口地喘，先急后缓（急喘 5 条、慢喘 7 条轮换）；恢复到 45 时长出一口气（3 条之一）。
   - 重伤时的心跳换成 Long Drive North 的心跳录音，伤得越重跳得越快。

不接音效库时（构建版、别的电脑、`?archive=0`），这些声音仍退回原来的合成声。

## 怎么验的

- `harness/shots/m4fix.mjs`，截图在 `loop/shots/m4fix/`，全部通过：
  - 下蹲：视线 1.62 → 1.10 米，再按 C 恢复。
  - 尿尿：看得见水流（空中约 130 滴）和湿印，听得见开始、水流、结束三段录音。
  - 喘气：4 次急喘、2 次慢喘、1 次缓过来；受伤时 3 秒内 4 次心跳。
  - 房车：门开着时走进去、走到后排、走出来都不用按键；门关着走不进去。
- `harness/shots/m4fix_noise_probe.mjs`：51 和 88 km/h 时，风声和路面低频都是 0，柏油路上没有轮胎滚动声。
- `harness/shots/m4fix_launch_probe.mjs`：全油门起步时打滑录音按 0.5 档播放（实际 0.75 倍速），音量 0.49。
- 原有验收：`m4_audio.mjs`（M4 声音）、`m2_rv.mjs`（M2 房车）全部通过。
- 单元测试 2,058 项通过，4 项跳过。新增 `harness/sim/m4_fixes.test.ts`，并更新了轮胎声测试。全套并跑时，地形生成的一项耗时测试因 CPU 繁忙超时一次，单独跑 27 项全过，与本次改动无关。
- 生产构建通过。

## 待试玩

1. 下车，按住 P：听开始、水流、结束；低头能看到水流和地上的湿印。
2. 开到 80–100 km/h：应该只剩发动机，没有底下那层"沙沙"声。
3. 全油门起步：轮胎声应该低、厚，不刺耳。
4. 打开房车侧门，直接走进去，往后走到后排，再走出来。
5. 步行时按 C 蹲下、再按 C 站起；坐进车里按 C 仍是切视角。
6. 跑步把体力耗光：听喘气由急到缓，最后长出一口气。
