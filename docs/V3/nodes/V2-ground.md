# V2 地表：草地、花、岩石，和一次大的性能腾挪

视觉迭代的第二个里程碑（`../plan/visual-loop.md`）。2026-11-21。

## 做了什么

**花回来了。**
- 原因：从 E3 开始，地球世界的草地上的花全交给了"地被植物团"，而这种团很少。结果所有地方的草地都没了成片的花，花田里一朵花都没有：数了 25 块 40×40 米的草地，花是 0。
- 现在草地重新有花：
  - 花田照常有一垄一垄的花，每垄一种颜色，比以前更密；
  - 别的地方的草地有成片的花，数量是覆盖表里花量的七成（`scene/worldBuild.ts` meadowSample、ROW_FLOWERS）。
- 结果：花田每块草地约 1950 朵花，林荫道的草地约 180 朵。

**草地远看有笔触**（照 Painted Valley 的画法，`render/terrainMaterials.ts` rtMeadowDabs）：
- 中景的草地上有一团团颜色深一点的粗草，聚成大片；
- 更细的是一笔暗一点的草丛、一点阳光；
- 每一层笔触在格子小到只有几个像素前就淡掉，所以不会闪；
- 再远一些，花丛变成草上的一层花色（花粉一样的点）。

**岩石。**
- 照 Painted Valley 画远山的方法，同时画四种大小的石块：220、64、19、5.5 米。大块上叠小块，每块各自朝向光或背光，石块之间的缝是暗的。缝始终只有一两个像素宽，而且是断断续续的（rtRockFacets）。
- 以前是按距离只画一种大小，远处一面山只剩几块大平面。雪山上那种 260×180 米的固定三角面，看起来就是 low poly，现在也换成了这四种大小的石块。
- 石块铺在岩面自己的方向上：峭壁上的石块竖着排，缓坡上的平铺（rtRockPlane）。

**绿色的地方保持绿色。**
- 森林、林地、湿地、农田，以及湿润草原里的峰林、方山和峭壁：除了最陡的那几面，都是绿的。以前这些地方的高处会被整片画成条纹岩石，所以湿润喀斯特的峰丛看起来是光秃秃的黄白条纹（`core/world/earth/region.ts` green）。
- 远山上露出多少岩石，看这个地方本身：荒漠里只要有坡就露岩，森林里只有峭壁露岩（terrainMaterials.ts e0）。

**拿掉了旧的占位地标。**
- 第 5 版世界里不再放水泥大圆环、石柱廊、搁浅的军舰这些旧占位地标（`core/world/landmarks.ts`）。它们是灰色的平面方块，站在手绘风的山野里很突兀，还会出现在不合适的地方，比如湿润喀斯特的森林里立着大圆环。
- 以后的地标会按这个世界自己的方式做。

**性能：快了大约三成。**
- 深度缓冲改成"反向浮点深度"，前提是显卡支持 EXT_clip_control（`render/core.ts`）。这个改动不影响画面。
  - 以前用的是对数深度：每个片元着色器都要自己写深度，GPU 就不能提前剔除被挡住的东西。
  - 结果是所有被挡住的东西都会先上色再被覆盖：仪表台和引擎盖下面的地面、树后面的草、树后面的树。
  - 现在被挡住的部分不再上色。
- 需要自己写深度的地方都改成了反向深度的写法：
  - 树冠远景卡片、试车场的地面漆、路面和贴花要往视线方向拉近的那一点；
  - 阴影的比较方向反过来，阴影矩阵不再改 z（`render/shadow.ts`、`shaderlib.ts`）；
  - 绘画后期按深度换算距离（`render/frame.ts`）。
- 网址加 `?depth=log` 可以退回对数深度。
- 草地和岩石的格子改成从一张贴图里取（`render/textures.ts` cellsTexture），一次采样就够，不再每个片元搜索 3×3 个哈希。

## 数字

- 性能闸门（5060 Ti，1080p，驾驶座，P95）：

  | 测点 | V2 之前 | V2 之后 |
  |---|---|---|
  | 森林 | 11.5 ms | 9.2 ms |
  | 开阔地 | 8.4 ms | 6.3 ms |
  | 山地 | 10.4 ms | 7.1 ms |
  | 海岸 | 9.9 ms | 7.6 ms |
  | 荒漠 | 8.0 ms | 6.2 ms |
  | 高架桥 | 8.7 ms | 5.8 ms |
  | 河边 | 11.0 ms | 9.2 ms |
  | 石廊 | 9.8 ms | 6.1 ms |

- 河边那个测点：草的三角形数还是比分项预算多 4%，和以前一样。
