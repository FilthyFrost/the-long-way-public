## 给用户的试玩清单

1. 开皮卡或房车，往右下看：两座之间的手刹；点左键拉起、再点放下；开车时按住空格，拉杆跟着抬。
2. 开车时右边的按键列表里没有“下车”；看向左边车门时才出现“E 下车”。
3. 停车，往右看副驾驶座，按 E 挪过去；看右边车门，开门下车。再从外面打开副驾驶门坐进去，挪回驾驶位。
4. 往车斗或后备箱放几样东西；站在车旁按 Tab：左边是身上，右边是车上，A / D 切换，E 放进去或拿出来；看一眼车里，东西确实进去或出来了。
5. 下雨天（开发面板的天气页签可以调）走进路边的房子或车库：雨声变闷，有雨打屋顶的声音，人不会被淋湿。
