# E0 规则表 + 旅程模拟器（涌现地球的第一步）

方案：`plan/emergent-earth.md`。这一步不改游戏画面：只有规则、导演和一个不出画面的旅程模拟器，外加一张旅程卡片页。

## 一句话

一个随机种子 → 一条穿过整个地球的公路。每 5 km（时速 60 约 5 分钟）一个地方；每个地方是什么，全由几条真实规律算出来：它的生态、地貌、岩石颜色、水、季节、名字，还有路特意带你去看的那个"时刻"。一段 400 km 的旅程平均遇到 22 种路边生态系统（算上坡上和水边近 40 种）、27 种地貌，相邻两处太像的只占 5%。

## 做了什么

代码都在 `src/core/earth/`（纯逻辑，不碰画面，E1 起世界直接读它）：

| 文件 | 内容 |
| --- | --- |
| `kinds.ts` | 模糊区间（梯形）、季节型、水、扰动、地势这些共用的词 |
| `rocks.ts` | 18 种岩土：亮面、暗面、土色，名字里的颜色字，肥不肥，软硬 |
| `efg.ts` | 70 张 IUCN 生态功能类型卡：陆地 T1–T7（含 8 种荒废的农田、牧场、果园），淡水 F、湿地 TF、海岸 MT/MFT/FM、岸上看得见的海 M；每张写它的温度、湿度、生长季、需要的条件、结构、高度、植物原型、主色、招牌景、起名用字 |
| `landforms.ts` | 55 种地貌，按成因分 11 家（风、流水、冰川、冻土、喀斯特、火山、构造、风化、海岸、蒸发盐、平地）；每种写它要的岩石、地势、干湿冷暖、起伏范围、山顶要不要冰 |
| `climate.ts` | 物理：气温随高度降（每千米 6.5°）；迎风坡越往上越湿、背风坡干（雨影）；山的云雾带（凝结高度以上，热带 7–20°、温带 3–12°）；一年的冷暖幅度（热带一两度、海边六七度、西伯利亚三十度，按 9 个真实气象站对过）；生长季均温（林线在 6.4°，Körner & Paulsen 2004）；最热月不化冻的地方才是冰盖（柯本 EF）。还有：一个点选哪张卡、两张卡之间的过渡带、"斑块"（同一气候下森林里的草场、稀树草原里的旱林，由导演挑一块，只在它几乎和最合适的一样合适的地方成立） |
| `look.ts` | 一个地方"长什么样"压成一个签名（结构、植被色、地面色、轮廓、水、雪、起伏），两个签名之间的视觉距离；各生态最美的月份；按生态、地貌、岩色、季节起两三个字的地名 |
| `director.ts` | 导演：17 种走法（翻山、下山、进盆地、上高原、到海边、离开海岸、顺河走、换纬度、变湿、变干、跨地质分界、进火山区、进喀斯特、进沙海、进湖区、进湿地、进冰川区）。每次往前看：把能走的每一种都试一遍，看它会带来的地方，挑新鲜的（和最近十几处不像、没见过的生态和地貌）、合节奏的（不连着翻山、高低交替）、合"环球路线"的（冷暖、干湿按一条长波在热带和高纬、沙漠和雨林之间来回）。每个地方再挑地貌（走法自己的那家更常见）、季节（往这个生态最美的月份转，一次最多两个月）、斑块；和上一处太像就换个地貌、来条河、换块岩石，按可能性挑 |

规则里几条重要的"不许"：

- 公路只翻到雪线以下（生长季均温 0.5° 以上），冰川在山顶看得见；路面上永远不是冰盖。
- 纬度慢慢变冷时，路跟着往下走，不会停在冻住的高处。
- 翻山、下山时纬度和干湿几乎不动：变化来自高度，所以一次翻山能看到一层层的带。
- 盐和石膏只在干的地方；变湿了，盐湖变淡水湖，盐壳变黏土。红树林、海岸盐沼、三角洲只在海边。农田、牧场要有土；森林不长在盐上。
- 地势、岩石、水在一段走法的哪里换：翻山时一开始就离开平地的河和海岸，下山时到了谷底才出现河和平原，跨地质分界换在中间。
- 热带的卡和极地苔原永远不相邻。

70 张卡、55 种地貌在四万个随机地方里都有容身之处（测试保证）。40 条旅程里没走到的：白沙石楠林（要湿热带的白沙）、泥炭藓沼泽、鼓丘、冻胀丘、桌状山、礁岛——都是稀有组合，E5 导演会专门安排"哇"的时刻。

## 例子：种子 2331，120–170 km

从三角洲的雨林出发，过岛链、峰丛，一路翻上去：热带低地雨林 → 稻作梯田 → 常绿阔叶林（798–1295 m）→ 热带山地云雾林（"路上漫过的云"，1824 m）→ 石柱峰林在云里（2337 m）→ 帕拉莫高山草地（"雾里的高山湖"、"一株株巨大的银色莲座"，2784–3275 m），山顶是冰川。

## 已知不足，留给后面

- **湿热带的大翻山少**：80 条旅程里 3 条有"雨林 → 云雾林 → 帕拉莫"这一整段（E1 坡度放缓后只剩 1 条）。环球路线里湿热带本来就只占一小块；E5 导演会把它当招牌时刻安排。
- **地球是压缩的**：从温带到热带最快五六处（二三十公里）。每一步都是自然的邻居，但比真实快得多；这是"每 5 分钟一个新地方"的代价。
- **草原、疏林偏多**（路边约三成）：温带偏干的默认样子。真实地球也这样，以后可以让导演多偏向森林和水。
- **地名朴素**：两字组合（樟河、苍雾、金扇、紫湾……），偶尔别扭；E5 再细修。
- 动物不在这一步（E7）。
