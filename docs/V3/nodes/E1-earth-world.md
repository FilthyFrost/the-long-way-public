# E1 环境场接进世界：第 4 版世界

方案：`plan/emergent-earth.md`；上一步：`E0-earth-rules.md`。

## 一句话

新开一局现在是第 4 版世界：导演（`src/core/earth/`）排出的每个地方，在路上就是一章、一个它自己的区域。区域的海拔、地势起伏、山谷两侧的山墙、水和海、林线和雪线、白天黑夜的气温、植物和颜色，都从这个地方的数据算出来。开进一个地方，屏幕上出它的名字。第 3 版和更早的世界一点没变（`?world=3` 还能开）。

## 怎么接的

| 部分 | 做法 |
| --- | --- |
| 区域注册表 | 手写的区域照旧（`AUTHORED_REGIONS`，12 个）。地球的区域在旅程走到时才追加在后面（`biomes.ts earthRegion`），同一个 id 永远同一个下标。第 2、3 版世界只认手写的那些（`handRegions`）。 |
| 噪声 | 地球区域的地形、天气、林子的噪声用它自己的 `noise`（`4096 + 第几个地方`），不用注册表下标。所以同一个种子做出来永远是同一个世界，不管之前做过什么别的世界。手写区域的噪声还是原来的下标，一个数都没变。 |
| 第 4 版规则 | `rules.ts RULES_V4`：第 2 版的生成器，发牌换成 `earth/road.ts DEALER_V4`。先是家（开局要求的区域，车间那片还是原来的样子），然后导演的每个地方一章，4 段路（5 km）。相邻两章混合的宽度是短的那章的七成，不超过规划允许的最大值。路更用力地贴向这一带的海拔（`pull` 0.07），能跟上导演 4.5–6% 的长坡（导演的坡度从 5.5–7.5% 降到了 4.5–6%）。 |
| 地方 → 区域 | `earth/region.ts regionOfPlace`：路的弯直按地势挑（山地像高山，河谷像竹海，丘陵像枫叶丘陵，平原、盆地按干湿像荒漠或草原）。海拔就是地方的海拔。起伏按地势：丘陵的山丘有这一带起伏的一半多高；山地、河谷起伏过 450 m 就有两侧山墙；远处的山脉是起伏的 1.6–3 倍。湖、河、湿地、海岸、盐湖、绿洲按地方的水来。林线在生长季均温 6.4° 的高度，雪线在这个月月均温低于零下一度的高度。白天黑夜的温度按这个月和干湿算。颜色（`EarthLook`）用岩石的地面色、植被色、花色、干燥程度、积雪、岩层、秋色。 |
| 植物 | `earth/flora.ts floraOfPlace`：按路边生态卡和上一层带的卡出一张植物表。卡上的树、灌木、作物用世界里已有的植物画；植物表加了 25 种，用已有的树冠家族：椰子、扇叶棕、金合欢、桉、红树、树蕨、橄榄、意大利柏、雪松、红杉、伞松、约书亚树、落叶松、冷杉、雨林巨树、偃松、山毛榉、山杨、绿干树、榕树、马鲁拉、陆均松、杜鹃、刺灌丛、高山矮灌。每公顷几棵、林子占多大，按结构定；林子到林线为止。水边有柳、榕、芦苇，热带海边有红树，干旱的河和绿洲边有扇叶棕。梯田、茶园、葡萄园、向日葵各有各的作物。 |
| 借的部分 | 地貌和锚定地形（喀斯特的石峰、峡谷区的孤山）、地面上的小花小草，暂时借最像的手写区域（`templateOf`）。E2 起换成地方自己的。 |
| 画面 | 区域的样子第一次用到时才做（`render/style.ts styleOf`），地球区域的调色从它的 `EarthLook` 来（`scene/palette.ts earthPalette`）。 |
| 屏幕和工具 | 地名、开发者面板的旅程条、"这里是哪"都读同一个旅程接口（`journey/road.ts RoadJourney`），第 3 版和第 4 版通用。存档记第 4 版。 |

## 数字

- 测试：新增 `harness/sim/e1_earth_world.test.ts` 7 条，全部 2319 条通过（两条"第 4 版不存在"的旧测试改成了第 5 版）。
- 同一个种子，中间做过别的世界，再做一次，地形高度一点不差。第 3 版世界做第 4 版前后完全一样。
- 路跟着地方的海拔走：两个种子各 58 个地方，地方中点处路的高度和地方的海拔差不到 320 m（高处不到四分之一）。翻山时大约落后 100–170 m。
- 性能（种子 7，RTX 5060 Ti，1920×1080，驾驶位）：森林 11.3 ms、开阔地 8.3、山地 8.3、海岸 8.4、荒漠 7.4，绘制调用 222–286 次。同一时间量的第 2 版：森林 10.7、草原 8.4（今天显卡整体比 2-C 时慢，2-C 时第 2 版森林是 8.5）。地球的森林比第 2 版的森林多花 0.6 ms 左右，森林这一处 P95 超过 11 ms 的预算，第 2 版今天也超。
- 开 6 km：游戏自己每帧平均 3.25 ms（第 3 版 2.89），超过 20 ms 的帧 0.25%（第 3 版 0.03%）。地方都是新的，远景照片和独一无二的树多烘了一些。

## 已知不足，留给后面

- 地貌（沙丘、峡谷、方山、火山锥……）、岩石的纹理、地面小花小草，还是借手写区域的。E2、E4 做。
- 树和灌木是用现有的模型代替：E3 按性状长各地自己的物种。
- 天气、雾、光还没有按地方变，云雾林里还没有雾。E6 做。
- 坡度放缓之后，热带大翻山（雨林 → 云雾林 → 帕拉莫）更少见了，80 条旅程里只剩 1 条。E5 导演会专门安排。
- 每个地方 5 km，相邻两处在交界前后混合。变化是一步步的，不是连续的。
