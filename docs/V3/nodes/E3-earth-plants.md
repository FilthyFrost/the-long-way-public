# E3–E4 植物的性状和生态摆放

方案：`plan/emergent-earth.md` 第六节；上一步：`E2-earth-land.md`。

## 一句话

每个地方的植物现在都是它自己的：树和灌木来自它的生态卡；地上的草、苔藓、矮灌、花，一层一层跟着山坡往上换，每个高度用最合适的那张卡（`ecosystemAt`）。叶色、个头、花色都按气候的性状规则来：秋天在大陆性的冷地方是红的，在温和的海边是金的；干地方的硬叶灰绿；湿热带的深绿发亮；热带和高山的花是鸟传粉的红色管状花，温带的是蜂传粉的蓝紫黄白；林线下最后的树又矮又弯。路边的样子也按当地来：田野里一排白杨（地中海是意大利柏），开阔草原上偶尔一棵孤零零的大树，稀树草原上平顶的金合欢。

## 做了什么

| 部分 | 做法 |
| --- | --- |
| 地面档案 | `world/earth/profile.ts profileOfPlace`：每个地方一份自己的地面档案（`EcoProfile`），从海拔 −1000 到 9000 m 按 100 m 取样，同一张卡连成一层。每层的草（草甸禾草、高秆草、丛生旱草、莎草、苔藓、地衣、蕨、水稻）、矮灌（林缘灌丛、欧石南、蒿、刺灌丛、桃金娘、垫状草本）、花，都用地面系统认识的名字。每月的高温、低温、降水、积雪也在里面：季风型夏季多雨，地中海型冬季多雨；草的枯黄、霜打按月份来。每季的雪线、林线，地上散落的石头（花岗岩是圆石，玄武岩是柱状块，石灰岩是溶蚀孤石，砂岩、页岩是层状块，冰碛是砾石）也都在档案里。以前借的模板档案不用了。 |
| 花 | 颜色看谁来传粉。热带（不管干湿）和高山是红、橙红、玫红，加白；温带是紫蓝、黄、白、淡紫；荒漠是金、橙、粉；地中海是紫粉、黄、白。只在这个地方的那个月和前后各一个月开，雪下面不开。油菜是黄的，薰衣草是淡紫和紫蓝。 |
| 叶色 | `region.ts crownsOf`：秋天的落叶林，大陆性强（cont > 0.55）偏红，靠海的偏金。干燥温暖的地方叶色往灰绿拉 32%；湿热带往深绿拉 25%；冷的地方往深蓝绿拉 22%。秋天的林子直接换成枫树（红）或新加的金叶山杨（金）。 |
| 个头 | 林线下 120 m 以内多一排矮树（偃松，热带用当地的树），尺寸 0.4–0.7。干燥或风大的卡，所有树小一号（0.6–0.95）。 |
| 路边 | 田野：路两侧 12–26 m 一排白杨或意大利柏，跟着树篱线走。有树的草原：偶尔一棵 1.2–1.45 倍大的孤树（橡树，热带是金合欢）。稀树草原：路边散着金合欢。 |
| 地面颜色 | `render/style.ts earthStyle`：地球区域直接用自己的颜色画（玄武岩是黑的，红砂岩是红的），不再从类别的样子按比例"带过来"。原来那种做法最多只能变四倍，绿色的地永远变不成红色，所以火山渣原以前是一片绿草甸。 |
| 雪线 | 树冠的季节雪线现在是用到时才算（`floraScatter.ts seasonalLine`），地球区域的雪线也有了。 |

## 数字

- 测试：新增 `harness/sim/e3_earth_plants.test.ts` 5 条：每个地方都有自己的地面档案，各层首尾相接，用的植物、花、颜色地面系统都认识；山地的档案往上会换层；花色看传粉者，按月开花；树冠颜色看性状（秋色红或金，干地方比湿热带灰）；地面是自己的，林线有矮树、田野有路边树行。

## 已知不足

- 物种还是"原型 + 颜色 + 大小"，树形本身没有按性状变（比如板根、滴水叶尖、旗形树冠）。要等树的原型参数能按地方传进渲染。
- 地面植物的名字借的是参考档案里的说法，画法按它们的形态（草、莎草、苔藓、垫状草本……），种类还不多。
- 动物不在这一步（E7）。
