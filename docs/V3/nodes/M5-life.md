# M5 · 路边的鸟和昆虫

开车经过仙纳度牧地时，仓燕会成群扫过前方的田地，翻身转弯时可以看到一片深浅交替的翼面。停车走到池塘边，可以看到绿头鸭的绿头白领、绿翅鸭的栗色头和绿眼纹。在暖湿夏夜的田界，萤火虫沿着草梢和树篱低飞，风大时会稀下去。

## 去哪里看

| 地方 | 可以遇到 |
| --- | --- |
| 仙纳度牧地、农舍与水塘 | 每群 14–26 只仓燕，成群落地的美洲鸦；红尾鵟在开阔坡上盘旋，有围栏时也会落在栏上。淡水池塘里有绿头鸭和绿翅鸭。 |
| 枝头、灌丛、完好的架空线 | 该地研究档案列出的小鸟会栖在枝上、线的中点或围栏上。在两个栖点之间短飞，车或人靠近时飞离。 |
| 浅水、河谷、海岸 | 中国南方水田或喀斯特水边的白鹭，苔原池塘的天鹅，奥特韦海岸的银鸥、大苏尔的褐鹈鹕。天鹅有连续弯曲的长颈、贴水的身体和翘起的背羽。 |
| 花丛与湿地 | 蜂在花头附近小幅盘旋，白、浅黄、蓝灰、橙色的蝶按本地类群出现，在花丛间起落；蜻蜓限于适合本地种群的淡水。 |
| 林缘与灯边 | 仙纳度和阿巴拉契亚在六月、七月满足天气条件时有萤火虫。夜蛾绕室外点亮的台灯或太阳能灯。 |

旧游戏地貌共用路网的生态原型映射；研究档案 ID 可直接使用。每个实际候选点还要检查水深、盐淡水、花量、树或湿度。旅程暂以六月开始，每 30 个游戏日换月。鸟在 6–19 时活动；暴雨、雷暴、冰雹、暴风雪与沙尘暴会让鸟虫一起隐去。萤火虫要求实温至少 14°C、适合的当月气候与湿润落点，随降温和风速上升减少数量。

仙纳度牧地的两种鸭、美洲鸦和红尾鵟据美国国家公园管理局的当地名录补入。[仙纳度国家公园鸟类名录](https://irma.nps.gov/NPSpecies/Reports/SpeciesList/Species%20Checklist/SHEN/2/true?action=Index&controller=Park)

## 试玩与截图

1. 以种子 7 从普通草原开局，晴天下午开到约 3.98 公里。自然分布下能从驾驶座看到田上的仓燕。记录中驾驶员前方 30–105 米的画面范围内有 33 只。
2. 打开开发者面板「生灵」，看所在地的档案、月份和数量。选择本地物种，点「召来所选物种」，在合适的池塘、花丛或林缘看它；随后点「恢复自然分布」。召来仍然要过季节与天气条件。
3. 在雪山把时间拨到深夜，附近数量为零。选雷暴天气也会清空活动中的鸟虫。
4. `loop/shots/m5-life/before/` 保存第一轮的七张实机图；同名新图在上一级。两张驾驶视角是 `flock-seat.png` 和 `firefly-seat.png`。另有 `raptor-below.png`、`mallard.png`、`teal.png`。每张新图的同名 JSON 记下拍摄条件。
5. 仓燕驾驶图使用普通路网和自然种群。天鹅、斑蝶、萤火虫图用实机脚本临时注册研究原型和当月日夜气温，游戏本身没有注册这些测试区域。暖夜驾驶图中气温 15.1°C，附近 304 只萤火虫，前窗范围内有 60 只。萤光按曝光补偿，每只独立渐亮、渐暗；少数个体从草梢上方升起。相同驾驶机位的前后图为 `firefly-seat-before.png` 和 `firefly-seat.png`。普通草原的固定夜温较低，还需在正式月气候接入后复验。

## 怎么扩充

`src/core/v3/life/rules.ts` 中的名称对应生态档案，行内定义翼展、配色、行为和落点要求。新生态区直接复用已有类群或补一行。模型在 `src/game/modcar/v3/life/models.ts`，模块由内核自动发现。地栖大型鸟、蝉、蚊蝇、草蜢、蜣螂尚未建模。
