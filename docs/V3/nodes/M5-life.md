# M5 · 路边的鸟和昆虫

在梯田边停车，燕群会在田上兜圈。在内华达谷底的静水塘边，六月白天可以看到蜻蜓贴水悬停。在林缘慢慢走近一只停在枝头的小鸟，它会离开栖点。开走再回来，池塘、栖枝和出没的物种由原来的地点决定。

## 谁会出现

从路面所在区域取生态档案，再看候选地点是否真有淡水、海岸、开花的地被、树或湿润草地。25 份档案共接了 35 种鸟、9 种昆虫的名称或类群，共用 13 种模型轮廓。旧区域对应到研究里的地貌原型，新区域可以直接用研究档案的 ID；没有对应档案的地方留空。

| 在哪里看 | 能遇到什么 |
| --- | --- |
| 树冠、灌丛、民房围栏和路边架空线 | 蓝鸦、星鸦、山蓝鸲、莺雀等；栖鸟在两个落点之间短飞，靠近时飞起。架空线取两根实际电杆之间垂下的中点，断掉的线不落鸟。 |
| 田野与崖海 | 梯田上的燕群，奥特韦海岸的银鸥和短尾鹱，大苏尔海边的褐鹈鹕。小群绕圈时保持间距、随群转向。 |
| 开阔坡地与河谷 | 渡鸦、南方凤头卡拉鹰盘旋；非洲渔雕限于本地档案的河边。 |
| 浅水岸、池塘 | 白鹭站在浅水里，苔原天鹅浮在池塘水面上，附近有车或人靠近会起飞。 |
| 开花的草地与灌丛 | 野蜂、熊蜂、粉蝶、灰蝶、斑蝶、凤蝶，随地区和月份变化。 |
| 水边、灯边与湿润林缘 | 蜻蜓分淡水塘、河湾等栖息地；夜蛾绕室外点亮的台灯或太阳能灯；萤火虫在阿巴拉契亚六月、七月温暖湿润的夜里闪烁。 |

旅程暂以六月开始，每 30 个游戏日换月。鸟只在 6 时至 19 时活动。暴雨、雷暴、冰雹、暴风雪和沙尘暴会让鸟虫一起隐去。萤火虫还要满足实时气温至少 14°C、当地该月夜间气候温暖、雨量充足，以及落点的土壤湿度条件。

## 试玩

1. 第 2 版世界，晴天白天到梯田，打开开发者面板「生灵」，看当前档案、月份、附近数量。选燕类，点「召来所选物种」，再点「恢复自然分布」。
2. 到林缘或路旁停住，找栖在电线或枝头的小鸟，走近看它起飞。在花田贴近花丛，在湖岸顺着水面看。召来仍需合适的地点与时段。
3. 把天气改成雷暴，附近数量应为零。到雪山把时间拨到深夜，也应为零。

## 实机验收

- 真显卡 RTX 5060 Ti，1920 × 1080。截图在本工作树 `loop/shots/m5-life/`，每张 PNG 同名的 JSON 记着区域、月份、坐标和实例数。燕群 `birds`、卡拉鹰 `raptor`、天鹅 `waterbird`、草甸斑蝶 `butterflies`、静水蜻蜓 `dragonflies`、萤火虫 `fireflies`，以及雪山空夜 `snow-pass`。
- 卡拉鹰、天鹅、萤火虫这三张，实机脚本在开局前用正常区域接口注册了相应研究档案，借用已有地形，并采用原型六月的日夜气温。萤火虫画面实测 15.6°C。普通路线仍只有旧版地貌；这三张用于验证生灵接入新地理区域后的表现。旧枫林的固定夜温偏低，萤火虫在此会被天气条件挡住。
- 驾驶视角实测整帧 13.79 ms。相机平移穿过格子时，生灵 CPU 平均 0.012 ms、P95 为 0.10 ms、最高 0.30 ms。独立 GPU 计时查询测生灵批次每帧 0.0012 ms，测量时画 28 只，移动期间最多 44 只。详见同目录 `timing.json`。
- `harness/sim/m5_life.test.ts` 的 6 项覆盖地域、南北半球月份、时段、天气、水陆栖息地、环绕格、回访位置、实例数上限和稳定帧堆分配。全部 110 个测试文件通过，2,086 项通过、4 项跳过。类型检查和生产构建通过。

## 接线与扩充

`src/core/v3/life/rules.ts` 按物种名称定义轮廓、翼展、行为、栖息地和配色。新增一行后，只会在生态档案也列出该物种时出现。游戏侧 `src/game/modcar/v3/life/` 由模块系统自动发现。鸟和虫各用一圈 5 × 5 格，鸟格 32 米，虫格 7 米，每帧最多补一个待更新的格。几何由程序构造，同种共用实例批次；翅膀在顶点着色器里扑动。

尚待正式路网接入更多研究区域与逐月实际气温。生态档案里还有大型地栖鸟、蝉、蚊蝇、草蜢、蜣螂等未建模。现有 25 份档案没有鸭类记录。
