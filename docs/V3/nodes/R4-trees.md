# R4 树：每种树自己的形状，各生态系统自己的树

方案：`plan/scenic-roads.md`。上一步：`R3-structures.md`。

## 一句话

以前世界里十三种阔叶树都按橡树的样子长，只是颜色不同。现在每种都有自己的形状：
- 椴树：高圆冠；
- 山毛榉：灰白光干上一个宽而低的圆冠；
- 白蜡：高干上的疏冠；
- 欧洲栗：粗干宽冠；
- 香樟：常绿的宽圆冠；
- 马鲁拉：稀树草原上矮干宽冠；
- 南青冈：一层层平展；
- 胡杨：虬曲的乱冠。

另外新做了六种生态系统里缺的树：
- 雨林露生巨树：板根、三十多米的高干、平顶的大冠，雨林里的大树；
- 榕树：低而极宽的冠，从枝上垂下气生根；
- 南洋杉：层层的烛台枝；
- 帕拉莫的毛叶菊：毛茸茸的巨型莲座顶在一根粗茎上；
- 荒漠的蜡烛木：一丛长鞭；
- 热带开花的凤凰木（红）和蓝花楹（紫）。

## 做了什么

| 部分 | 做法 |
| --- | --- |
| 阔叶树的形状 | `scene/flora/catalog.ts`：八组新的圆冠阔叶参数，按 Painted Valley 长树的规则：粗干、几根大枝、一团团冠，冠是一整块，不是碎片。 |
| 新树形 | `scene/flora/trees4.ts`：雨林露生巨树、榕树、毛叶菊、蜡烛木、南洋杉。 |
| 家族对上 | `scene/crowns/species.ts KIT_OF`：椴、山毛榉、白蜡、栗、香樟、雨林巨树、马鲁拉、榕、南青冈、胡杨，各对上自己的形状。新家族有：毛叶菊、蜡烛木、南洋杉、龙血树、凤凰木、蓝花楹。 |
| 植物和颜色 | `core/world/plants.ts` 末尾加了六种植物，`crowns/palette.ts` 加了它们的颜色。凤凰木和蓝花楹的树冠就是花，按"花色"进色调盘，不会被拉成绿色。 |
| 谁长在哪 | `world/earth/flora.ts`：<br>• 帕拉莫等热带高山的巨型莲座是毛叶菊，干旱地方的是龙舌兰；<br>• 热带的多浆树是龙血树和约书亚树；<br>• 热带开花的树是凤凰木和蓝花楹；<br>• 热荒漠的刺灌里有蜡烛木；<br>• 层叶针叶林里有雪松和南洋杉。 |
