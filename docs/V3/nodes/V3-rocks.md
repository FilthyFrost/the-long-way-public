# V3 石头和岩壁

方案里这一步的目标：程序化的石头（凿出来的面、圆角、顶上长苔藓或积雪），陡坡上露出岩石，每种地貌有自己的石头。

## 以前的问题

- 路边的石头都是五到七条边的棱柱，顶上收成尖。远看像一簇簇水晶碎片，黑峡的深蓝色"碎片"最明显。
- 散在草里的"大石"和"石块"是二十面体，同样像水晶。
- 熔岩地和火山渣锥的地上，石头跟别处一样是浅灰的圆石，看不出熔岩。
- 石头的多少不跟地方走：除了水边和陡坡，大约四十个格子才有一块，熔岩地、冰碛、花岗岩石蛋堆和草地一样空。

## 现在的石头（`scene/chiselRock.ts`）

每块石头的做法是：先捏一团略不规则的石胚，再用几刀平面"凿"掉多出来的部分，凿出平的面；底部切平、埋进土里一点。法线按顶点算，所以凿面是平的，面和面之间的棱是圆的（材质 part 6）。Painted Valley 的石头也是这样做的："一团疙瘩，敲掉几个平面"。

不同的岩石有不同的样子：

- **大石：** 一团石胚，凿六刀。
- **花岗岩：** 圆润的石块，只凿三刀，而且凿得浅。
- **冰碛：** 介于大石和花岗岩之间。
- **层状岩（砂岩、页岩）：** 水平方向下刀，所以有平顶和一层层的台阶。
- **岩鳍：** 竖着下刀，形成立着的薄板。
- **石灰岩：** 立着的塔，侧面有九道竖向的溶沟。
- **熔岩块：** 凿十七刀，表面再加一层细碎的起伏，面保持硬朗，颜色接近黑、略带暖。熔岩地和火山渣锥的地上全是这种石头（`core/world/earth/profile.ts`）。

**玄武岩柱群**（`scene/paintedStones.ts` basaltColumns）：六角形石柱按蜂窝排列，柱顶是略微倾斜的平面，近看柱顶边缘有一圈倒角能接住光。高的柱子半腰有一道横向节理，上面那段稍细一点，留出一道暗缝。每根柱子的明暗略有不同。有三种形态：

- 中间高、四周低的一簇；
- 一侧高的台阶状（像崖边断开的柱子）；
- 一片矮柱桩，脚下躺着一两截倒下的柱段。

**散在草里的大石和石块**（`scene/plantModels.ts`）也换成了凿出来的石头。

## 石头的多少跟着地方走

`core/world/earth/profile.ts` 里新加了 rockinessOf，按生态和地貌给每个地方定一个"多石程度"：

| 地方 | 多石程度 |
|---|---|
| 熔岩地、火山渣锥、柱状玄武岩 | 0.85 |
| 火山、冰川谷、冰碛湖、角峰、鼓丘 | 0.55 |
| 光秃地 | 0.5 |
| 花岗岩石蛋、岛山、石林、石柱、劣地、雅丹 | 0.5 |
| 苔原 | 0.42 |
| 荒漠 | 0.38 |
| 峡谷、方山、陡崖、海崖等 | 0.3 |
| 灌丛 | 0.22 |
| 草原 | 0.1 |
| 森林 | 0.07 |

- 石头成片出现，每片几十米：这里一片乱石，那里一片空地（`core/world/groundField.ts`）。
- 多石的地方，大约八块里有一块是大石，有普通石头的两到三倍大。
- 多石地方的陡坡上，碎石中间会露出成块的岩头，比周围的石头大 1.5–2.3 倍，并且顺着坡面躺着（`core/world/rockTables.ts`）。

## 多花的面数和省回来的

- 只有大石和花岗岩近处的主石块用细一级的石胚（180 个三角形），其余都用 80 个三角形。
- 碎石从 12 块减到 10 块。
- 远处的石灰岩塔只画一块。
- 玄武岩柱：只有近处内圈的柱子有倒角，倒下的柱段也只在近处画。
