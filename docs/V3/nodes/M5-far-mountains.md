# M5 驾驶窗里的远山

种子 7，324.35 km 向左看。原来的白色山墙从峰顶一直糊到山脚，偶尔藏在云后。现在能顺着暗灰色的岩沟往下看见雪舌，再往下是针叶林和谷底。这个机位的前后长焦图最容易看清差别。

**一个实际渲染问题。** 版本 2 的地形网格带着海拔，驾驶场景创建材质时却只开启了地表覆盖，没有开启海拔分支。雪线、林线以及远景空气都没有使用已经写好的版本 2 算法。现在道路和地形启用同一分支，远景的地形块也继承它。

**山壁怎么画。** 从约 1 km 开始，让粗岩面在向光和背光之间多一道半明部，岩沟朝下分叉，沟内迎光一侧留雪。岩面纹样固定在世界里；车开近只改变笔触的强弱。林线以下，按当地已有的林冠密度画成片的树冠，高处的小亮面在雪区变成覆雪的树梢。林线和雪线沿用该地区的海拔设置。

现有地区从生态资料里的对应公路取岩石比例。雪山用落基山口的花岗岩，红峡谷的砂岩以水平层面为主，喀斯特的石灰岩沟纹较直，索诺兰山前的火山岩使阴面偏暗。资料中的火山岩记录为山前棱石；本轮没有在这条路放置独立火山锥。

**山脊怎么叠。** 路外约 7.8 km 开始出现斜穿主山脊的次级褶皱，延伸到原先的远山。鞍部能露出后方峰顶。中距离仍保留岩色，更远的山逐渐转蓝，低处积雾，在原有 90 km 地平线前收尽。地形生成仅改 `greatRange`；版本 2 修订号为 7，参考世界已经重录。

## 实拍与耗时

RTX 5060 Ti，GPU 锁内，1920 × 1080，晴天 15:30。每个驾驶位预热后连续渲染 40 帧，每帧等 GPU 读回。毫秒数为平均和 P95；CPU 为测试期间整台机器的平均占用。

| km | 窗外 | 原平均 / P95 | 新平均 / P95 | CPU 原 / 新 |
| --- | --- | ---: | ---: | ---: |
| 80.62 | 红岩台地 | 8.56 / 10.3 | 10.20 / 13.1 | 33% / 26% |
| 138.04 | 冻湖与对岸林坡 | 10.95 / 13.2 | 11.25 / 13.9 | 26% / 26% |
| 190.30 | 湖岸与后山 | 13.07 / 15.3 | 13.61 / 15.3 | 36% / 22% |
| 324.35 | 积雪山脊 | 12.24 / 14.9 | 12.55 / 14.9 | 25% / 28% |
| 44.75 | 平原对照 | 12.40 / 14.8 | 12.99 / 15.2 | 22% / 25% |
| 350.55 | 密林对照 | 20.08 / 25.0 | 21.12 / 27.1 | 23% / 24% |

四个山景样点的 P95 均在 16.67 ms 以内；密林仍超出预算。这是固定驾驶位的渲染计时，尚未包含行车时加载新地块的尖峰。

配对图片在本工作树 `loop/shots/m5-far-mountains/{before,after}/`，驾驶位以 `_seat_15h5.png` 结尾，`alpine_vista_long.png` 是同机位以约 2.67 倍倍率重新渲染的局部，`shots.json` 记录帧时与 CPU。
