# V1 光与色

视觉迭代的第一个里程碑（`../plan/visual-loop.md`）。2026-11-21。

## 做了什么

**不再连开一小时雪地。**
- 原因：北方针叶林的最佳月份是 1 月，旅程一经过就被拉进隆冬。冷的大陆性气候冬天零下十几到二十几度，一路十几个地方全是雪。
- 改法：最近六个地方里已经有两个下雪，这个地方又会被雪盖住时，季节就往 7 月走，每个地方走三个月（`core/earth/director.ts` SNOW_RUN）。
- 结果：前 60 个地方里，种子 1 从 15 个雪地降到 2 个，种子 3、7、11、23 各有 1–5 个。

**夜里。**
- 天比地亮，地上的东西是天空下的剪影。夜里的曝光从 2.6 降到 1.7，天空、云、雾的颜色重新配过（`specs/art/style.json` −18° 那一档）。
- 地上暗的部分偏向蓝灰，就像人眼在夜里看到的样子；天空和灯光保持原色（`render/frame.ts` uNight）。
- 星星分三层：亮的少，暗的多，各有冷暖颜色，靠近地平线闪得更明显。银河有亮核、偏紫的旋臂和中间的暗带。地平线上有一层很淡的青绿色气辉。
- 星空一夜转一圈。晚上九点半左右，银河的核心在车头方向的低空，从挡风玻璃里就能看到（`env/sky.ts`）。
- 月亮六天一个周期（`core/env/time.ts` MOON_DAYS）：
  - 只有亮的那一面发光；
  - 新月看不见，满月有月晕；
  - 照在地上的月光跟着月相走，新月夜只有星光。
- 流星：平常夜里偶尔一颗；每三晚有一晚流星雨，都从同一个辐射点飞出来。
- 每个地方有自己的夜空（`core/world/earth/palette.ts` air.night）：
  - 空气越干燥、越高，星星越亮，湿热带和海边暗一些；
  - 靠北的冷地方有极光，是挂在北边天上的帘幕，下沿绿色，上沿紫色。
- 晴天的积云跟着气温走：早上少，下午最多，日落后散去，晴天夜里能看到星空（`env/environment.ts`）。

**清晨和傍晚。**
- 太阳低的时候，阳光是完整的金色，比阴影亮得多；阴影偏紫蓝，暖光和冷影拉开（`render/shaderlib.ts` rtLowSun、rtGroundLight）。
- 太阳一碰到地平线，阳光就从低处退走，往高处爬：低一度时只照到比视线高 400 米以上的地方，低两度时要 1200 米以上。到最后只有山顶亮，也就是高山红（`shaderlib.ts` uEarthShadow）。
- 日落前后，背对太阳的天边有一条蓝灰色的地球阴影，上面是粉色的维纳斯带（`sky.ts` uBelt）。
- 日落后，背对太阳的雾偏紫蓝，不再整片发粉。

**白天。**
- 晴天的积云也会在地上投下影子，影子随风移动（`environment.ts` uCloudShadow）。
- 最后一道调色：饱和度从 1.06 调到 1.14，以中灰为中心加一点对比，暗的更深，亮的更亮（`frame.ts` uContrast）。
