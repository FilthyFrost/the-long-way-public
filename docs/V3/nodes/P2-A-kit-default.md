# 里程碑 2-A：世界里的树默认由工具箱长

2026-11-20 夜。审批 B 按推荐通过以后的第一步。

## 做了什么

- **默认就是工具箱的树**：世界里 55 个树种家族，现在全部由工具箱长（`scene/crowns/species.ts` 的 `KIT_OF`）。
  - 原来的长法留着对照：地址里加 `?flora=m5`。
  - 性能检查和截图脚本跟着改：`perf_gate.mjs --m5`、`p3_kit_world.mjs` 的 world 一栏是原来的长法。
- **补上最后 4 个家族**（`scene/flora/trees3.ts`）：
  - **红杉**：树干粗、根部有棱，下面四成光秃，上面是一根窄柱子一样的树冠，枝条短、下垂；
  - **陆均松**：几根向上的枝从短干上伸出，每团细叶都垂成长长的穗子；
  - **约书亚树**：粗壮的干分两三次叉，叉的角度不规则，每根枝的尽头一团硬叶；
  - **智利火焰树**：照樱花的长法，用它自己的颜色（红花）。
- 都在面数预算内：红杉近处 1,800、中档 500；陆均松 1,754、500；约书亚树 1,616 左右、600。

## 结果

| 地点 | 树的三角形（原来 → 工具箱） | 绘制次数 |
|---|---|---|
| 森林 | 0.06 → 0.05 百万 | 245 |
| 草原 | 0.08 → 0.07 | 300 |
| 雪山 | 0.04 → 0.03 | 209 |
| 雪山远眺 | 0.05 → 0.04 | 222 |
| 湖区 | 0.13 → 0.09 | 356 |

- 实际开 3 公里：7 种树都在后台长（每种 21.8 毫秒），56 张远处照片都在后台烘；游戏自己每帧的工作平均 3.9 毫秒。
- 帧时还是不作数：显卡一直被另一个程序占着。
