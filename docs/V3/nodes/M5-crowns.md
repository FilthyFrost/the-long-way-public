# M5 远处的树冠

森林驾驶位每帧从 17.64 毫秒降到 11.07 毫秒，离 60 帧的预算还有约 5.6 毫秒。三次测量中一次达到 11 毫秒目标，另外两次稍高。

## 做了什么

- 八个树种族，每族两个变体。用原来的远级模型和叶片笔触，从水平方向绕树取十六个角度。每个像素记下最前面的树皮或叶子、法线、深度和受光的开敞程度。画远树时每棵只用两个三角形，混合相邻角度。林色、秋色、雪、云影、雾和最后一道笔触沿用树冠材质。
- 乔木通常在 70 米和 200 米左右交接。交接带里的两个模型按互补的像素图案淡入淡出。密林内部提早交接，灌木按自己的距离交接。最远一级地块也接入这套画法，并沿用原先的疏密。
- 近、中级省去埋进相邻叶团深处的叶片。先画已有的遮挡物，再从近到远画树冠；近、中级在顶点算对数深度，让显卡可以提早跳过被挡住的像素。保留原来的叶缘裁切和树冠笔触用的透明度 0.85。
- 树在绘制批次中保留自己的位置。跨级、进出视野和原点迁移时更新相应实例。整块都在远处时只检查地块边界。宽阴影图用原来的远级立体模型，并剔除阴影方向也完全朝视野外的树。

## 怎么测的

RTX 5060 Ti，1920×1080，种子 7，15:30。用 GPU 锁独占显卡，运行 `harness/shots/v3_slice.mjs`；同一驾驶位连续绘制并等待读回 40 帧。改前测一轮，改后测三轮，表中取改后中位数。脚本强制调用裁剪更新，车辆位置固定。

| 地点 | 改前（毫秒） | 改后（毫秒） |
| --- | ---: | ---: |
| 草原 | 13.78 | 10.24 |
| 森林 | 17.64 | 11.07 |
| 雪山远眺 | 16.74 | 10.78 |
| 湖区 | 11.77 | 8.33 |

森林三轮分别为 11.28、10.98、11.07 毫秒。四处的驾驶位、跟车图及逐轮数据在 `loop/shots/m5-crowns/{before,final1,final2,final3}/`。同一段远林的原尺寸裁图分别在 `before/forest_far_crop.png` 与 `final3/forest_far_crop.png`。树梢与林带的冷暖层次保留，放大可见个别枝叶的位置有差别。

测试覆盖图集逐字节可复现、四级散布的植物身份逐一对应、两次细节交接的方向和渲染原点迁移。全套测试 2,054 项通过，4 项跳过；类型检查与生产构建通过。

## 待验收

森林稳定低于 11 毫秒仍待验证。十六个角度针对道路上的近平视视线；陡峭俯视、全天光照变化和连续驾驶时的交接仍需动态目检。
