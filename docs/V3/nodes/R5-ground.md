# R5 地上的植物

方案：`plan/scenic-roads.md`。上一步：`R4-trees.md`。

## 一句话

地上加了五种以前没有的植物，各长在自己的生态系统里：
- 稀树草原一人高的象草；
- 丘状草稀树草原和荒漠的刺鬣草团（以前画成普通丛草）；
- 苔原、高山、帕拉莫的垫状植物（以前画成苔藓地毯）；
- 盐漠的盐生灌丛；
- 热带雨林和热带林下的大叶草（芭蕉、海里康那样的大叶）。

岩石本来就按岩性分了九种形状：
- 花岗岩是圆石；
- 玄武岩是柱状块；
- 石灰岩是竖沟孤峰；
- 砂岩、页岩是层板；
- 冰碛是砾石；
- 另外还有岩鳍、碎石坡、河滩卵石和普通巨石。

R1 让它们跟着每个地方的光色变。

## 做了什么

| 部分 | 做法 |
| --- | --- |
| 新的地上植物 | `scene/flora/ground.ts`：<br>• 象草：一人高的丛草；<br>• 垫状植物：贴地的紧实半球；<br>• 盐生灌丛：灰绿的矮灌；<br>• 林下大叶草：从一个根上伸出五到八片带柄的大叶，叶尖下垂。<br>`scene/flora/catalog.ts` 记进工具箱。 |
| 接进地面 | `groundTables.ts` 加了这些植物，`crownData.ts GROUND_KIT` 让工具箱来长：刺鬣草团用早就做好但没接上的那个。<br>`world/earth/profile.ts`：<br>• 稀树草原的高草是象草，丘状草是刺鬣草团；<br>• 热带林子的地上多一种林下大叶草；<br>• 盐漠的灌丛里多一种盐生灌丛。 |
| 颜色 | 象草、刺鬣草团按草取色，垫状植物、大叶草、盐生灌丛按叶子取色，都在各地的色调盘里（`groundField.ts earthClump`）。 |

## 数字

- 新植物都在面数预算内；全部测试 2364 项通过。
