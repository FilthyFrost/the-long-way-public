# M5 公路边的树

玩家希望从车里就能看出各地长的树有什么不同。此节点把旧模型和新地区要用的树种一起放进手绘树冠系统，共 53 个模型族、108 株样树。每株有近、中、远三套网格。

生态原型清单里的 11 项均有模型。地理布设由地区植物表按名称引用；研究文件中的待建列表保留其原始调查记录。

|模型族|代表树与生境|轮廓|
|---|---|---|
|southern_beech|澳洲、新西兰和南美的南方山毛榉|湿谷高冠、密圆叶冠和受风矮曲冠三个变体；落叶种有橙色秋相和冬枝|
|douglas_fir|北美西部山地的花旗松|长灰褐干、深绿色层枝|
|palo_verde|索诺兰的帕洛维德|光滑黄绿干，树叶细而稀疏|
|mesquite|索诺兰的牧豆树|近地分枝、低伞冠，叶下挂褐色细豆荚|
|lemon|地中海梯田果园的柠檬|修剪状矮圆冠、油绿叶，小黄果在结果实例出现|

|marula|南部非洲稀树草原的马鲁拉|灰干，圆形羽状叶团间能见天空|
|blackwood_acacia|澳洲湿润沟谷的黑木相思|直干，暗绿细叶，树梢微动|

## 模型和接入

阔叶树和针叶树沿用样板段的暗色叶团核心和外圈叶片。大枝、枝轮和叶团的种子固定。特形植物直接长出有折线的叶片或有棱的茎，用游戏原有的明暗色带、风和雾。果树的果色取自可采植物自己的色表。地区表给的是植物名，绘制时先找具体树，例如枫树和栎树过去共享 broadleaf，现在各取自己的枝形。世界仍负责位置、树高、尺寸和采集物。

需要冬树时，取 `SPECIES[family].variants[variant]` 的 `grow` 和 `seed`，调用 `growSpeciesModel(grow, seed, level, true)`。它生成枝架和空梢，落叶松也可这样生长。摆放时沿用有叶模型的原始高度和比例，可避免落叶后树干变大。何处换冬树由雪区工作接入。

## 怎么看

- `harness/shots/m5_trees.mjs` 用游戏的树材质、光照和画面后处理拍平地样树。18 米处逐族拍全部变体，60 米和 200 米处分组拍，另有秋色和雪地行。文件名从左至右列出树族，族内从左至右为各个种子变体。
- `loop/shots/m5-trees/lineup/rows.json` 是 143 张排阵图的目录。驾驶图和计时数据在上一级的 `shots.json`。拍摄种子 7，15:30，晴，1920×1080。
- 看草原 44.75 公里的散生树、森林 350.55 公里的针阔混交、荒漠 86.05 公里的柱形仙人掌、枫林 393.05 公里的秋色。驾驶图名分别以 plains、forest、desert、maple 开头，seat 为座舱，chase 为车后。
- 树冠测试逐变体检查同种子重建的顶点、三档面数、阔叶团与树枝的距离，以及地区乔木表的模型覆盖。单株面数上限依次为 6,500、1,800、1,100；小灌木为这些数的四成。

### 实机帧时

RTX 5060 Ti 独占测试锁，同一位置重复绘制 40 帧并读回像素。草原、森林、荒漠、枫林的平均帧时分别为 15.79、18.78、9.57、14.53 毫秒。森林未达到每帧 16.67 毫秒目标，画面中有 1,602 株树冠，其中第三档有 1,445 株。合入远树替身后还需重测，这组定点均值也不能代替连续行驶的帧时分布。
