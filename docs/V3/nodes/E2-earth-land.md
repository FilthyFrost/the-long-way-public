# E2 地貌和岩土颜色

方案：`plan/emergent-earth.md` 第五节；上一步：`E1-earth-world.md`。

## 一句话

导演给每个地方选的地貌（55 种），现在用游戏地形函数自己的部件真的做了出来：路边的锚定地形（塔、方山、火山锥、圆丘）、四种沙丘、梯台、每段地势的种类和强弱、山丘、山谷两侧的山墙、天际线上的方山。尺寸按这个地方的起伏来定。颜色跟着岩土走：白色石膏、金色石英沙、红砂岩、黑玄武岩、白盐壳、彩色流纹岩。方案里列的 12 种荒漠，在生成的旅程里都找得到，游戏里也都看得出来。

## 做了什么

| 部分 | 做法 |
| --- | --- |
| 地貌 → 地形 | `world/earth/landform.ts landOfPlace`：55 种地貌每种一份做法，平地类的 4 种除外（平原、丘陵、高原、山坡）。用的是地形函数现成的部件，没另起一套。 |
| 锚定地形 | `features.ts` 加了"圆丘"（dome，一整个弧面，最陡 1.5×高宽比）。和原有的塔、方山、带火山口的锥一起，摆出这些：雅丹（拉长的低脊）、鼓丘（拉长的圆丘）、冻胀丘、峰林、峰丛、石柱峰林、石林、火山渣锥、层状火山（几千米外的一座大锥）、火山口湖、方山与孤峰、桌状山、花岗岩岛山、石蛋、丹霞、石柱与烟囱岩。所有的都守高度场的规矩：离路中心线 34 m 以内不放、坡不陡过 2:1、脚下和顶上坡度为零。 |
| 沙丘 | `operators.ts dunes` 加了三种形状：纵向沙垄（顺风的长脊，两坡一样）、星状沙山（三组沙丘交叉成的金字塔）、新月形沙丘（平地上一弯一弯的、互相隔开）。原来的横向沙丘不变。远处地形粗的地方，用每种形状实测的平均高度代替。 |
| 地势的种类 | 峡谷、瀑布峡谷、劣地、柱状节理有峡谷壁；曲流河谷、河谷有谷壁；单面山、断崖是一边高的坡；海崖是路在崖顶。钙华梯池用梯台。山地的路几乎都在两侧有山墙的山谷里。冰川地貌（U 形谷、角峰、冰川、冰碛湖、峡湾）一路都是山谷。 |
| 山墙和远景 | U 形谷底宽 450 m、墙陡；角峰墙更高，远处山脉高三成；裂谷底宽 1.4 km。方山、峡谷、桌状山在天际线上加上第 1 版的方山远景，高度是起伏的一半。 |
| 颜色 | 岩石决定地面和岩壁的颜色。砂岩、页岩是层状的，石灰岩、白云岩半层状。盐和石膏上什么都长不出来，地面露出白色。积雪的地方地面是白的。秋天的落叶林有秋色。 |
| 植物表 | 地球区域的植物表就是它自己生态卡的，不再按采集档案删改（以前冷荒漠会多出巨柱仙人掌）。 |
| 规则修正 | 积雪统一一条规则：这个月均温低于 −1°，或生长季不化冻（`climate.ts snowAt`）。导演的"雪"和世界的雪线现在一致。荒漠、半荒漠的卡（T5、刺鬣草稀树草原）一律当荒漠类，哪怕雨稍多一点也不画成青草地。 |

## 已知不足，留给后面

- 锚定地形是高度场能表达的形状：海蚀柱、天生桥、柱状节理的柱子这些悬空或直立的东西，要做成带碰撞的模型，以后再说。
- 雅丹、石蛋、鼓丘比较矮，从驾驶位看不太显眼。
- 盐沼雨后的镜面、冰川舌、熔岩的质感，要靠材质。E6 和以后的材质工作做。
- 天气和光还没跟着地方变（E6）。
