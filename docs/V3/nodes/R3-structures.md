# R3 路上的构造：护墙、观景台

方案：`plan/scenic-roads.md`。上一步：`R2-roads.md`。

## 一句话

每种景观路有自己的路面和路边：
- 傍山路、盘山路、垭口路、峡谷路、冰川谷路，外侧是石砌矮护墙；
- 海崖路是贴海的石护墙；
- 河谷、湖岸、海边、沿河路是公园路的样子：草路肩、木护栏；
- 丘陵、田园小路是乡间小路：栅栏；
- 林荫道是砂石路。

有景可看的路，在景色最好的那一段放一个观景台，外伸在悬崖或山谷边上。观景台上有护栏、望远镜、长椅、桌子和路牌。

## 做了什么

| 部分 | 做法 |
| --- | --- |
| 路面和路边 | `core/earth/roads.ts ROAD_BUILD` 给每种路型一种路的样式（`world/roadStyles.ts` 新加了山路、海崖路、公园路、乡间小路、砂石路），`RegionDef.roadStyle` 记在区域上，`roadStyleAt` 先看它。护栏照原来的规则立：路边往下掉、急弯外侧、桥头、水边。现在山路和海崖路的护栏换成石砌矮墙。 |
| 观景台 | 傍山路、盘山路、垭口路、山脊路、海崖路、峡谷边缘路、梯田路的指定那一段（`RegionDef.lookouts`），路边地方的位置先给观景台，排在加油站前面，加油站推到后面能放下的地方。<br>观景台只放在有景的那一侧：傍山路外侧、峡谷边缘那一侧、海的那一侧。<br>它可以外伸在落下去的地面上（`sites.ts fit` 的 brink：外侧往下掉不算挖填）；路可以有弯（曲率到 1/45）、有坡（到 8.5%）。 |

## 数字

- 3 个种子、38 个有景可看的地方里，32 个有观景台。没有的那几个，那一段是河、湖或盘山急弯。
- 全部测试 2348 项通过。
