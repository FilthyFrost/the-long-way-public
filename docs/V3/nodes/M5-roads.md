# M5 随地区变化的路

草原的碎石封层路边是牧场木栏，林区常见补过的柏油和木护栏，湖区有压实的砂石路。峡谷和荒漠有土路，沙会漫上路边。高山公路有清晰的边线、钢护栏和路肩外的积雪。梯田、竹海和喀斯特路段可见浅色混凝土板、伸缩缝和石墙。商店与民宅前的小段铺石路带路缘石，出入口留空。桥面沿用桥梁自己的栏杆，牧区偶有横跨车道的牲畜格栅。

## 如何生成

`roadStyles.ts` 按地区编号选常用与次用铺装，同一区域内每 768 米有一次换样式的机会。村道根据实际商店或住宅的位置选择。路面半宽 2.78–3.25 米，车道贴图和轮胎读取同一段的宽度、路肩与表面。砂石和泥土分别使用各自的摩擦、滚阻和粗糙度；修补路和石板使用硬路面参数。路面中心线沿用原来的道路。第 2 版的生成修订号为 9，已录制对应的世界轨迹。

木栏、石块、格栅与路缘石在每个加载路段合成一次实例化绘制。石墙和木栏沿用有碰撞体的护栏段；已有反光柱、里程石和桥栏沿用原有批次。
