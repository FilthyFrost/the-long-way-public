# V7 生灵

方案里这一步的目标：更多的鸟群、蝴蝶和虫，水里有鱼。

## 审片时看到的问题

- **天上几乎是空的。** 路边的生灵（`game/modcar/v3/life`）只管车周围：鸟在 310 米见方的 25 个格子里，只有四分之一的格子有鸟，通常六群上下；会成群飞的燕子、雨燕一群 14–26 只，栖在树上、电线上的大多只有一只。远处的天上一只鸟也没有。
- **虫只在 35 米以内**，每格两只，花田里的蝴蝶稀稀落落。
- **水里没有鱼。** 河、湖、路边的溪流、浅海里一条都没有。

## 改了什么

### 天上的鸟群（`scene/skyFlocks.ts`，新）

按地方、季节和钟点，远处的天上会有这些鸟群：

| 鸟群 | 什么地方、什么时候 | 样子 |
|---|---|---|
| 椋鸟群舞 | 开阔地和湿地，冷的半年，黄昏和清晨 | 250–600 只聚成一团，在空中拉长、折叠、翻滚，慢慢飘 |
| 雁阵 | 水边和开阔地，春秋两季迁徙时（苔原的夏天也有），白天 | 12–40 只排成人字，高高地慢慢横过天空，两翼像波一样起伏 |
| 海鸥 | 海边（大湖也有一些），白天 | 十几二十只顺着风盘旋，滑翔多、扇翅少 |
| 雨燕 | 暖和的地方，5–8 月的早晚 | 深色的月牙形，在高处兜着圈子乱飞 |
| 白鹭 | 暖和潮湿的地方，傍晚 | 一行白鸟低低地飞回去 |
| 鹦鹉 | 暖和的林子，白天 | 一小群鲜绿的鸟快速飞过 |
| 渡鸦 | 荒漠、高山、灌丛 | 几只黑鸟在空中盘旋 |

- 每群从视线前方几百米处出现，横穿天空，飞远到身后或待够一阵就消失，之后再来下一群；同时最多三四群。
- 下雨、下雪、起雾、大风时不出来。
- 所有鸟群的鸟一次绘制：每只是两片翅膀组成的人字形，按自己的节奏扇动（海鸥、渡鸦大多平展着滑翔），朝着自己飞的方向。
- 远处的鸟画出来至少有四五个像素宽：按真实大小，五百米外的椋鸟比一个像素还小，一群鸟会变成一层看不见的灰。这样远处的鸟群是一团看得出来的鸟，和画家画进画里的一样。
- 深色的鸟在天空下是剪影；白色的鸟（海鸥、白鹭）被太阳照亮；远的被大气的雾淡化。

### 路边的鸟、蝴蝶和蜜蜂更多（`game/modcar/v3/life/system.ts`）

- 有鸟的格子从四分之一提到一半。
- 有花的地方，蝴蝶一格 3–5 只（原来 2 只），蜜蜂 2–4 只。

### 水里的鱼（`scene/fishView.ts`，新）

- 车周围 160 米见方的范围里，每个 18 米的格子中间如果是浅水（河、湖、路边的溪流、浅海，水深 0.4–6 米，没结冰，不在桥下、不在漫水路面上），四分之三有一群鱼，5–14 条。
- 鱼按水和气候来：冷水河里是暗橄榄色的鳟鱼，暖水湖里是金褐色的鲤鱼（偶尔一条红白的），海里是蓝灰色的鱼，热带的海里是蓝、黄、橙、青的小鱼。
- 鱼群在水下慢慢兜圈，整群一起游走，尾巴摆动。
- 每群每隔十几二十秒有一条跃出水面：银色的鱼沿着弧线竖着跳起来再落回去，离开水面和落回水面的地方各溅起一圈白色的水花，水花圈的边是碎的。
- 鱼画在水面上一层：水面会写深度，第一版放在水面下两厘米，全被挡掉了。现在用深色、半透明、带水色的样子画出"水下的鱼影"。
