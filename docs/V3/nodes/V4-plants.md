# V4 植被

方案里这一步的目标：草长高长密到 Painted Valley 那样，有成片的花海；森林分大树、小树、灌木三层，每棵树都不一样；先腾出显卡余量，再加密度。

## 审片时看到的问题（整条审片路线，下午 15.5 点）

- **常绿阔叶林（樟河、樟洲、玉悬）从路上看是一堵暗蓝绿的墙。** 它们的"深绿"是所有树色里最暗、最灰的。针叶林的"青绿"也一样，向阳的一面都显得像阴影。
- **林区路边的草是一片平整的"草坪"。** 这些地方的地被是蕨和苔藓，草的密度被直接压到 13%。树林底下这样没错，但空地和路肩也被一起压掉了，只剩地面的颜色。
- **林子是"草坪上的树干"。** 新地球的地方，林下灌木一棵都没画：之前的规定是"林下的观赏植物由地被表提供"，可地被表里只有蕨、苔藓，偶尔一丛林缘灌木，每公顷 4 丛。
- **最贵的是远处的树牌。** 森林测点画了 3500 多张远处的树牌，每张都在像素里写自己的深度，所以显卡的提前深度剔除失效了：被山挡住的、被别的树挡住的也照画不误，用掉 1.3 ms。

## 改了什么

- **远处的树牌不再自己写深度**（`render/crownMaterial.ts`）：树牌都在 200 米外，用牌子本身的深度就够了。这样显卡能提前剔掉被挡住的部分，1.3 ms 降到 0.6 ms，省下的时间用来加密度。
- **常绿林和针叶林的颜色**（`core/world/earth/palette.ts` KEYS）：
  - 深绿：亮度 0.53 → 0.625，彩度 0.092 → 0.12，色相往黄绿偏了 15°；
  - 青绿：亮度 0.52 → 0.585；
  - 结果是向阳的一面是绿色而不是阴影，背光的一面仍然深。
- **林下三层**（`core/world/earth/flora.ts`）：
  - 林冠下长出小树：用这片林子的第二种树（没有就用第一种），长到成树的 38–62%，数量是成树的三分之一；
  - 林子的灌木翻倍：郁闭林每公顷 110 丛，疏林 100 丛，林地 80 丛，范围从林缘一直到林冠下；
  - 新地球的地方现在会画林子里那些"画出来的"灌木（`scene/floraScatter.ts`），只画近处。
- **林区的空地和路肩长草**（`scene/worldBuild.ts`）：地被是蕨和苔藓的地方，林冠下的草照旧只有 13%，林冠越开越接近满密度。
- **草地高了一些：** 默认从 0.42 米提到 0.52 米，到膝盖。
- **野花多了一半：** 开阔的地方（草原、稀树草原、林地、疏林、灌丛、苔原）每种野花的量从 0.04 提到 0.065。

## 没做、留到后面的

- 樟翠（峰丛）的山还是光秃的绿色，看不到树，归到 V5 地貌主角。
- 近处的树一共 20 多棵，却要 1.2 ms，原因是叶片层层重叠。可以先只画深度、再上色来省掉这部分，等以后加更多近处的树时再做。
