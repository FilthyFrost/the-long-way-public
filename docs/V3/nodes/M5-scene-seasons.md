# M5 地区自己的季节

停车过夜只改变日照、天气和旅程天数。沿路进入另一片地区才会逐渐进入它的时节。地被与鸟虫按所在位置取月份，开花、结果和落叶按每株树的位置取月份；积雪先按各地自己的月份和海拔计算，再混合两侧雪量。降雪和融雪仍能临时改变覆盖。跨年时按较短的方向过渡，例如从十月枫林开往一月雪山，中间经过十二月。

| 地区 | 月份 | 驾驶时应看到的景象 |
| --- | ---: | --- |
| 平原 | 6 | 牧草拔高，温暖湿润的夜里可以看见萤火虫 |
| 森林 | 7 | 盛夏树冠闭合，道路有荫 |
| 雪山 | 1 | 谷底和山口都有积雪。游戏纵谷海拔压缩，场景冬季雪线取 150 m，上下 100 m 平滑过渡 |
| 枫林 | 10 | 转红的枫叶和挂果的枝条 |
| 湖区、湿地 | 1 | 生态原型在新西兰，一月是南半球盛夏；水鸟和昆虫还须在当地名录和温湿度范围内 |
| 花田 | 9 | 对应的 Big Meadows 调研记录加拿大一枝黄花在八至十月开放，选九月 |
| 沙漠 | 3 | 雨后春花与仙人掌共存 |
| 红峡谷 | 4 | 春季灌丛衬出干燥的红砂岩 |
| 梯田 | 5 | 春耕蓄水，露出台阶与田埂 |
| 竹海、喀斯特峰林 | 6 | 初夏竹林成荫，石灰岩谷底湿润 |

扩展地区也按地理原型逐行查月。高山通道采用冬季雪景，阿尔卑斯落叶松林用十月金针，北极苔原和阿拉斯加河滩用七月短夏，南半球峡湾和草原多用一月，开普灌丛用九月春花。未识别的地区取六月。没有萤火虫记录的湖岸不新增物种。
