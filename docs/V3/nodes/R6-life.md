# R6 鸟和虫

方案：`plan/scenic-roads.md`。上一步：`R5-ground.md`。

## 一句话

第 4、5 版世界的每个地方以前都借它的模板地区的鸟和虫（大多是北美的）。现在每个地方按自己的生态系统、水、冷暖和月份，有自己的一群：
- **林子：** 热带有鹦鹉、果鸠、唐纳雀、太阳鸟；温带有松鸦、山雀、莺雀、啄木鸟；冷林有星鸦、灰噪鸦。
- **开阔地：** 温带有鹨、燕子和鵟在草地上空；热带换成织布鸟和卡拉鹰。
- **荒漠和山：** 荒漠有渡鸦和哀鸽，高山有成群的黄嘴山鸦。
- **水边：** 海边有银鸥、鹱，暖海还有鹈鹕；湖和湿地有白鹭、天鹅、野鸭；河边有翠鸟和渔雕。
- **虫：** 开花的地方有熊蜂或野蜂，以及蝴蝶（热带是凤蝶、斑蝶，温带是粉蝶、灰蝶）；水边有蜻蜓；夏夜湿热的地方有萤火虫；灯下有蛾子。都只在当地够暖的月份出来。

## 做了什么

| 部分 | 做法 |
| --- | --- |
| 鸟 | `world/earth/profile.ts birdsOf`：按结构（林子、开阔地、田、荒漠）、冷暖、山地、水（海、湖、湿地、河），从生灵系统的物种表（`core/v3/life/rules.ts`）里挑。每类选几种，用地方自己的骰子，相邻地方不会一模一样。 |
| 虫 | `insectsOf`：只在月均温 9 °C 以上的月份出来；下雪的地方没有虫。萤火虫要夏天湿热。 |
| 生灵系统找得到 | `core/v3/life/rules.ts profileFor`：地方的区域先找它自己的档案，找不到才看模板。 |

## 数字

- 种子 2 的前 29 个地方，一共用到 38 个物种，每个都在生灵系统的物种表里。
- 全部测试 2365 项通过。

## 还没做

- 鱼：生灵系统里还没有鱼的样子（钓鱼系统的鱼只在钓上来时出现），水里看不到鱼群和跃出水面的鱼。
- 大型动物（鹿、驯鹿、野鸭）还是只在路边的地方附近（`world/fauna.ts`）。
