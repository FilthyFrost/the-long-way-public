# R2 路型和导演：每个地方一种景观公路

方案：`plan/scenic-roads.md`。上一步：`R1-palettes.md`。

## 一句话

新开一局是第 5 版世界：每个地方（5 km，正常车速四五分钟）由导演给一种景观公路。路型共 24 种，从傍山路、盘山路、垭口路、山脊路、峡谷路，到海崖路、海边低路、湖岸路、林荫道、草原波浪路、沙丘路、峡谷边缘路、梯田路、峰林路、熔岩原路、冰川谷路、高原路……

- 同一种路不会连着出现；封闭的路之后接开阔的，弯多的之后接舒展的，看得远的之后接看得近的。
- 让人记得住的路，最多隔两三个地方就来一条。
- 平原开久了，导演会去找山、海或者看点。

第 4 版世界（以前的存档）完全不变。

## 参照

- **蓝岭公路**（设计者 Stanley Abbott）：把"变化"当作第一原则，近处的小景和一望无际的大全景轮流出现。路一会儿顺着山溪，一会儿爬上山坡牧场，一会儿下到开阔的谷底，再回到林子里。每个缓弯都打开一个新的视野。
- **Appleyard、Lynch、Myer《The View from the Road》**（1964）：开车是一组连续的镜头，靠封闭和开阔的节奏、景色一个个露出来推进。
- **挪威国家景观公路**：最好的位置留给看风景。

## 做了什么

| 部分 | 做法 |
| --- | --- |
| 路型目录 | `core/earth/roads.ts ROADS`。每种路型包括：适合什么样的地方（打分 0–1）；四段路各是什么地形；怎么弯（设计车速、直道多少多长、一个弯转多少度、半径放多宽）；怎么起伏；封闭程度、弯多不多、看得多远三个节奏数；是不是让人记得住的路；路两旁有没有树行。 |
| 排路型的导演 | `RoadDirector`：每个地方在合适的路型里打分。<br>• 最近六处用过的打折（上一处用过的几乎不选），没用过的加分；<br>• 和上一条路的三个节奏数差得越多，分越高；<br>• 隔两处以上没有让人记得住的路，这类路加分，隔得越久加得越多；<br>• 最后在前两三名里按地方自己的骰子挑。 |
| 有戏剧感的旅程 | `EarthJourney(seed, { drama: true })`：连续两处没有山、海或看点，导演选走法时就偏向能带来它们的，越久越偏。 |
| 新地形 | `world/landform.ts`：<br>• **傍山**：内侧一道 15 米左右的石壁，再往上是山坡。外侧从路边就陡落（最陡约 58°），落到几百米下的谷底，谷底宽几百米，对面一面比路还高的山墙。<br>• **崖边**：一侧是平地；另一侧离路边几米就断开，几百米深的峡谷，对面的崖壁回到崖顶的高度。<br>• **峡谷**：峡谷路的两侧崖壁靠得更近、更陡（接近 2:1）。<br>• **山脊**：两侧落差按地方的起伏放大，一般 70–340 m。 |
| 四段路按顺序排 | 每个地方的四段路，按路型给的顺序排：进入、正段、正段、离开（`routeProfiles.ts setRouteSettings` 加了起始段）。 |
| 海 | `world/sea.ts`：<br>• 连续几个海边的地方共用一片海，每个地方的正段海岸线都贴着路。<br>• 海崖路的海面在路下 70–180 m，崖脚只有一条碎石滩，崖不会被抹平成缓坡。<br>• 第 4 版世界的地方太短，以前一直排不出海岸。现在第 5 版有海了。 |
| 湖 | `world/water.ts`：湖岸路的湖是长湖，紧贴路边，这一段在左、下一段在右。 |
| 林荫道 | `world/earth/flora.ts`：两旁离路中线 7.7–10.6 m 各一行这个地方自己的主树，个头放大，林子一直长到树行边上。 |
| 盘山路的连串急弯 | `world/spine.ts`：盘山路的第二、三段是一组回头弯（`RegionDef.hairpins`）。<br>• 路先拐向山坡，再一段一段斜着横过山坡，每段 85–155 m，朝向偏离前进方向 73–78°；<br>• 两段之间是半径 12–17 m、约 150° 的急弯；<br>• 段落用完前拐回原方向，弯的曲率先放平，再交还给普通的路。<br>路的朝向始终在 ±85° 以内，不会掉头，世界照旧可以按 x 排序。急弯段一路爬升或下降，坡度不小于 8%。两段路之间的山坡由同一个 x 上的路高自然连起来，每段路切在坡上。<br>• 找最近的路时，还会从前后两三段路起各找一次，取最近的那段（`terrain.ts nearestLeg`）；<br>• 急弯段不放路边的地方和建筑，也不放河和湖。 |
| 接进世界 | `world/rules.ts RULES_V5`，`earth/road.ts DEALER_V5`。<br>• 地方的区域编号是 `earth5:种子:序号`；<br>• 两个地方的��渡只占一章的 35%（第 4 版是 70%），每条路有 3 km 以上是它自己的样子；<br>• 屏幕上的地名下方先写路型，比如"傍山路·褶皱山·温带火适应湿润林"。<br>新开一局默认第 5 版；`?world=4` 打开上一版。 |

## 数字

- 路型导演（12 条旅程，每条 80 处、400 km）：
  - 每条旅程用到 17 种以上路型（40 条旅程平均 21 种），24 种全都出现；
  - 同一种路连着出现的不到 1%；
  - 最长一段没有让人记得住的路不超过 10 处，绝大多数间隔 0–2 处；
  - 40 条旅程里，"路型 × 生态系统 × 地貌"的组合有 1772 种。
- 盘山路：每个盘山地方 14–17 个回头弯，两段急弯路爬升 140–190 m，最大朝向 82–84°，路面下的地 100% 托住路。
- 测试：`harness/sim/r2_roads.test.ts`，7 项。全部测试 2348 项通过。
  - 高度开销的微基准在满负荷下偶尔超时，单独跑能通过。
- 性能（第 5 版、种子 7 的五处测点）：森林 9.98 ms，开阔地 6.35，山 7.59，海岸 7.27，荒漠 6.0，都在预算内。
