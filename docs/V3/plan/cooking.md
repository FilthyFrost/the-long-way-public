# 烹饪系统：方案（用户 2026-11-22 点头，按推荐项开工）

2026-11-22，主会话。用户的要求：几十种食材（瓜果蔬菜、蛋、奶、各种肉、鱼），重食材、轻调料；随便组合去试，不在菜谱里的就是失败料理（像塞尔达）；处理过程轻量、好懂、有沉浸感和幸福感；厨具是实物，能搬到房车后面，能从建筑里搜出来；灶要换燃气罐；手里拿着东西时，能放的地方显示它的立体投影；菜有星级，推着人往前探索。这一轮只做东西和系统，放进测试面板；刷新概率和成长曲线等所有模块做完再统一设计。

## 一、现在已有什么

- **数据和规则**（`src/core/v3/cooking/`、`forage/`、`fishing/`）：89 种采集物、9 种野味、90 种鱼、13 种做法、150 道菜谱、出菜引擎、十种限时增益。偏"野外求生"：食材是牛肝菌、荚果蕨这类，没有番茄鸡蛋牛奶猪肉这样的家常食材；引擎是"永远有结果"，没有失败料理。
- **模型**：分支 `v3/c1-game`（未合并）里有 16 个厨具和 13 个菜肴的模型，可以拿来用；那个分支的做法是"对着灶按 E 弹出面板"，这次不沿用。
- **手持、摆放、投影**：游戏里已有手持（`held.ts`）、散放物（`loose.ts`）和投影（`ghosts.ts`），厨房的投影指引接在这上面。

- **已有的 89 种采集物和 90 种鱼不删**：它们按大类归进来（任何野生菌算"菌菇"，任何鱼按大小算"小鱼／白肉鱼／红肉鱼"），能代替同类的食材下锅。这 60 种是有自己的模型、被菜谱点名的"主角"。

- 模型：60 种各一个整的、一个切好的。已有的直接用，没有的按同一画法新做。

## 三、菜：约 120 道，一到五星

**一锅放 1–5 样食材，用什么厨具就是什么做法。** 引擎找"最具体的那道菜谱"；一道都对不上，就是失败料理。

| 层 | 数量 | 怎么写 | 星 | 例子 |
|---|---|---|---|---|
| 家常菜 | 约 40 | 按大类写，合理的搭配基本都能成 | ★–★★ | 清炒时蔬（任意蔬菜，炒）、菌菇汤（任意菌，煮）、烤肉串（任意肉，烤）、水果沙拉（任意两种水果，拌）、煎蛋、白粥、烤鱼 |
| 具名菜 | 约 60 | 点名具体食材 | ★★–★★★★ | 番茄炒蛋、土豆炖牛肉、蒜蓉西兰花、培根蛋炒饭、南瓜浓汤、奶油蘑菇汤、鱼香茄子、蛤蜊意面、苹果派、柠檬蜂蜜茶 |
| 大菜 | 约 20 | 4–5 样、跨几个来源、要高星食材 | ★★★★–★★★★★ | 海鲜饭（米、虾、蛤蜊、番茄、辣椒）、松茸炖鸡、黄油龙虾、松露奶酪意面、金枪鱼刺身拼盘、烤全羊排 |

- **星级跟菜谱走**：一道菜是几星是定好的，由它点名的食材的星和数量决定。想做更高星的菜，就得去找更稀有的食材。
- **做得好另算**：火候正好、切过、调过味，这道菜是"完美"的（金色名字，饱食和增益多四分之一）。不改变星级，所以不会做也不吃亏，会做有奖励。
- **失败料理三种**，都能吃但只有一点点：搭配不对是"说不清的一团"，烧过头是"焦炭"，肉和鱼没熟是"夹生"。失败的搭配会记进食谱本，下次再放同样的东西，锅上会提醒。
- **食谱本**：做出来的自动收进去。没做出来的显示剪影、星级和一句提示（"某种菌 + 蛋，煎"）。可以钉住一道菜，手里拿到它要的食材时会亮。
- **菜的模型**：约 30 个造型（汤碗、炖锅、炒菜盘、串、煎饼、饭碗、面碗、沙拉、三明治、派、饮品杯、整鱼盘、刺身拼盘……），上面的料按用到的食材上色和摆放，120 道菜各不相同，不用做 120 个模型。
- 现有的 150 道菜谱和增益数值留作底子，改成点名这 60 种食材。

## 四、厨具：实物，能搬，能搜刮

每件都是一个能拿起来、放下去的东西，放在任何平的地方或房车后面的厨房位。

| 第一批（做完就能完整做一顿饭） | 用途 |
|---|---|
| 卡式炉 | 火源。装一个燃气罐；旋钮分关、小火、大火；有余量表 |
| 燃气罐 | 一罐大约能烧 40 分钟大火；空了要换 |
| 案板和刀 | 切。可切可不切 |
| 平底锅 | 煎、炒 |
| 汤锅（带盖） | 煮、炖、煮饭煮面 |
| 搅拌碗 | 拌：沙拉、凉菜，不用火 |
| 盘子和碗 | 装盘，菜就出现在上面 |
| 调料盒 | 六种调料，按一下加一种 |

| 第二批 | 用途 |
|---|---|
| 烤网 | 架在炉子或篝火上，烤 |
| 水壶 | 饮品、热水 |
| 蒸笼 | 架在汤锅上，蒸 |
| 小烤箱 | 烘焙：派、面包、烤鸡 |
| 保温箱 | 存食材，保鲜 |

- **换燃气罐**做成完整的动作：掀开侧盖 → 抬起卡扣 → 抽出空罐 → 推入新罐 → 压下卡扣"咔哒" → 合盖。手里拿着新罐走近炉子，罐仓里会显示罐子的投影。
- 火烧到一半没气了：火苗变小、熄灭，锅里的进度留着，换上罐子接着做。

## 五、做一顿饭的过程

只用两个键：E（放下／拿起／操作），长按 E（连续操作）。

1. **摆**：拿着炉子，平地上出现炉子的投影，按 E 放下；拿着锅，炉头上出现锅的投影。
2. **切（可选）**：拿着番茄，案板上出现番茄的投影；放上去，按三下 E，一下一刀，切成块。切过的熟得快，并且算"完美"的一项。
3. **下锅**：拿着食材，锅里出现它的投影，旁边一排小格显示还能放几样（最多 5）。调料盒在旁边，对着它按 E 选一种加进去。
4. **开火和看火候**：拧旋钮点火。锅沿上一圈进度：生 → 正好（绿色一段）→ 焦。中途会提示翻一下或搅一下（按 E），做了绿色那段变宽。在绿色里把锅端下来或关火。
5. **装盘**：拿着盘子对着锅按 E，菜出现在盘子上，报出菜名和星级；第一次做出来的有"新菜谱"的提示和声音。
6. **吃**：拿着盘子按使用键；或放在桌上坐下吃。

- **投影规则只有一条**：手里的东西现在能放到哪里，哪里就显示它的半透明模型；不能放的地方什么都不显示。放不了的原因（锅满了、这件厨具不做这类食材）在准星下用一行字说明。
- **幸福感**：切菜声、下锅的滋啦声、汤的咕嘟声、蒸汽和油烟、装盘时的亮相；做坏了也有它的样子和声音。

## 六、测试面板

开发面板里加"厨房"一页：按类别取任意食材；取任意厨具和燃气罐；"摆一套厨房"（在面前摆好炉子、锅、案板、盘子）；全部菜谱解锁／清空；"试一锅"（选做法和食材，直接看会出什么菜，不用真的做）。

## 七、分步

每一步结束时交游戏里的截图，并且能在测试面板里用。

1. **数据和规则**：60 种食材和 6 种调料的表；引擎改成"对不上就失败"；约 120 道菜的表和星级。测试：每种食材至少进 4 道菜；每道菜都做得出来；随机抽"合理的搭配"成功率在七成上下，胡乱搭配基本失败。
2. **模型**：食材（整的和切好的）、第一批厨具、燃气罐、菜肴造型。先出样张。
3. **操作**：摆放和投影、切、换罐和点火、下锅、火候、装盘、食谱本。
4. **手感和指引**：声音、蒸汽油烟、亮相、提示、失败的反馈。自己从头做几顿，看是不是轻、是不是一看就懂。
5. **第二批厨具**和收尾：存档、性能、文档。

## 八、要你定的

1. **失败有多严**：推荐上面的写法——合理的搭配大多能成一道家常菜，胡乱搭配才失败。另一种是只认具名菜谱，其余全失败，试错会很挫败。
2. **星级**：推荐"星级跟菜谱走，做得好另给完美"。另一种是做得好能加星。
3. **切菜**：推荐可选。另一种是有些菜必须切。
4. **已有的 89 种野生食材和 90 种鱼**：推荐保留，按大类顶替。另一种是只留这 60 种。
5. **食材清单本身**：60 种里要增删哪些。
