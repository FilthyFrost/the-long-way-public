## 一、掉帧：实测

| 地方 | 拿着什么 | 准星对着 | 帧率 | 摆放代码每帧 |
| --- | --- | --- | --- | --- |
| 车库 | 罐头 | 地面 | 120 | 0.5 ms |
| 车库 | 罐头 | 方糖车身 | **60** | 9.6 ms |
| 路边，房车后面 | 罐头 | 地面 | 122 | 0.3 ms |
| 路边，房车后面 | 罐头 | 后保险杠 | **11** | 86 ms |
| 路边，房车旁边 | 罐头 | 侧面车身 | **47** | 18 ms |
| 房车里 | 罐头 | 地板、餐桌、墙 | 和不摆放一样 | 0.1 ms |

**原因（不是偶发 bug，是算法太慢）：**
- 找落点时，`nd-place/system.ts` 的 `surfaceHit`（465–490 行）沿视线每 4 厘米走一步。
- 每一步，都对 8 米内的每辆车调用一次 `vehicle.surfaceAt`（vehicle.ts:84–98）。
- `surfaceAt` 每次先把整车的矩阵重算一遍（`updateMatrixWorld(true)`），再用不带加速的射线竖直往下打整车所有网格。
- 房车一次约 1.5 ms，一帧要打 35–58 次。落点检查（394–411 行）还要再打 5 次。

**改法：**
- 每帧只打一条视线射线，用拿东西已经在用的加速射线（`castMesh` / `triGrid`，`CarView.targetCast`）。
- 整车矩阵每帧只算一次。
- 车里地板的高度照旧查车厢高度图（cargo.ts `HeightGrid`）。
- 目标：任何地方摆放代码每帧 0.3 ms 以内，摆放和不摆放的帧率一样。

## 二、ND 的摆放到底怎么做的

1. **车上有一块块"放置面"：** 地板、车斗、桌面、货架、车顶架、引擎盖、保险杠。每块面用车自己的方向。同一辆车的面编成一组，共用一个原点（SnappingPlaneGroup.SharedOrigin），所以几块面上的格子线是连着的同一套。
2. **一条射线：** 摆放时每帧从准星打一条射线，只打放置面这一层，再确认中间没被挡住（IsSnappingPlaneOccluded）。打中了，东西就贴在面上，面的格子在东西周围亮起，往外淡掉（半径是东西俯视半条对角线的 2.5 倍，至少 0.5 米）。
3. **Q / E：** 转到下一个 90° 整角（0.2 秒，带一声），按"所在的面"对齐，也就是车的方向。东西没在面上、人站在车上时，按这辆车对齐；都不是，才按世界的方向（MeasureStepAngle）。
4. **其它键：** 按住右键左右拖是自由转，此时镜头不动；滚轮调远近；左键放下，放下前用同一套规则再检查一次；R 取消。没有 G。
5. **提示：** 摆放时只有六个词：距离、释放、旋转、向左旋转、向右旋转、取消。ND 全部 49 个操作提示几乎都是 1–4 个字（使用、丢弃、吃、喝、点火、手刹……）。
6. **位置不吸格子：** 东西跟着准星连续走。格子只是钉在车上的参考线，配合 Q/E 对齐朝向。这一点和你的描述不一样，见第九节第 1 条。

## 三、我们现在哪里乱

- **三套算法：** 车里的"区域"（cargo.ts `aim`）、别的平面（`surfaceHit`）、悬空，各算各的。准星一换套，位置和朝向就跳。
- **格子不是车的：**
  - 格子是一块 1.2 米、5 厘米一格的网，跟着东西走（`showGrid` 每帧摆在东西脚下），所以线不是钉在车上的。
  - 在车外，位置按世界方向吸格（379–382 行），网却按车的方向画，两者对不上。
  - 5 厘米一格，24×24 条线，太密。
- **Q/E 只在车里区域对齐车：** 准星在车里区域时，Q/E 按车转；人在车后、对着地面或车身时，按世界方向转（`turnStep` 216–217 行）。
- **G 是另一个开关，**默认关着。按 Q/E 不会进格子。
- **隔着墙选中车里：** 房车后门关着时，对着后墙选中的是墙后面的"后排长椅"区域，显示"放不下：碰到了边上或别的东西"，东西本身看不见（cargo.ts `aim` 只判断区域盒子，不管墙）。
- **保险杠、引擎盖、车顶不算能放的面：** 对着保险杠，东西浮在半空、发红，提示"挡住了：碰到墙或别的东西"。
- **右下角常驻 7 行：** 放下 / 转 90° / 拖动鼠标转 / 格子：关 / 远一点近一点 / 拿回手里 / 空出手，再加一张完整的物品卡。

## 四、新的摆放

| 键 | 做什么 |
| --- | --- |
| R | 拿出来摆放；再按一次收回 |
| 左键 | 放下 |
| Q / E | 转 90°，同时进入格子 |
| 按住右键拖 | 自由转，同时离开格子 |
| 滚轮 | 远近（东西悬空时） |

G 去掉。

**落点：**
- 一条射线打真东西：车（里面和外面）、家具、地上的别的东西、地面和建筑。取最近的，被挡住的不算。
- 打中朝上的面（坡度 30° 以内）：东西贴在上面，包围盒最低点贴面。
- 打中墙：能挂的就挂，不能挂的就悬空。
- 什么都没打中：悬在面前，显示往下的虚线和落点影子（照旧）。

**格子用哪套：**
- 准星落在车上（车厢、车斗、座位、桌面、车顶、引擎盖、保险杠）：用这辆车的格子。
- 准星落在地上，但离车 3 米以内（比如在房车后面）：还是这辆车的格子。线延伸到车外，和车里接得上。
- 落在家具上：用这件家具的方向。
- 都不是：正南正北；在建筑里用建筑的方向。

**格子什么样：**
- 10 厘米一格。线按车算，钉在车上不动，东西在线上移动。车里车外是同一套线。
- 画在落点那块面上（车厢地板、车斗、车顶、地面），只在东西周围约 1 米内显示，往外淡掉。
- 按 Q/E 才出现；右键拖动转以后消失。

**格子里（按过 Q/E 以后）：**
- 朝向对齐格子（90° 一档）。
- 位置吸到格子上：东西的边贴线，几样东西并排就是整整齐齐的一排（见第九节第 1 条）。

**其它：**
- 放不下：东西发红，不写字；按左键时才闪一句"挡住了"。
- 右下角只写 ND 那几个词：滚轮 距离 · 左键 放下 · 右键 旋转 · Q/E 转 · R 取消。
- 摆放时物品卡收成一行名字。

## 五、提示的新规矩

1. **一个键一个词。**
   - 屏幕下方只写此刻准星对着的东西能做的事，一行一个：「左键 拿起」「按住左键 拆下」。
   - 名字单独一行。不要括号，不要说明。
2. **做不成的不显示。**
   - 灰色的"off"行全部去掉。
   - 原因留在动作里（`why`）。玩家按下那个键时，在提示的位置闪一句，1.5 秒后消失。
   - 原因不超过 8 个字：「先停车」「先开引擎盖」「手满了」「没电了」「满了」「这是柴油车」「挡住了」「先拿走上面的东西」。
3. **右下角键表：**
   - 空手什么都不显示。
   - 拿着东西，只显示这件东西自己的键（右键 吃、滚轮 喷嘴）。
   - Q 放下、R 摆放、Tab 背包，只在前三次拿起东西时各出现一次。
4. **物品卡：**
   - 手里的东西平时只显示名字（有量的加一条量）。
   - 整张卡只在看着地上的东西、或在 Tab 里出现。
   - 卡上不写怎么操作，只写状态（「锈 32%」「能开」）。
5. **弹出的小字（toast）：**
   - 只说"发生了什么"，几个字，不教操作。
   - 每次都弹的删掉或换成声音：收进后备箱、喷嘴：细、该翻炒了、这下不容易糊了、手上没地方了。
6. **教学只出现一次。**
   - F1 卡只在第一次开局出现，之后在暂停菜单里。
   - 车库清单只显示当前这一步，一行，做完不倒退（现在拆下一件就倒退，回车库又显示"开出车库"）。

## 七、怎么算做到了

1. **帧率：** 车库对着方糖、房车后保险杠、房车侧面、房车里四处摆放，帧率和不摆放时相差不到 5%。这四处加进性能闸门。
2. **格子是车的：**
   - 房车里放一排三样东西，再到车后地面放一样，都按过 Q/E。
   - 截图里车里车外的格子线是连着的；四样东西的边都贴在线上，朝向和车平行。
3. **Q/E：** 车里、车斗、车后地面三处，按一次 E，朝向都落在车的 90° 整角上，同时出现格子；右键拖动后格子消失。
4. **不隔墙：** 房车后门关着，对着后墙不会选中车里。后门开着，对着车里地板能放。
5. **一键一词：** 自动检查所有按键行，每行一个键、不超过 6 个字（名字行除外），没有括号，没有 off 行。
6. **做不成就闪：** 把第六节"常驻"清单里每种情形都在游戏里做一遍。按下那一下出现原因，1.5 秒内消失，不按就什么都不显示。
7. **截图：** 摆放、装件、加油、厨房四个场景各截一张，屏幕上的字数比现在少一半以上。
