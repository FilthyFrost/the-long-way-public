# 钓鱼改版：接进主游戏的物品栏和界面（用户 2026-11-23 点头，按推荐项开工）

2026-11-23。用户看了第一版（单独的 `fishing.html`，记录在 `docs/V3/nodes/F2-fishing-lite.md`）后说：界面跟我们的游戏没关系，太杂，一堆字。用户要的是：

- 有没有背包都一样，用最初那两格快捷栏拿起鱼竿；
- 鱼饵用另一格，想个办法给竿上饵；
- 整体 HUD 不换，信息极少：给一根竿、一个饵，让人钓鱼；
- 钓上来的鱼像《How to Fish》那样直接掉在地上，跟别的物品一样；准星对着它显示它的信息，按 E 像平常一样捡起来。

## 一句话

钓鱼不再是单独的页面和一套自己的界面，而是像做菜一样，做成主游戏的一个模块。竿、饵、鱼都是物品，用主游戏原有的键和 HUD，屏幕上不加新面板。

## 一竿是什么样

走到栈桥尽头，按 1 拿起鱼竿：钩上挂着一条蚯蚓，快捷栏那一格下面的细条是剩下的饵。对着水按住左键，水面上一个小圈往外走；松手，浮漂啪地落进水里。

一个鱼影慢慢游过来，浮漂点了两下，你忍住。第三下浮漂猛地沉下去，"咚"一声，你点一下左键。溅起的水花是蓝的：这是一条稀有鱼。

准星外面那一圈涨红了，你松手，鱼拖走一截线；圈退回白色，你再按住收线。鱼被一下甩上栈桥，在你脚边啪嗒啪嗒地蹦。你低头对准它，物品卡写着：大口黑鲈 ★★★，48 厘米，2.1 公斤，银牌。按 E，它进了鱼篓。

## 一、屏幕上有什么

主游戏现在的 HUD 一样不换：左上角的体温和饱食、顶上一句话的提示、右边的物品卡、准星和它下面那一行字、底下两格快捷栏、右下角的按键提示。钓鱼只往这些里面填内容：

| 什么时候 | 屏幕上多出来的 |
| --- | --- |
| 拿着竿 | 右下角的按键提示写竿怎么用；快捷栏里竿那一格下面有一条细条，是竿上还剩多少饵（主游戏里能装东西的物品本来就有这条） |
| 蓄力 | 水面上一个落点圈，只在按住时出现 |
| 等口 | 没有。只有浮漂和水里的鱼影 |
| 咬钩 | 浮漂沉下去，"咚"一声，溅起的水花带颜色，就是这条鱼的稀有度；准星下那行字变成"提竿！" |
| 搏鱼 | 准星外那一圈当张力表，从白变金再变红（主游戏"长按"时用的就是这个圈） |
| 上岸 | 没有弹窗。只有第一次钓到、破纪录、技能升级、断线、脱钩时，顶上一句话 |

第一版里的这些全部去掉：硬币、钟点、竿和饵的标签、张力弧线、"！"气泡、上岸的鱼卡、把鱼举到眼前、小屋（商店）、图鉴、委托板、天象历、地图和许可证、设置面板、手机上的大按钮。

## 二、两格快捷栏：上饵和接鱼

关键在这里：饵挂到竿上以后，就装在竿里，不再占格子。主游戏本来就有"能装东西的物品"（比如篮子），竿就是一个只装一种饵的东西。

- **格 1：** 鱼竿，饵装在竿里。
- **格 2：** 先放饵。饵挂上竿以后这一格就空了，用来接鱼，或者放一个鱼篓。
- 有没有背包都一样，钓鱼只用这两格。背包多出来的格子，可以多放几种饵、几条鱼。

**上饵：**

1. 拿着饵（比如"蚯蚓 ×20"）按 F：整叠饵挂到另一格的竿上，手上换成竿，钩上挂着一条蚯蚓。
2. 竿在快捷栏里时，再捡到同样的饵，直接进竿（能装东西的物品本来就是这样收东西的）。
3. 换饵：拿着另一种饵按 F，新的挂上去，旧的退回手里。
4. 活饵：钓上来的小鱼本身就是饵，拿着它按 F 就挂成活饵。湖主只吃本湖指定的那一种活鱼。

之后每次抛竿，自动从竿里取一个挂上；饵用完了，按键提示写"竿上没饵"。拟饵（亮片、软虫、羽毛饵）不会被吃掉，一直挂着，断线才丢。

**接鱼：**

- 鱼落在脚边，按 E 捡起来，进空着的那一格。
- 格 2 放的是鱼篓的话，捡起来的鱼直接进篓。主游戏本来的规则就是先进手上能装它的东西。
- 鱼篓装 10 条、10 公斤以内。装不下的大鱼（一米多的湖主）只能抱着走，要空出一只手。
- 篓满了，拿回房车放进保温箱（做菜模块里的，鱼坏得慢），或者直接下锅。

## 三、键

| 键 | 拿着竿时做什么 |
| --- | --- |
| 按住左键，松开 | 蓄力，抛竿 |
| 点一下左键 | 浮漂沉下去时提竿。浮漂只是轻点时提竿，鱼会被吓跑：整套钓法里只有这一处要沉住气 |
| 按住左键／松开 | 搏鱼时收线／放线；等口时按住，是把浮漂收回来 |
| E | 捡地上的鱼和东西，和平常一样（线在水里时，左键只管钓鱼） |
| F | 拿着饵时，挂到竿上 |
| 长按 G | 放下；拿着鱼对着水，就是放生 |
| 1／2 | 换格；线在水里时换格，线自动收回 |

## 四、地上的鱼

- 拉到脚下的鱼被一下甩上岸，落在栈桥板或岸上，啪嗒啪嗒蹦几下就不动了。它不会自己蹦回水里，也不会被鸟叼走。
- 它就是一件普通物品：躺在地上，存档里也在。
- 准星对着它，弹出的是主游戏自己的物品卡，只写几样：名字、稀有度（星）、长度和重量、牌级（铜、银、金、钻）、品相（闪光、白化……）、一句话说明。第一次钓到的标一个"新"。

```
鱼
大口黑鲈                ★★★
48 厘米 · 2.1 公斤 · 银牌
只追会动的东西。
新鲜 ▓▓▓▓▓▓▓░  还能放一天
```

- 鱼会坏，做菜模块定的是放一天。钓上来的鱼直接能下锅，做菜模块已经认得鱼。

## 五、内容：留下的、并进主游戏的、砍掉的

**留下：**

- 110 种鱼和六档稀有度、16 根竿、16 种饵；
- 有容量的鱼塘：看到的鱼影就是会钓到的那条，钓走一条少一条，第二天清晨放满；
- 湖主、天象鱼、鱼群沸腾、金色涟漪；
- 牌级和品相；
- 程序化的鱼模型；
- 搏鱼的规则，和三档机器人测出来的难度；
- 声音。

**并进主游戏：**

- 渔夫等级：变成主游戏成长系统里的"钓鱼"技能。和采集一样，升级时顶上一句话；抖饵、活饵这些特长挂在技能等级上。
- 图鉴：钓过哪些鱼、最大的纪录，记进主游戏的图鉴数据。主游戏现在还没有给玩家看的图鉴界面（只有测试面板里看得到），钓鱼也不另做一个；新的鱼靠物品卡上的"新"字和顶上那一句话。
- 湖主线索：漂流瓶是一件物品，拿着按 F 打开，顶上一句话，比如"黄昏，老塘主只吃活白条"。
- 天象：跟主游戏自己的天气和天空走，测试面板能直接叫出来。
- 水里的鱼影：和主游戏水里本来就有的鱼群（V7）合成一套，不会有两种鱼。

**砍掉：**

- 硬币、卖鱼、商店、许可证、委托：主游戏现在没有钱。和做菜一样，竿和饵先从测试面板拿；以后从哪来，等所有模块做完一起设计。可以是钓具店里搜到、工作台做、蚯蚓从土里挖，面包、玉米、虾这些食材也能直接当饵。
- 12 个挂件、渔具箱的五条升级线：太杂。竿好不好，就看竿本身。

## 七、代码怎么改

1. **跟上主线：** 先让钓鱼分支跟上主线最新的 19 个提交。做菜模块就在里面，它对物品、地上东西、存档的改动，钓鱼都要用。只在钓鱼的工作区里做，主项目不动。
2. **规则：** `src/core/v3/fishing/lite/` 基本留下，包括鱼、钓场、竿和饵、鱼塘、搏鱼、一竿的状态机、机器人。
   - 去掉：钱、商店、许可证、委托、挂件、渔具箱。
   - 新加：把鱼、竿、饵、鱼篓、漂流瓶登记成主游戏的物品，以及它们物品卡上的几行字。
3. **新模块：** `src/game/modcar/v3/fishing/`，像厨房一样自己注册。里面有手上的竿（线、浮漂、竿弯）、水里的鱼影和水花、鱼甩上岸和落地、测试面板、存档（鱼塘、技能、图鉴）。
4. **删掉单独的页面：** `fishing.html`，以及 `src/game/fishing/` 里的界面、输入、小屋面板。鱼的模型、竿、水面上的信号、声音搬进新模块。
5. **模型：** 鱼还是 three.js 程序化生成（生态资产的规矩），用和其他物品一样的材质。竿、饵、鱼篓、漂流瓶按主游戏物品的 Blender 脚本做，和厨具一个画法。
6. **主游戏的公共代码只加一处：** 让模块能接管"手上拿着某种东西时左键做什么"，并且能在手上的模型上挂东西（线和浮漂）。现在喷漆罐、海绵是直接写在玩家代码里的，钓竿需要这么一个口子。合并时只要看这一处。

## 八、分步（每一步交真实的游戏内截图）

1. **物品：** 跟上主线；鱼、竿、饵、鱼篓成为物品，在手上、地上、快捷栏里、物品卡上都对。
2. **钓：** 上饵、抛竿、等口、提竿、搏鱼、甩上岸、捡起、放生。这一步做完给试玩链接。
3. **湖：** 鱼塘、鱼影、鱼群沸腾、金色涟漪、湖主和活饵、天象鱼、漂流瓶；钓鱼技能和图鉴接进主游戏。
4. **收尾：** 重新校准难度、声音、性能（在主游戏的预算内）、文档。

## 九、要用户定的

1. 两格的用法（第二节）：饵挂上竿后不占格，格 2 接鱼或放鱼篓。另一种是严格的"一格竿、一格饵"，那样捡鱼之前得先把饵放下。
2. 钓鱼用哪个键：推荐左键。这是钓鱼游戏的习惯，主游戏里喷漆罐、海绵这种对着东西用的工具也是左键。另一种是右键／F，也就是主游戏"用手上的东西"的键：左右键完全分开，永远不会误捡。
3. 砍掉钱、商店、许可证、委托、挂件、渔具箱：推荐砍，跟做菜一样以后统一设计。另一种是这一轮就在湖边放一个卖鱼、买饵的地方。
4. 十片钓场：推荐留着，测试面板一键过去。另一种是只留一片湖，在面板里切换它的鱼。

先这样定，用户不同意再改：地上的鱼不会跑；手机先不做（主游戏现在只支持键鼠，钓鱼跟着它）。

## 十、进度

用户 2026-11-23 回复"可以你按照方案去做吧"，四个问题都按推荐：

1. 饵装进竿里，不占格子；
2. 左键钓；
3. 钱和商店这一轮砍掉；
4. 十片钓场都留着。

**第 1、2 步完成（2026-11-23）：鱼、竿、饵是主游戏的物品，在主游戏里能钓。**

- **入口：** `?seed=20261113&fish=<0–9>` 直接站到那片钓场的栈桥边，格 1 是挂好 40 条蚯蚓的「柳枝」竹手竿，格 2 是鱼篓。开发面板（\` 键）的「钓鱼」页有这些功能：
  - 去任意一片钓场；
  - 拿竿、拿饵、拿鱼篓、漂流瓶、沉船木箱；
  - 叫出天象、重新放鱼、让一条鱼来咬；
  - 调钓鱼技能的等级。
- **物品：**
  - 110 种鱼各是一种物品（`fish_<id>`），每条的长度、重量、牌级、品相记在它自己身上；
  - 16 根竿、16 种饵、鱼篓、漂流瓶、沉船木箱、大珍珠、靴子、易拉罐；
  - 竿、饵、鱼篓这些用 `tools/blender/items/fishing.py` 做，和厨具一个画法；
  - 鱼是 three.js 程序化的（`models.ts`）：躺着的样子，按牌级的大小和品相的颜色画，在地上、手上、快捷栏里是同一个模型；
  - 鱼登记成了做菜的食材，任何鱼都能下锅。
- **手上：**
  - 左键：按住蓄力，水面上有落点圈；松开抛竿；浮漂沉下去时点一下提竿；搏鱼时按住收线。
  - 准星外那一圈是张力：白、金、红。
  - 按键提示写在快捷栏上面那一行，只有当时要用的那句。
  - 线在水里时准星不选别的东西，竿的物品卡也收起来。
  - 搏鱼时站着不能走，等口时走开会自动收线，竿离手就收场。
- **上岸：**
  - 鱼被甩到脚边的栈桥板或岸上，扑腾几下，就是一件普通物品；
  - 准星对着它弹出主游戏的物品卡：鱼 · 稀有度、星、体长、重量、牌级、品相、"第一次钓到"、新鲜程度；
  - 按 E 捡起来，进鱼篓或者空着的那格；
  - 两只手都占着、鱼篓又装不下的大鱼（比如湖主），会提示先空出手。
- **饵：**
  - 拿着饵按 F 挂到另一格的竿上，旧饵退回手里；
  - 竿在快捷栏里时，捡到同样的饵会直接进竿（主游戏本来的规则）；
  - 每钓一条吃掉一个，拟饵断线才丢。
- **手上的其他动作：**
  - 小鱼按 F 挂成活饵（钓鱼 5 级）；
  - 漂流瓶按 F 打开，顶上一句湖主的线索，有时掉出星屑饵；
  - 拿着鱼站到水边长按 G，放回水里，拿经验。
- **主游戏的成长：**
  - "钓鱼"技能用主游戏的曲线，一条鱼的经验是第一版的十二分之一；
  - 3 级抖饵、5 级活饵、8 级读水、12 级放生拿全额经验；
  - 钓到的鱼记进主游戏图鉴的"鱼"一栏；
  - 顶上的一句话只在第一次钓到、破纪录、出品相、金牌以上、断线脱钩、升级时出现。

**第 3 步完成（2026-11-23）：湖里的东西。**

- **十片钓场：** 改到主游戏默认世界（种子 20261113）里真实的栈桥上，用 `harness/sim/fishing_waters_scan.ts` 扫出来；第一版扫的是另一套世界参数，那些栈桥在主游戏里不存在。每片 30–45 条鱼，水里看得到鱼影，鱼群沸腾、金色涟漪照第一版。
- **浅水塘：** 樱岭塘的栈桥站在半米深的水里，原来一条鱼也放不进去。现在水浅的塘，鱼可以待在一半深的地方。
- **湖主：** 黄昏用第二根竿挂活白条，在樟篁湖钓上老塘主：1.13 米，22.9 公斤，搏了 48 秒。
- **天象鱼：** 叫出雨后彩虹，天上真的出现彩虹；星屑饵钓上"虹"，搏了 74 秒，同时升到钓鱼 8 级、学会读水。
- **天象怎么来：** 跟主游戏自己的天空走（真下雨、真有彩虹、流星雨、极光、满月……）。每片钓场隔天还有一次自己的天象，到点时那里的天气会被推过去，叠在开发面板的天气调节之后，不抢它。

**任何一片水都能钓（2026-11-23）：**

- 十片钓场以外的湖、海，拿着竿对着水，面前那片水就是一口"野外的水"，鱼按十片钓场里最像它的一片放：海水放青野海湾的鱼；淡水按它在路上多远，每 30 公里换下一片的鱼。
- 湖主和天象鱼只住在自己那片钓场。
- 在路上第 36 段一片不带栈桥的湖边，换陡一点的岸，放了 34 条苍谷湖的鱼，4 秒咬钩（`harness/shots/fishing.mjs wild`）。
- 浮漂落在太浅的水里时，顶上会说"这里水太浅了：往深处抛，或者找个栈桥"。有的湖岸很缓，20 米外水才 0.3 米深，那里钓不了。

**修过的 bug（2026-11-23，用户试玩时发现）：长按左键没有蓄力，竿抛不出去。**

- **原因：** 竿只在按键状态变化时才更新"按着"还是"松开"。一竿结束时左键还按着（按着收线、鱼上了岸，或者按住把浮漂收回来），松手时竿已经空闲，那次"松开"就没告诉它。它从此一直以为左键还按着，之后每次按下都被当成"还在按"，蓄力永远不开始。钓上第一条鱼时最容易碰上，因为收线时一直按着。我先前的测试每竿都换新状态，所以没测出来。
- **修法：** 竿空闲时也把松开同步过去，新的一下按下一定能被看见（`system.ts rodButtons`）。另外，按住收回浮漂时，就算那一下吓跑了正游过来的鱼，只要还按着，照样收回来（`session.ts`，原来按住 2 秒多也不动）。
- **复现：** 修改前的代码在真实鼠标下复现过：收回浮漂后松手，竿仍记着"按着"，再按 0.8 秒一点蓄力都没有。修好后同一串操作正常。现在有两项测试固定下来：`harness/shots/fishing.mjs play` 钓完再抛一竿，`fishing.mjs mouse` 用真实鼠标按着收线到鱼上岸，松开后再抛一竿。
- **蓄力动画做明显了：** 竿从前倾一路竖到接近竖直，手跟着抬起，满蓄力时轻轻发抖；松开往前低甩，再回到原位（`rodView.ts`）。原来只从前倾 19° 抬到 50°，不容易看出来。
