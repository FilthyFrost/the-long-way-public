# 她：照 Painted Valley 的做法，用代码长出来的玩家角色

2026-11-24 起，分支 `feat/character-pv`（worktree `D:/tlw-char`，从 `v3/next` 拉出）。参考图是用户给的三视图（深肤色、白色短发、红橙色眼睛、白色蕾丝吊带睡裙、右大腿缠着绷带、赤脚；本机 `refs/character/turnaround.png`，不入库）。用户定了：**眼高跟着她走**（身高约 1.63 米、眼高约 1.50 米，不再固定 1.62）。

之前的人物分支（`feat/character`，白狐面具长发的方案和 Meshy 生成的模型）不沿用；这份方案替代它。

## 一、目标

1. 一个在 three.js 里由代码生成的角色：身体、脸、头发、睡裙、绷带、以后所有衣服，都是程序生成，参数一改就重新长。
2. 画法和游戏一致：人物是赛璐璐加墨线（`specs/art/STYLE.md` §1），背景是油画。
3. 一整套动作：站、走、跑、冲刺、跳、蹲、蹲走、开车（方向盘、挡杆、手刹、钥匙、喇叭）、骑摩托、上下车、开车门、吃、喝、吃药、搬东西、捡、放、倒油、喷漆、擦洗、爬梯子、坐椅子、钓鱼……
4. 第一人称和第三人称都要好：第一人称的手要做到市面第一梯队的精细度，持续迭代。
5. 衣服是真的穿在身上：睡裙只是初始服装，换上羽绒服、裤子、靴子、手套、帽子、背包，身上就真的换。

## 二、Painted Valley 的角色是怎么做的（源码 `D:/美术参考/painted-valley`）

| 它的做法 | 我们怎么用 |
|---|---|
| 身体是一个装了骨骼的人体（MakeHuman，CC0），骨骼是 Universal Animation Library 的 | 骨骼**一节一节照抄**它的名字、父子关系和每节骨头的静止坐标系，只换成她的长度；身体本身改成代码雕出来 |
| 动作是 UAL 的 CC0 片段（走、慢跑、横移、转身、跳）加 Patch 自己的（跑、冲刺、起步、急停） | 33 个片段直接播在她身上（骨盆位移按腿长缩放，根骨位移拿出来当速度），已验证 |
| 帽子、斗篷在代码里做：帽子是车床体，斗篷是真布料（点阵 + 定长线 + 风 + 身体碰撞棒） | 睡裙裙摆、发带、绷带尾巴同样做成真布料；头发、衣服全部代码生成 |
| 人是赛璐璐，不是油画：三种颜色（亮、暗、褶子深处），暗色是单独调的颜色不是亮色压暗 | 皮肤、头发、布料都是"亮色 + 暗色 + 深色"三色；暗面用天空的颜色照 |
| 每个部件在画面透明通道写一个小编号，最后一遍在编号不同的地方画线；油画化跳过这些像素 | 游戏的 `frame.ts` 已经是这套（编号 < 0.23 画线，< 0.6 不上油画笔触）；她用 0.04–0.19 |
| 不接自己的影子，只接环境的大遮挡；地上的影子是干净的形状 | 采样阴影时朝太阳挪 30 厘米，跳过自身遮挡；树、车顶、屋顶照样遮她 |
| 动画：按速度和方向的混合空间，所有循环共用一个步态相位（左脚着地为 0），按真实移动距离推进相位，脚不打滑；切换时找脚的位置最接近的那一帧接上；脚踩地形 | 把它的 `animator.js` 移植过来，加上我们自己的层（见第五节） |

## 三、怎么"长"出她（`src/core/character/`，纯 TypeScript，可测试，可在 worker 里跑）

1. **骨架** `skeleton.ts`：PV 的 65 节骨头 + 前臂/上臂扭转骨。只换长度：她约 1.63 米、6.5 头身、腿长、肩窄、手小。建模姿势是 A 字（手臂下垂约 45°、手指放松），这样常用姿势下肩膀变形最小。
2. **雕塑** `body.ts`：一百多个圆润的几何体（椭球、圆锥、圆角盒）挂在骨头上，像捏泥一样平滑融合：头骨、脸颊、下颌、鼻子、耳朵；胸廓、腰、胯、臀、肩胛；三角肌、上臂、肘、前臂；掌心、大小鱼际、指关节、每根手指三节加指腹；大腿、膝盖骨、小腿肚、踝骨、脚跟、足弓、五个脚趾。手指之间、两腿之间、手臂和肋骨之间用"硬并集"隔开，不会粘成蹼。
3. **表面** `polygonize.ts`：稀疏网格上的 surface nets（只算表面附近的格子），顶点沿梯度投回表面；法线直接取场的梯度，所以不管三角形怎么分，明暗交界线都是光滑的。
4. **减面** `decimate.ts`：二次误差边折叠，手、脸、脚、关节加权保细节，平的地方省面。
5. **蒙皮** `mesh.ts`：每个顶点跟着离它最近的几何体走，几何体沿自身长度在关节处把权重交给上一节和下一节骨头（关节处五五开，不起折痕）；前臂的扭转分给扭转骨，手腕不会像糖纸一样拧。每个顶点还带：手心/脚底程度（深肤色人的手心脚底更浅）、关节泛红、属于哪个部位（第一人称隐藏用）、墨线编号。
6. **打包** `tools/character/build.ts` 离线跑一次（同样的代码出同样的文件），写 `public/models/character/her.bin`：第三人称身体约 3.8 万面，第一人称两条手臂各约 1.7 万面（1.1 毫米的格子）。和发动机录音库一样，是"我们自己的定义离线算好的数据"。
7. **头发、睡裙、绷带、衣服**不是雕塑，是按曲线和身体表面生成的薄片和布料（第四、六节）。

## 四、画法（`src/game/character/material.ts`）

- 皮肤：亮面暖深棕，暗面更深更红的棕，褶子深处再深一档；手心脚底浅一档；指节、膝盖、指尖一点红；边缘一圈很淡的天光。读游戏共用的太阳、天空、房间灯光、雾、车灯（`shaderlib.ts` 的 `globals`）。
- 脸：眼睛、睫毛、嘴在着色器里画（参数化的形状，随时可以眨眼、看向别处、张嘴吃东西），不用贴图；脸的法线朝外"球化"，避免鼻子投出难看的影子（罪恶装备 Xrd 的做法）。
- 头发：一缕一缕的发片，亮色白、暗色冷淡紫灰、发梢更深，头顶一圈光带；每缕一个墨线编号，缕和缕之间有线。
- 睡裙：白色半透感，暗面冷灰蓝；蕾丝边在着色器里画（扇形边 + 镂空小孔）；系带、交叉绑带、绷带单独编号。
- 墨线编号：皮肤 0.045–0.105（沿肢体平滑升高，左右不同、每根手指不同，所以手指压在掌心上、胳膊横在身前都会出线），头发 0.118–0.148，衣服 0.158–0.188，边饰 0.19。
- 阴影：身体的深度替身（只在阴影图层，带蒙皮）投到游戏自己的两级阴影图里；第一人称时头部不画，但影子里有头有头发。
- 低画质：没有阴影图时用游戏现有的软圆影。

## 五、动作系统（`src/game/character/animator.ts` 等）

按层叠起来，每层只管一件事：

1. **移动层**（移植 PV 的 animator）：站立呼吸、走、慢跑、跑、冲刺、八方向横移、原地转身、起跳/空中/落地、起步急停；步态相位按实际移动距离推进，脚不打滑。
2. **姿态层**（程序姿势，按状态淡入淡出）：蹲、蹲走（走路片段 + 骨盆下沉 + 腿部 IK）、坐车（骨盆落在座垫上，大腿前伸，脚踩踏板）、坐椅子沙发、骑摩托（前倾、脚踩脚踏、跟着车身侧倾）、爬梯子（手脚交替抓蹬横档）、游泳、抱大件走、睡觉。
3. **视线层**：头和脊柱跟着镜头的俯仰和偏航；第一人称时头直接对齐镜头。
4. **手臂层**：两节骨的解析 IK（带肘部朝向），目标来自游戏：握着东西时在握点，捡东西时伸向东西，开车时在方向盘边缘，开门时在门把手。
5. **手指层**：一套握法库（张开、放松、握拳、握把、握瓶、捏、托、提、抱、握方向盘、握车把、握横档、按按钮、拿杯子、拿手机/相机），切换 0.1–0.15 秒；手指合拢到碰到物体为止（按物体形状逐指收拢）。
6. **动作时间线**（`actions.ts`）：吃（送到嘴边、咬三口、放下）、喝（仰头）、吃药、捡、放、倒油（一手提把一手托底）、喷漆（先摇再按）、擦洗（来回）、拆装零件（拧）、开车门（抓把手沿铰链拉开）、上车下车（转身、坐下、收腿）、换挡、拉手刹、拧钥匙、按喇叭、穿衣服。动作在按键那一刻就生效，手的动画只是追上去，随时可以被新动作打断，不排队。
7. **脚的 IK**：脚贴地形和台阶，骨盆随之调整；车里脚踩踏板（油门刹车按输入踩下）。
8. **会甩的东西**：头发每缕挂弹簧骨（VRM SpringBone 的规则），睡裙裙摆是 PV 斗篷那样的真布料（挂在胸下的接缝上，和大腿、臀部的碰撞棒碰撞，跑起来往后飘，风吹侧摆），发带尾巴、绷带尾巴也是小布条。

## 六、第一人称

- 镜头就在她两眼之间（头骨上的眼点），身体位置和朝向由游戏的行走/座位逻辑决定，脊柱和脖子吸收镜头的上下点头和晃动；低头看到自己的胸口、裙子、腿和赤脚。
- 第一人称画两条细的手臂（1.1 毫米格子生成，约 1.7 万面一条），身体自己的手臂和头不画。
- 手和手里的东西都按 UE 第一人称渲染的办法往镜头方向"缩"（屏幕上大小不变），贴墙、伸进柜子时不穿模；放下东西时恢复真实深度。
- 手的精细度清单（逐项迭代到第一梯队）：指甲（着色器画的甲面、甲根线、高光）、指关节的褶和微红、掌纹的三条主线（只在近处画）、手心浅色和手背深色的过渡、手腕骨的凸起、手背伸直时的肌腱、握东西时指腹压扁贴合、每根手指的弯曲有先后（从食指到小指依次）、手的重量感（拿重东西时手腕下沉、微抖）、放松时的手指自然弯曲。
- 每一个"手去做"的游戏动作都对应一张第一人称实拍，逐张对照打磨。

## 七、衣服系统（`src/core/character/wardrobe.ts` + `src/game/character/wardrobe.ts`）

- 槽位沿用游戏的：帽子、外套、裤子、鞋、手套（`core/modcar/items.ts` 的 `WearSlot`），加背包和头灯。身上穿什么完全由 `ModPlayer.worn` 决定，存档里本来就有。
- 每种衣服是一个"版型生成器"：从同一个身体的形状往外长（外套 = 躯干和手臂的场往外推 1–3 厘米，羽绒服再按横向绗缝鼓起；裤子 = 腿的场往外推，裤腰收住；手套 = 手的场推 2 毫米，露指手套剪掉指尖；靴子、帽子同理），网格生成后蒙到同一副骨骼上。同版型按物品卡的两种颜色和破旧程度出不同样子。
- 被衣服完全盖住的皮肤不画（按部位遮罩），不会从缝里穿模。
- 和睡裙的关系：穿外套时睡裙上身不画（裙摆照样露在外套下面）；穿裤子时睡裙裙摆收短塞进裤腰；不穿就是原样。
- 第一人称：外套的袖子、手套同样有细版，一抬手就看到袖口和手套。
- 换衣服是瞬间换上（和现在一样），之后可以加"穿上"的动作。

## 八、接进游戏

| 游戏里 | 位置 | 她怎么接 |
|---|---|---|
| 步行的眼点和朝向 | `core/onfoot/walker.ts`（`FOOT.eye`）、`ModGame` 的镜头写入 | 眼高改为她的眼点；身体脚底在行走者脚下，朝向跟镜头偏航（超过 60° 原地挪步） |
| 座位 | 座位模型的 `EYE` 节点、`FirstPersonRig` | 骨盆落在座垫，眼点对上座位眼点 |
| 方向盘 | `M_steering` 挂点、`part_steering.rotation.x`、半径 0.195 | 两手握在 9 点 3 点，跟着转；转过约 90° 交替换手 |
| 挡杆、手刹、钥匙 | `cockpit.ts` 的 `LEVER`/`KEY` | 右手伸过去，跟着动 |
| 车门 | 面板的铰链和 `panelOpen()` | 走近、抓门边沿弧线拉开；上车下车补上转身坐下的过程 |
| 手里的东西 | `held.ts` 的十层姿态 | 东西的位置照旧算，手去握它；吃喝、倒油、喷漆、擦洗按它的时间线做手的动作 |
| 衣服 | `ModPlayer.worn` | 换了就重新组装身上的衣服 |
| 阴影 | `shadow.ts` 的两个图层 | 蒙皮深度替身放在阴影图层 |
| 第三人称 | 新增：步行时按 V 切换跟随镜头（PV 的 Follow：身后偏一侧、避障、贴地） | 车里已有的车外视角里也能看到她坐在驾驶座 |

## 九、怎么检验

- **自动检查**（`harness/sim/character_*.test.ts`）：表面封闭无破洞；每个顶点权重和为 1；骨架和 PV 片段对得上；IK 几百个随机目标误差 < 5 毫米、肘不翻；弹簧骨一万步不发散；衣服在几十个采样姿势下不露出身体。
- **对照参考图**：`tools/character/compare.ts` 在参考图的同一比例下画正、侧、背三视图和参考图并排；`harness/shots/character.mjs` 在游戏渲染器里拍三视图、动作、特写。
- **实机检验**：放进游戏里，在车库、草原、森林、雪地、黄昏、夜里、车里拍第一人称和第三人称，看是否和场景的美术搭、和车的赛璐璐搭；每轮挑最差的三处改，再拍同机位。
- **性能闸门**：`SHOTS_GPU=1 node harness/shots/perf_gate.mjs`，P95 ≤ 11 毫秒、≤ 400 次绘制。她最多加 5 次绘制（身体、头发、衣服、影子两层）。

## 十一、风险

- 程序雕的身体不够好看：每一轮都和参考图三视图并排对照改；脸和手单独放大检查。
- 手的精细度：第一人称的手是这件事的成败，单独留出迭代时间，每个握法都拍特写。
- 改公共渲染代码（墨线、阴影）会影响车和场景：尽量只在她自己的材质里解决（墨线编号渐变、阴影偏移），必须改时同机位对比车和场景。
- 眼高从 1.62 降到约 1.50：要回头检查柜台、架子、车里视线、梯子顶端、坐姿这些地方。

## 十二、进度记录（2026-11-24）

- **第一人称的镜头在她真实的眼睛上。** 座位里按她坐好的姿势算眼点：她比原先设定的驾驶者小，坐得更靠前，轿车里眼点比座位原眼点前移约 0.2 米，摩托上约 0.4 米（趴向车把）。步行时镜头跟着她的头走（步伐的上下起伏平滑掉，游戏自己的晃动保留），低头时眼睛随头前移下移；低到 −1.25 以下能看到自己的裙子、腿和脚。
- **视线俯仰方向修正。** 之前镜头往下看时她的头是往上仰的（第一人称看不见头所以没发现，第三人称会看反）。
