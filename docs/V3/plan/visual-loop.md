# 视觉迭代（V 系列）：一直改到每个地方随手截图都好看

2026-11-21 定。用户试玩 R7 后的反馈：生态不够震撼、像 low poly；植物和石头粗糙；高架桥和隧道简陋；光影不够丰富，要更美的朝阳夕阳、银河星空流星；植被和花鸟鱼虫密度不够。用户批准按本方案自己循环迭代，里程碑只汇报不停工。

## 2026-11-22 纠偏（以此为准）

V1–V10 一轮轮"加东西"之后，用户认为画面越做越乱、越做越差。调查和修正见 `nodes/G-ghibli.md`。往后迭代守这几条：

1. **先减后加**：一个画面里大片安静的地方和少数有细节的地方要分明。新加的东西先问"它成组吗、有主次吗"，均匀撒满的一律不要。
2. **摆放按构图**：树成林分，灌木成带成丛，石头成露头，花成带（`core/world/layout.ts`）。每类地区有自己的格局（`core/world/earth/flora.ts PATTERN`）。不逐格掷骰子。
3. **一个地方一套颜色**：树冠一套四档梯度，树种之间只差一点；石头用这个地方岩石的颜色。
4. **主角地貌要经得起近看和远看**：造型按岩石怎么碎来做（层理、节理、岩块），细节逐像素画。
5. **云**：各种云型都要，按生态地区分配，一个天空一个主题，每种云本身要画好；可以无云。
6. **光影**：Painted Valley 是画法的参考（阴影有颜色、明暗分档），不是每个地方都照它的光。按生态地区、环境、天气各自设计。
7. **审片用自由机位**（不带车舱和界面，`D:/modcar-scratch/v1/probe/eye.mjs`）：空中看摆放，人眼高度看构图，再看驾驶座。

## 诊断（R7 实拍，对照 Painted Valley 和用户给的 50 种地貌图鉴）

1. 种子 1 第 3–17 个地方全是雪，连开一个小时白茫茫：北方针叶林的最佳月份是 1 月，旅程一经过就被拉进隆冬（V1 已修）。
2. 光从早到晚都是平光：夕阳只是天变粉，地上没有暖光和长影；夜里只是暗一点的白天，没有星星、银河、月亮（V1）。
3. 山和雪坡是一块块平的大三角，一看就是 low poly；岩壁没有层理和笔触（V2）。
4. 石头几乎没有（预算用了 0%），树只用了预算的 2–8%，草矮且稀，没有成片的花海（V3、V4）。
5. 地貌没有主角：地热区没有蒸汽和热泉，火山没有熔岩（V5）。
6. 桥和石廊是纯色方块（V6）。
7. 配色对但保守：缺少主色，冷暖、明暗对比没拉开（V1 先做整体，V4 再做各地的主色）。

## 怎么自我迭代

- **固定审片路线**（`harness/shots/v1_review.mjs` 的 ROUTE）：种子 1、7、3 的 21 个地方，覆盖森林、雪地、高山、熔岩、峡谷、海崖、海蚀柱、稀树草原、热带、河、花田、梯田、喀斯特、地热、方山、苔原、瀑布峡谷。每处从驾驶座拍 7 点（清晨）、15.5 点（下午）、18.3 点（夕照）、19.1 点（日落后）、23 点（夜里）。
- **每一轮**：拍 → 和 Painted Valley、图鉴并排比 → 按评分表挑最差的三项 → 改 → 再拍同机位。
- **评分表**：远中近三层是否都有东西；明暗对比；有没有主色；近景的细节密度；剪影是否好认；光的氛围；有没有平三角、突兀的颜色、穿帮。
- **性能闸门**：每个里程碑跑 `harness/shots/perf_gate.mjs`，5060 Ti 1080p 每帧 11 ms 内。
- **汇报**：每个里程碑发同机位改前改后的游戏内实拍和性能数据，然后接着做，不停下等。
