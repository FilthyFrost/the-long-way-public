# 服装与真实生存（阶段 5 设计草案，待审批 D）

2026-11-20。依据：[总方案](../PLAN.md)里的阶段 5"服装与真实生存，主参考《漫漫长夜》"。用户原话：冷的地方要穿羽绒服，沙漠里热要中暑。

## 一、现在游戏里有什么

`src/core/modcar/vitals.ts`，照 Arctic Drive 的普通难度做的：

- **身体**：生命、体力、饱腹、口渴、体温、膀胱，加几种持续状态：
  - 醉、精神抖擞、闹肚子；
  - 热食和暖身药带来的"暖和"；
  - 失温、淋湿。
- **体温**：只有一个"舒适线"：20°C 减去身上衣服的保暖数之和。
  - 气温低于它，体温慢慢降，最低 28°C；高于它，体温回升。
  - 低于 32°C 失温，掉血。
  - 淋湿时保暖数减 25。
- **衣服**：5 个部位（帽子、上衣、裤子、鞋、手套），每件只有一个保暖数（3–10）。
  - 现在有鸭舌帽、毛线帽、护耳帽、破外套、破毛衣、夹克、棉服、羽绒服、破裤子、工装裤、加绒裤等。
- **没有的**：
  - 风、热、中暑；
  - 衣服淋湿再结冰、衣服磨损；
  - 冻伤、晒伤；
  - 地点和天气对冷热的影响也很粗。

50 段风景从零下 25°C 的霜林到 33°C 的红土雨林都有，这一套不够用了。

## 二、《漫漫长夜》是怎么做的

参考：[Feels Like](https://thelongdark.fandom.com/wiki/Feels_Like)、[Clothing](https://breezewiki.com/thelongdark/wiki/Clothing)、[Warmth](https://bw.artemislena.eu/thelongdark/wiki/Warmth)、[衣物与保暖指南](https://www.bamboogaming.net/the-long-dark/clothing-warmth)、[官方 1.0 更新说明](https://store.steampowered.com/news/posts?appids=305620&enddate=1484246783&feed=steam_community_announcements)。

1. **一个"体感温度"总管一切**
   - 体感温度 = 气温 + 风寒 + 衣服的保暖 + 衣服的防风，再加火堆、热源、睡袋。
   - 屏幕上只显示这一个数。
2. **体感在 0°C 以上**：保暖条回升；**0°C 以下**：保暖条下降，越冷降得越快；**降空**：开始掉生命；**冻了两个小时**：染上"失温"，掉得更快。
3. **衣服分层**：
   - 里层管保暖，外层管防风和防护；
   - 防风只算最外层，而且只抵得了实际的风寒（无风的日子防风没用）。
4. **湿了会冷，湿透会结冰**：
   - 湿了保暖下降、防风失效；湿透后在严寒里结冰，保暖几乎归零，还会冻伤那个部位。
   - 防水的衣服湿得慢、干得快；羊毛湿了还保暖，棉的不行。
5. **衣服会磨损**：完好度越低保暖越差，能缝补。
6. **哪儿没穿哪儿冻伤**：空着的部位冻伤风险上升（手脚最快），满了就永久少一截生命上限。

它只管冷，没有热。我们的路线有荒漠、热带，热的部分得自己补。

## 三、我们的做法

### 3.1 体感温度

每秒算一次：

```
体感温度 = 气温（段落、时刻、天气、海拔）
         + 风寒（风速 × 暴露程度）
         + 衣服的保暖（按完好度、湿度打折）
         + 衣服的防风（只算外层，不超过风寒）
         + 热源（火堆、车里的暖风、房车的炉子、温泉）
         + 日晒（白天直晒加几度，阴影、车里没有）
         + 遮蔽（室内、车里、帐篷：不吹风）
```

- **气温**：从风景段的数据里来（`scenes.ts` 每段的白天平均温度和季节），按时刻加昼夜温差（荒漠和高原差得最大），再按天气调整（雨雪、阴天）。阶段 4 的地区天气做出来后，从那里取。
- **风**：天气系统已有风速。开车时车窗开着，车速也算风。
- 屏幕上显示体感温度和一个冷热条，样子照 Arctic Drive 的 HUD 风格，边框换卡通。

### 3.2 冷和热两头

| 体感 | 会发生什么 |
|---|---|
| 0°C 以下 | 保暖条下降，越冷越快；降空后体温掉，掉血 |
| 0–25°C | 舒适 |
| 25–32°C | 热：口渴加快 |
| 32°C 以上 | 很热：体力恢复变慢、口渴翻倍，体温往上走 |

身体状态：

- **失温**：体温低于 35°C。手抖（瞄准、钓鱼变难）、走得慢、掉血；回到暖处慢慢好。
- **冻伤**：某个部位空着或衣服结冰，在严寒里风险上升，满了少一截生命上限，要药治。
- **热衰竭**：体温高于 38.5°C。体力掉得快、口渴翻倍、画面发白。
- **中暑**：体温高于 40°C。掉血、走路摇晃，要进阴凉、喝水、浇水降温。
- **晒伤**：白天在强日照下（荒漠、高原、盐原的反光）不戴帽子、没穿长袖久了，体力上限变低，要药膏。

两条常识：

- **热的时候衣服湿了反而凉快**：浇水、穿湿衣服能降温。冷的时候湿是最糟的。
- **荒漠的夜里会冷**：白天中暑、夜里失温，是一种独特的压力，要备一件外套。

### 3.3 衣服

部位从 5 个加到 9 个：

| 部位 | 层 | 例子 |
|---|---|---|
| 头 | 1 | 鸭舌帽、毛线帽、护耳帽、遮阳帽、头巾 |
| 脸与脖子 | 1 | 围巾、面罩、防风镜、太阳镜 |
| 上身里层 | 1 | T 恤、衬衫、保暖内衣、毛衣 |
| 上身外层 | 1 | 夹克、棉服、羽绒服、雨衣、长袍、皮大衣 |
| 手 | 1 | 手套、厚手套、连指手套 |
| 腿里层 | 1 | 秋裤、保暖内裤 |
| 腿外层 | 1 | 工装裤、牛仔裤、加绒裤、雪裤、短裤 |
| 脚里层 | 1 | 袜子、羊毛袜 |
| 脚 | 1 | 运动鞋、靴子、雪地靴、凉鞋 |

每件衣服的数值：

- **保暖**（°C）、**防风**（°C，只算外层）、**防水**（0–1）；
- **遮阳**：减日晒加热，帽子、长袖、长袍才有；
- **透气**：热的时候散热好不好，羽绒服最差，亚麻长袍最好；
- **重量**：穿多了体力消耗变快；
- **完好度**（0–100%）：会磨损，钩到、摔倒、冻住时磨得快，能用针线和布、皮补；
- **湿度**（0–100%）和**结冰**：在车里暖风前、火堆边、房车的晾衣架上能烤干。

约 40 件衣服，按用途分：

- 寒带：羽绒服、皮大衣、雪裤、雪地靴、连指手套、面罩；
- 温带：夹克、牛仔裤、毛衣；
- 雨林：雨衣、速干衣、雨靴；
- 荒漠：亚麻长袍、头巾、遮阳帽、凉鞋；
- 高原：冲锋衣、太阳镜。

它们从哪里来，对上[路边建筑](buildings-80.md)：

- 滑雪小屋出羽绒服、雪地靴；猎人小屋出皮衣；
- 土坯房出长袍、头巾；高原避难所出冲锋衣；
- 汽车旅馆、公寓楼出日常衣物。

做衣服（皮毛做大衣、羊毛织袜子、布缝补）是阶段 8 的制作系统。

### 3.4 庇护和热源

| 地方 | 作用 |
|---|---|
| 车里 | 不吹风；发动机热了能开暖风，有空调零件能开冷气；车窗开着进风 |
| 房车 | 炉子、暖气、晾衣架、床；停着时最好的家 |
| 建筑里 | 不吹风、不淋雨；有炉灶、壁炉的能取暖 |
| 篝火 | 要燃料，会灭；能烤干衣服、烧水、做饭 |
| 温泉 | 泡着暖身体（樱川、镜田的温泉旅馆，沸泉原） |
| 阴凉 | 树下、岩影、建筑里，挡日晒 |

### 3.5 用 50 段算一算

| 场景 | 体感 | 要穿什么 |
|---|---|---|
| 霜林，1 月傍晚，−18°C、风 5 m/s | 体感约 −28°C | 羽绒服、保暖内衣、毛线帽、面罩、连指手套、加绒裤、雪地靴，在外面能待一个多小时。穿一件 T 恤，四五分钟就失温 |
| 柏影丘，5 月白天 18°C | 舒适 | 夹克就行 |
| 赤沙海，6 月中午 25°C 烈日，沙地反光 | 体感约 33°C | 遮阳帽、浅色长袍，每小时喝约 1 升水，否则中暑。夜里降到 5°C，又要穿外套 |
| 风旗原，9 月白天 15°C，4,500 米，紫外线强、风大 | 白天体感约 8°C，晚上零下 | 冲锋衣、太阳镜；不戴帽子、不穿长袖会晒伤 |
| 红土雨林，9 月 30°C、闷热、午后暴雨 | — | 速干衣、雨衣；口渴快，衣服常湿，但湿了反而凉快 |
