# 一页看完：公路生态怎样改变下一段路

34 条公路与地区覆盖七大洲。32 条进入 25 个生态原型；冰岛 Eldhraun 熔岩与南极基地后勤路提供两个极端对照。每条路线都有地形、水与人类活动、植物分带、动物生境，以及 2001–2020 年代表格点的逐月高低温和降水。积雪取陆面覆盖比例；罗斯岛这一项缺测。

| 从车里看 | 地形如何改变生态和道路 |
|---|---|
| 科罗拉多 Trail Ridge | 草甸与山杨离开车窗，云杉、冷杉逐步矮化；约3450米的制作林线以上留低矮花垫、岩块与雪槽。路从林中弯变成开阔分水岭。 |
| 加州 Big Sur | 同一片海雾下，崖头长风剪灌丛，弯进避风溪谷才见红杉。决定树形的是风和水，不必等海拔显著变化。 |
| 云南元阳 | 水从山头林地经过村寨进入层层稻田。按田块同步表现蓄水、返青、收割；蜻蜓沿水渠出现，树留在田界和水源林。 |
| 南非萨比河 | 车沿永久河道经过大无花果树，再回到金合欢和马鲁拉疏林。渔雕栖河边高枝，旱季动物向水面集中。 |
| 南岛 Milford Road | 红山毛榉谷林、雪崩灌丛、隧道与峡湾湿林连续出现；山口鹦鹉与湿谷扇尾鹟有各自的位置。 |

**5–10 分钟的节奏。** 以 60 km/h 试做时，每 5–10 km 给驾驶员一次完整的视野变化。例如让一条峡湾线路先贴岸穿过村田，随后折返上桦林坡，最后开上露岩的积雪高地。资料中的过渡宽度是可压缩的行车距离。若两个地区缺少可信的陆路过渡，就在同一原型内换坡向、河岸或海拔带。当前邻接表保留这种自连接。

**模型排期。** 先做能在多条路上读出位置的素材：河滩圆石、林下蕨叶、湿地莎草、低飞蜻蜓；再补能让单个区域成立的树冠。南方山毛榉家族横跨奥特韦、峡湾和巴塔哥尼亚三型，各自需要本土变体。河岸无花果、帕洛维德与红树虽只服务一个原型，缺少时整段路的树形都会变样。

**精度边界。** 半度左右的再分析格点会混合山脊、谷底与近海，适合定季节，垭口雪缘、单种始花日期与局部林线仍需现场资料校准。积雪坡上的树须同时满足林线、生境和季节条件；旱台地、海柱、耕田、冰缘裸岩各有独立的留白理由。
