# Painted Valley 生态模型清单

按 25 个原型的实际引用计数。同一原型的多个海拔带和同一资产的多个变体只算一次。每一类内按覆盖原型数降序；括号里是具体变体各自的原型数。树表只列 `needsModel`，已有家族的地理变体见路线卡。尺寸是建模量级。同组骨架可共用，色版、冠形与出现地点按物种保留。

近景用两到三档颜料块读出形状，阴面带天光色；中景将零碎叶片并成轮廓，远景留体块与空气透视。鸟在远处优先保留翼型和飞行方式，小型昆虫仅靠近其生境才可见。[美术规格](../../../specs/art/STYLE.md) · [生态原型](../../../src/core/world/data/ecoProfiles.ts)
