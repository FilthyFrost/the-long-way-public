# 方案摘要（本地副本）

完整方案是 Claude Docs 文档「后末日公路旅行游戏 · 方案 v0.1」。这里只留循环里的智能体需要的要点。

## 游戏

1–4 人合作的第一人称公路旅行生存游戏。温馨的后末日：自然收回了世界，开着一辆越来越像家的车，沿无尽公路朝一座传说中的城市走。情绪公式：窗外是壮丽与孤独，车里是温暖与陪伴。

五条支柱：旅途本身就是奖励 · 每 1–2 分钟一个新鲜感（旅途导演）· 车就是家（极简改装、固定槽位）· 和朋友的慢时光 · 温柔的末日（没有僵尸和人类敌人，危险来自天气和自然）。

## 技术栈（已定）

HTML5 + Three.js（WebGL2）+ TypeScript + Vite。车辆物理自研（纯 TS，可在 Node 里无头测试）；世界碰撞与角色用 Rapier（下车探索阶段接入）；联机用 WebRTC（M2）；测试用 Vitest + Playwright。**不要引入其他引擎。**

架构约束：`src/core` 不依赖 three/DOM；模拟用世界坐标（双精度），渲染相对浮动原点；道路与玩法相关的生成必须确定性（整数哈希 + 四则运算 + 自带 sin/cos）。

## 美术方向（M1d，已写成规格）

规格：`specs/art/STYLE.md`（v1.1）+ 参数 `specs/art/style.json`；评分表 `specs/art/rubric.md` v2；研究笔记 `refs/NOTES.md`。

- **对标**：Painted Valley（patch.gg/blendi/painted-valley，代码 MIT、画面 CC0）的源码与 4 张对标图（`refs/targets/painted-valley/`）。只学技术、自己重写，不拷贝文件。ArtStation 1NKWJK 对自动访问返回 403，等人把图放进 `refs/artstation-1NKWJK/`。
- **一句话**：像手绘动画背景——每样东西都按画师的方式上色：少数几个调好的颜色、按明暗档位选色、阴影是有颜色的天光、近处有笔触远处是平涂、云是一团团白色积云、最后用软 Kuwahara 揉成颜料。
- **管线**：HDR 半浮点 + MSAA → 泛光 → 颜料收尾 → 描线（只描车）→ 暗角 → 画师曲线 → 饱和度 → sRGB → 抖动。光照按太阳高度查时段光表（7 个关键帧）。
- **世界**：草地三档色 + 三尺度笔触 + 冷暖色块；树 = 团块 + 叶簇卡片；草簇 + 花带；天际线山体与 32 km 远景地形环；远处雾减半，远山淡而读得出。
- **车舱**：赛璐璐色块 + 暗暖色描线，仪表台是车身漆色。
- **验收**：风格截图组（固定机位）对标图并排存在 `loop/shots/_compare/`；风格统计距离（可比的几张）平均 ≤ 0.35、最大 ≤ 0.6；独立视觉评审十项均分 ≥ 3.5、单项 ≥ 2.5。
