> 2026-11-16 立项，分支 `feat/modcar`。用户确认的方向（见对话 2026-11-15 深夜 / 11-16 凌晨）：

## 2. 结构

```
车（Build）= 车架（Frame）+ 挂点上的零件（PartInstance）
           零件还可以有子挂点：轮毂上装轮胎，发动机上装涡轮
```

- **车架**：车身外壳 + 底盘 + 内饰骨架 + 门/盖的开口。定义：挂点表、底盘质量与重心、悬挂、刹车力、风阻、驱动轮、驾驶员默认眼位、车身碰撞盒。
- **挂点**（mount）：`id`、`cat`（接受哪个类别）、位置与朝向、可选 `fit`（拉伸件的尺寸框）、可选的轮毂属性（前/后轴、转向、驱动、手刹）。
- **零件**（part）：属于唯一一个类别；**同类别的挂点都能装，与车架无关**。每个零件有质量、尺寸、模型、类别专属数值。
- **实例**（instance）：某一个零件实物：车况 0–1、喷漆色、脏、锈、液体（油/机油/冷却液/电量）、胎纹、扎没扎、子挂点上的零件、来源车架（板件用）。
- **推导**（derive）：车架 + 全部零件 → 一份 `VehicleSpec`（现有物理直接用）+ 每轮额外参数 + 显示用的属性卡。每次装卸都重算，`VehicleSim.applySpec` 原地换上（不丢位姿）。

### 2.1 类别（26 个）

车架挂点：`engine` 发动机 · `gearbox` 变速箱 · `radiator` 散热器 · `battery` 电瓶 · `fuelTank` 油箱 · `exhaust` 排气 · `rim` 轮毂（挂在轮毂位 hub 上）· `steering` 方向盘/车把 · `seat` 座椅 · `door` 车门 · `hood` 引擎盖 · `trunk` 尾箱盖/尾门 · `bumperFront` 前杠（含撞角、推雪铲）· `bumperRear` 后杠 · `headlight` 大灯 · `taillight` 尾灯 · `mirror` 后视镜 · `roof` 车顶件 · `armor` 侧装甲 · `horn` 喇叭 · `radio` 收音机 · `handbrake` 手刹 · `gearLever` 挡杆 · `ignition` 点火开关。

零件上的子挂点：`tire` 轮胎（在 `rim` 上）· `turbo` 涡轮（在 `engine` 上）。

板件（`door`、`hood`、`trunk`）的形状属于车架的开口：零件只带“样式”（原装、锈补丁、钢板装甲、铁丝网、冰箱门……）和数值；装到哪个车架就长成那个车架开口的形状。拿在手上或放在地上时，显示它最后所在车架的那块板的形状。
拉伸件（保险杠、车顶件、侧装甲）按挂点的 `fit` 框横向/纵向缩放；其余零件保持自己的尺寸（大发动机塞进摩托就是会露在外面）。

| 情况 | 后果 |
| --- | --- |
| 没电瓶 / 电瓶没电 | 打不着火，灯不亮，收音机不响 |
| 没点火开关 | 打不着火 |
| 没发动机 | 车只能推 |
| 没变速箱 | 发动机空转，车不走 |
| 油箱没装 / 没油 | 打着两秒就熄 |
| 柴油机加汽油、汽油机加柴油 | 突突几下熄火；混一点点只是掉功率 |
| 二冲程机加纯汽油 | 能跑，但车况掉得飞快（拉缸） |
| 水冷机没散热器 / 冷却液见底 | 水温一路涨，红区掉功率，再硬开就拉缸（发动机车况归零） |
| 风冷机 | 不需要散热器 |
| 轮毂位空着 | 那个角拖在地上（车身擦地，火花） |
| 轮毂上没胎 | 钢圈着地：抓地很差、很吵 |
| 左右轮子大小不同 | 往小的那边跑偏；前后大小不同改变重心和姿态 |
| 驾驶位没座椅 | 不能开（站着够不到踏板） |
| 没方向盘 | 只能直走 |
| 没手刹 | 停车会溜 |
| 重东西装得高 | 容易翻；发动机越重越推头 |
| 摩托装大发动机 | 抬头、很难开 |
| 没门 | 风噪大、雨会进来（以后联动淋湿）、风阻 +4% / 扇 |
| 装甲、撞角、铲子 | 重量、风阻上去，撞东西不伤车 |

每条规则都有一句人话的提示（点火自检或看着挂点时显示），代码在 `src/core/modcar/rules.ts`。

## 4. 推导（零件 → 物理）

- **质量**：车架 + 零件 + 液体 + 驾驶员 75 kg。重心按质量加权（零件在挂点位置），得到 `weightFront`、`cgHeight`（含当前轮半径带来的抬升）。
- **转动惯量**：车架基础值 × 质量比，再加重零件的平行轴项（只算 > 10 kg 的件）。
- **轮子**：每个轮毂位的半径 = 轮毂半径 + 胎侧高（没胎 = 钢圈半径，抓地 0.35）；轴的半径取左右平均，左右差进 `SimMods.radiusDrop`（跑偏）。胎宽 → 抓地与滚阻；胎种 → 7 种路面的抓地倍率。
- **发动机**：零件的扭矩曲线 × 排气倍率 × 涡轮曲线（`rpm > spool` 后渐入，`lag` 秒的迟滞）× 车况；没有发动机 = 扭矩 0 且 `engineCanRun = false`。
- **变速箱**：零件的挡位比；主减速比属于车架（差速器）。实际传动 = 挡位 × 主减 / 轮半径——换大轮子顶速上去、起步变软。
- **刹车**：车架给一个刹车力（N），`maxG = 力 / (总重 · g)`，封顶 1.0——加重的车刹车距离自然变长。
- **风阻**：车架 cdA + 每个零件的增量（车顶架 +0.12、尖刺 +0.08、推雪铲 +0.25、缺门 +0.04/扇）。
- **转向**：车架给最大转角与阿克曼；方向盘零件给传动比（显示用）、虚位（`steerPlay`）、响应速度倍率。
- **悬挂**：车架给弹簧频率与阻尼；总重变化后频率按 √(原重/现重) 变软（装满货、装甲车会“沉”）。
- **摩托**：两个轮毂在中线上，物理用“平衡辅助”模式（`spec.balance`，物理线实现）：自动保持直立、按速度和转弯倾斜，重心高 + 扭矩大会抬头。
- **油耗**：发动机的 `lPerKWh` 与 `idleLph`；油箱容量来自油箱零件；燃料种类不对按 §3。
- **属性卡**（拿着零件对准挂点时）：0–100 km/h、极速、油耗、重量、抓地、操控（转向响应 + 侧倾）六项，旧值 → 新值与百分比；由解析估算 + 0.6 秒的无头小仿真得出（`src/core/modcar/stats.ts`）。

### 物理实现说明（物理线 MC2，2026-11-16）

旧四辆车不写任何新字段，走原来的代码，逐位不变（`harness/sim/modcar_legacy.test.ts` 用全状态哈希把关）。下面是新车推导（`derive.ts`）要用到的字段和它们的确切含义。

**坐标与参考**
- `spec.wheelRadius` 是**参考轮半径**（车架设计的轮径）；`cgHeight` 是车子站在参考轮、悬挂处在参考压缩（`rideComp`）时的静态重心离地高。轮毂挂点（硬点）是车身几何，不随轮子、载重变化。推导两种写法都对、物理上完全一样（测试把关）：`wheelRadius` = 车架标称轮径、`cgHeight` 不含轮径抬升；或 `wheelRadius` = 实装平均轮径、`cgHeight` 含平均抬升——后一种请同时给 `emptyHubRadius`（空轮毂刮地的半径，默认 0.45 × `wheelRadius`，否则它会跟着别的轮子变大）。
- 摩托：前后 `track` 写 0，加 `balance: {}`；每个轮子在物理里是一对射线，下面所有逐轮量（索引 0/1 = 前、2/3 = 后）左右两项要写一样。

**轮子**
- `AxleSpec.wheelRadius?`：该轴实装轮半径，缺省 = `spec.wheelRadius`。比参考大 Δ，该轴两角抬高 Δ（车身随之俯仰）；滚动半径、轮速、传动比、极速都跟着变。驱动轮半径不同时按开放差速：每个驱动轮扭矩相同、推力 = 扭矩 / 自身半径，发动机转速按驱动轮平均角速度。
- `SimMods.radiusOffset[4]`（m，+ = 更大）：每个轮子相对本轴半径的尺寸差，左右不同的轮子用它。是真实尺寸：这个角升降、按新半径滚动；同轴左右差会让该轴朝小轮一侧转（侧倾转向，0.15 × 轴倾角，封顶 3°；后轴反向转，所以无论哪个轴不一样，车都往小轮那边跑偏，4 cm 的差在 60 km/h 松手 6 s 偏出约 7 m）。改了之后下一步立即生效，车身"重新落座"，不弹车。
- `SimMods.radiusDrop` 保持原义：爆胎压扁，**只能 ≥ 0**。负值会直接顶弹簧（−0.1 m 冲出 1 m/s，−0.3 m 把车弹起 1.3 m），也不改滚动半径，不要拿它表示大轮子。
- `SimMods.wheelFit[4]`（`WheelFit`）：`Tyre`（默认）；`Rim` 光钢圈——半径照常由轴半径 + radiusOffset 给出（推导给钢圈自己的半径），抓地 × `RIM_GRIP`（0.35）、滚阻 × `RIM_RR`（1.8），路面振感 ×3，`feel.rim` 报钢圈滚动速度（磨地声）；`None` 空轮毂——这个角落到轮毂/刹车鼓上（半径 `spec.emptyHubRadius`，缺省 0.45 × `spec.wheelRadius`），像锁死的轮子一样贴地刮（抓地 0.45 × 轮胎），不滚、不驱动、不制动，radiusOffset 对它无效，`feel.scrape` 报刮擦速度（火花）。滑行时车往空轮毂那边拐、很快停住；后驱给油时对角线承重可能让车反而偏向另一边（驱动轮各自封顶的老模型）。

**单辙车 `spec.balance`**（字段都有缺省）
- 每个轮子拆成相距 `stance`（默认 0.3 m）的两条接触射线，停着站得住（相当于脚撑地）。骑手控制让车身相对重力保持直立（7 rad/s、临界阻尼，最大力矩 = m·g·h）；轮胎侧向力的侧倾力矩由"压弯"承担——物理车身不倾斜，弯中左右射线载荷相等，不会被甩翻。
- `sim.lean`（rad，+ = 向右倒，和 `roll` 同号）= atan(侧向加速度 / g)，按 `leanTime`（默认 0.12 s）跟随，限 `maxLeanDeg`（默认 52°），也不超过轮胎抓地撑得住的角度（冰上约 8°，打滑时不会突然躺下），静止为 0。**渲染**：模型绕车身 x 轴、过 `(0, sim.leanPivotY, 0)` 转 `lean`；第一人称镜头同样要跟着倾。
- 侧倾超过 55° 骑手开始失控、70° 完全放手：车倒下、车身盒着地、`lean` 归零，之后一直躺着直到 `reset()`（弹回来也不再扶）（够猛的冲击才会倒：侧倾角速度 10 rad/s 以内的磕碰扶得回来，12 rad/s 倒）。`assist`（0–1.5，默认 1）调扶车力度。
- 翘头靠俯仰动力学自然出现（扭矩 × 重心高 / 轴距够大就抬头，`sim.wheelie` = 前轮离地、后轮着地），车尾盒着地相当于防翻杆；190 kW 的摩托测得抬头约 23°、持续 5 s 以上。前轮离地的条件大致是后胎有效抓地 ≳ b/h（b = 重心到后轴、h = 重心离地）：重心 0.66 m、b 0.67 m 的车要 μ ≳ 0.95 才稳定抬头，窄胎打折会让 V8 摩托差一点抬不起来。前刹极强 + 重心很高时急刹也会"倒立"甚至翻过车把，没有拦。

**缺件 `spec.absent`**
- `engine`：没有扭矩、永远不运转、0 rpm（也没有起动机可转）、不耗油、没有发动机制动，车只能推或溜；`spec.engine` 随便填，可用 `NO_ENGINE`。
- `gearbox`：不管挡杆在哪都等于 N——发动机随油门空转、车不走、P 锁不住、换挡无效。
- `steering`：前轮固定直行，转向输入无效（轮胎跑偏的 pull 照样起作用）。
- `handbrake`：手刹输入和拉杆锁止都无效，`setParkBrake(true)` 不生效，停坡会溜。注意 `sim.autoHold`（停稳后自动踩住刹车的辅助）不管手刹，有它车照样不溜：人下车或熄火时要把它关掉，“没手刹停车会溜”才看得见。

**载重与悬挂** `src/core/vehicle/rescale.ts`
- `rescaleSuspension(spec, { mass, weightFront, sidewall? }, sidewall?)` / `rescaleAxle(axle, ref, now)`：车架悬挂按参考载荷调，换算到现在的重量和轮胎，等于"同一套弹簧、减振、防倾杆"：频率 ∝ √(参考/现在)，阻尼比同比变小（限 0.12–1.0），防倾杆刚度不变，预载长度不变——更重就多压、`rideComp` 记住参考压缩，所以车身真的下沉（超载停在离缓冲块 10% 行程处，剩下的交给缓冲块）；胎侧高的轮胎是串联弹簧（轮胎刚度取 20 kN ÷ 胎侧高，单位 N/m），胎侧越高越软。
- `AxleSpec.tyreLoad?`（N，每个轮胎）：轮胎的额定载荷，抓地在这个载荷下是标称值，按 (载荷/额定)^−loadSens 变化（和真轮胎一样是幂律：超载 2 倍少约 8 %，限 0.7–1.1）；不给 = 各轮自身静载（静态重量永远不改抓地，旧车就是这样）。`rescaleAxle` 默认填车架的参考角载荷：发动机越重越推头（V8 轿车前重 60 %：不足转向 1.35 → 1.6 °/g），超载的车更早滑（2 吨的轿车极限侧向 g 低约 6 %）。推导可以按轮胎种类给别的额定值（拖拉机胎更高）。

**换件与极端组合**
- 衍生 spec 的 `applySpec`：重心沿车身移动时车身原地平移（轮毂在世界里不动），重心高度、轮径、压缩的变化用刚体移动一次到位（扭不过来的余量在 0.3 s 内渗进弹簧）；停车把 0.29 m 的轮子换成 0.62 m，竖直速度为 0。变速箱挡位变少时当前挡自动钳到最高挡。
- 健壮性（只对用到新字段的 spec）：转动惯量有下限（滚转/俯仰模态 ≤ 40 rad/s，横摆 ≥ 0.025·m·(a²+b²)，三者都 ≥ 同尺寸实心箱的十分之一；正常推导出的值远在其上，只挡垃圾输入）；车身盒至少包住重心上方 0.25 m、下方 0.1 m（重心高过车顶的怪车躺倒时重心不会进地里）；车身盒的底面和顶面各加四个点（两侧 1/3 长处：长车不会用肚子“骑”过坡顶，四脚朝天躺在坡顶上也不会让坡顶戳进车里）；底面接近路面就参与接触（每步对轮子接地平面 0.1 m 内，每 4 步采样地面 0.2 m 内），小轮子的车坐在车身上而不会穿地；轮胎相对路面外倾超过 30° 抓地渐失（60° 剩四分之一：两轮着地的车、倒地的摩托不会再靠轮子发力原地狂转）；`reset(x, y, z, yaw, ground?)` 可以带地面，出生时车身盒不进地里。1000 台随机极端车（120–8000 kg、3–500 kW、≤1200 N·m、0.06–0.75 m 轮、重心 0.3–1.6 m、cdA 0.3–8、缺件、摩托）平地 + 烂路混开 30 s、再全油门测极速：无 NaN、< 300 km/h、自转 < 30 rad/s、车身入地 < 0.2 m（5000 台 × 60 s 实测最深约 0.15 m，都是翻跟头的碰撞）；行驶中随机换件、陡坡（坡度过 30 %）全油门乱打方向、全油门冲进一片墙和桩也不炸（撞墙沿用旧的碰撞算法：重叠最多约一步的行程，旧车 T0 180 km/h 撞也有 0.23 m；12 cm 薄墙 240 km/h 也穿不过去）。衍生 spec 的车身接地弹簧随深度变硬、阻尼按各点的真实有效质量（离高重心远的角很“轻”）；几个点同时要止住时一起解（投影 Gauss–Seidel），不会每个点各自把车弹回去。

**测量与测试**
- `harness/sim/modcar/feel.ts`：`measureFeel(spec, { mods })` 返回 0–60 / 0–100（慢车用 0–60）、平路极速、100–0 与 60–0 刹车距离、30 m 圆最大侧向 g、侧倾梯度、不足转向梯度（摩托另给压弯梯度）、全油门起步是否翘头 + 最大俯仰、柏油 / 碎石最大起步坡度、60 / 90 km/h 油耗；每个 spec 约 0.1–0.2 s。`npx tsx harness/sim/modcar/feel.ts` 打印四个原装车架。

### 5.2 幽灵与属性卡（用户点名最重要；物品信息卡见 §5.5）

- 手上拿着零件时，**4 m 内所有车上所有能装它的挂点**都显示这个零件的半透明幽灵（青白色全息、轮廓发光、慢呼吸）；空挂点实线、已有零件的挂点虚一点并标“替换”。
- 准星对准的那个幽灵变亮，准星旁出现“装上之后”的卡：零件名、装在哪、换下来什么，以及六项属性的旧值 → 新值（变好绿色、变差橙色）；手上那件的信息卡在右边。
- 不能装的原因直接写在卡上（例如“先把轮胎从这个轮毂上拆下来”在本系统里不会出现——替换是允许的；会出现的是“车在动”“够不着”）。
- 准星对准**已装的零件**（空手）：零件描边高亮 + 它的信息卡（§5.5），快捷栏上方写“长按 F / 右键 拆下”。
- 车门、引擎盖、尾箱盖没有自己的模型文件：装在车上就是车架自己的那块蒙皮；它们的幽灵是**这辆车那个位置的车门 / 盖子本身的形状**；拿在手上、放在地上（和零件库的缩略图）用它原装车架（没有就用轿车）的同一块，平躺、外面朝上，风格照样看得出（装甲板、铁丝网、冰箱门和把手、进气口、锈）。

### 5.3 喷漆、清洗、液体

- 调色板 27 色（`src/core/modcar/palette.ts`，和 AD 喷漆罐的颜色一样多），从 `specs/art/STYLE.md` 的色系延伸，保证任何搭配都在画面里成立；每个零件单独上色，车架另有一色。
- 喷漆罐：照 AD，一罐一个颜色，三种大小，漆会用完；对准一个部件按住，2–4 秒从旧色渐变到罐子的颜色。见 §16。
- 脏、泥壳、锈和怎么刮掉它们：见 §15。
- 胎纹：随滚过的路磨（打滑时 8 倍），抓地 = 轮胎原值 × (0.75 + 0.25 × 胎纹)；胎纹每少 0.5 % 就把剩下的抓地力交给物理（`ModSystems.wear`，以前要等下一次装卸零件或加油才生效，磨秃的胎开起来和新胎一样）。
- 液体（照 Arctic Drive 的做法）：油桶加油口（车身侧面的加油口盖，`carView.ts` 把车架的 FUEL_CAP 挂在它前沿的铰链上，打开后露出加油管口；摩托是油箱盖，`fillers.ts` 的 pivot_FILLER）、水壶对散热器的加水口（蓝色盖子）、机油壶对发动机的加机油口（黄色盖子）；后两个盖子和标记 FILLER 由 `fillers.ts` 装到零件模型上（每个模型一处，位置看过模型的俯视图定的）。
  - 加油口盖要先空手打开；手拿对应的壶、准星对准打开的口（在够得着的距离内），壶就离手、按真实大小对过去：壶嘴停在口外几厘米、从视线右侧斜靠过来（不挡住口和液体），`held.ts` 的 `Dock`。
  - 按住 E 倒（壶倾到约 100°，顶上的口 125°），按住右键抽回（`tools.ts` 的 `siphon`：每秒是倒的 0.7 倍；空油桶抽油箱里最多的那种油，桶里有油就只抽同一种）。倒和抽的时候人和视角都不动（`InputManager.lookHold`）。
  - 看得到液体从壶嘴流进口里（`stream.ts`，抽回时流向反过来），屏幕中间一条“油桶 · 汽油 16.8 / 20 L ›››› 方糖的油箱 3.2 / 45 L”，两边的卡上液体条一起动；松手后写“加进去 3.6 L 汽油”。
  - 倒的速度：油桶每秒 2 L，水壶 1.2 L，机油壶 0.6 L；充电器给电瓶充电。

### 5.5 物品信息卡、快捷栏、按键提示（照 Arctic Drive 的布局和样式，只把边框换成卡通的）

### 5.6 把东西放进车里、拿出来（照 Arctic Drive 和 DBH，2026-11-17）

- **能放东西的地方**（`src/core/modcar/cargo.ts` 的 `CARGO_ZONES`，车架模型坐标）：轿车后备箱（盖子下面，净高约 0.49 m）、后座、副驾驶座；皮卡车斗、副驾驶座；房车车厢（走道和家具上）、副驾驶座；摩托后座（只放小东西）。后备箱、后座、副驾驶座要对应的盖子或车门开着（或者拆掉了）才放得进去。
- **地板**是从模型上量的：每块地方第一次用到时，从它的顶上往下用正交相机把这辆车单独画一遍，把高度编进颜色读回来（`src/game/modcar/cargo.ts` 的 `drawFloor`，2 cm 一格）。座椅拆了、车斗里的轮拱、房车的家具都在该在的地方；装卸零件后重画。
- **看哪放哪**：手里拿着任何东西（零件、工具、物品）看向这些地方，东西的虚影出现在视线落到地板的那一点（青色 = 放得下，红色 = 放不下并写原因：太大、这里没地方了）；那一点放不下就在 0.6 m 内找最近的空位，再试转 90°；站不下就躺着放（油桶在后备箱里躺下）。滚轮每格转 15°。按 E 放进去。盖子关着时 E 先开盖子。
- **偷懒的办法**：拿着东西看着车长按 G，自动塞进这辆车最合适的空位（按后备箱 → 后座 → 副驾驶的顺序，最低、最靠里的位置先放，挨着墙和别的东西码整齐），盖子关着就自己打开。车里放不下了会说。
- **拿出来**：看着车里的东西按 E（车里的东西比车身那个粗略的框优先）；或者按 Tab 看清单，点一下直接拿到手上，不用开盖子。
- 放进去的东西固定在车上，开车、急刹、翻滚都不会掉，存档读档后在原位（存档里记着在哪块地方、是不是躺着）。**重量算进车里**（`Build.cargo`，推导的总质量和重心都算上），装满货的皮卡更重、重心更靠后。
- 测试：`harness/sim/modcar_cargo.test.ts`（放得下 / 放不下、叠放、轮拱、码满、躺着放、重量和重心），实机 `harness/shots/modcar_stow.mjs`。

## 6. 渲染与美术（“异环”式 3A 动漫工业水准，同时属于 STYLE.md 的“赛璐璐”画法）

- **几何**：Blender 后台脚本建模——细分曲面车身（保持支撑边）、所有硬边倒角 2–3 段以接住高光、4–6 mm 的板件缝、真实的轮拱与门缝、加权法线；每辆车有完整内饰（仪表台、仪表、方向盘、座椅、地板、门内饰）。三角形预算：轿车 ≤ 80k、皮卡 ≤ 90k、摩托 ≤ 40k、房车 ≤ 120k（含内饰与板件），发动机 ≤ 15k，轮子 ≤ 6k，座椅 ≤ 5k，小件 ≤ 2k。顶点色烘焙 AO（0–1 灰）。
- **材质名约定**（GLB 里材质只靠名字，渲染时换成我们的着色器）：`paint`（主漆，实例色）· `paint_b`（副漆/拼色）· `trim`（黑色塑料、密封条）· `chrome` · `steel`（发动机、支架等金属）· `alu`（铝铸件）· `rubber`（轮胎）· `glass` · `glass_dark` · `lens_head`（大灯灯罩，开灯发光）· `lens_tail`（红）· `lens_amber` · `fabric` · `leather` · `wood` · `plastic_int`（内饰塑料）· `gauge`（仪表面）· `ceramic`（马桶）· `rust`（锈铁）· `emit`。
- **车漆着色**（`src/game/render/carMaterials.ts`）：在现有赛璐璐（亮色 + 单独调的暗色 + 干净的明暗交界 + 有颜色的天光阴影）上加：两条硬边的“地平线反射带”（天空亮带 + 地面暗带，随视角滑动——动漫车最标志的东西）、细而硬的太阳高光、菲涅尔边缘光；铬 = 高反差的反射带；玻璃 = 深色 + 一条斜高光；车灯 = 灯罩内有反射杯几何，开灯走泛光。描线沿用现有的 alpha 编号描线（零件之间、车与背景之间），线色是底色变暗偏暖。脏、锈、喷漆覆盖是手绘感的遮罩，不做写实贴图。
- **幽灵材质**：加色混合的青白全息，菲涅尔边缘 + 横向扫描线 + 呼吸；不写深度、不投影。
- **合批**：一辆车静态部分按材质合成少数几个网格（车漆用顶点属性带实例色），会动的（车门、引擎盖、尾门、车轮、方向盘、指针）单独；整车 draw call 目标 ≤ 40。
- **Blender 规范**：Blender 轴 X 前、Y 左、Z 上；导出 glTF（+Y 上）后正好是我们的 +x 前、+y 上、+z 右。车架 GLB 里：`BODY`（固定外壳）、`INTERIOR`、`GLASS`、`UNDER`；板件对象 `P_<mountId>`，原点在铰链上；挂点空物体 `M_<mountId>`（局部轴 = 零件摆放的轴）。成对的件（轮毂、灯、镜、门板、装甲）只做左边，右边运行时镜像。轮毂原点在轮心，外侧朝 Blender +Y（左）。会脏的网格（车架的车身连车窗、每块板件连它的玻璃、每个零件连它的活动件）各自带一套 `MASK` 展开（`lib/modcar.py mask_uv`：Smart UV Project 按角度分块，玻璃放大两倍，三个像素的间隔装进一个正方形；原有的 UV 留在第一套，有它时 MASK 是 TEXCOORD_1，没有时是 TEXCOORD_0），节点上写 `mask_px`（脏污遮罩的边长，按面积每米 400 像素，64–2048，§15）；车厢里面、底盘、指针、雨刮、加油口盖没有。零件 GLB 一件一个文件：`public/models/modcar/parts/<id>.glb`；车架 `public/models/modcar/frames/<id>.glb`；脚本 `tools/blender/`；`tools/blender/build.py <id|all>` 重建。

## 10. 验收

**自动（`npm test`）**
1. 目录完整：每个零件类别合法、数值在范围内、模型文件存在；每个车架的挂点 id 完整。
2. 互换矩阵：每个零件装到每个车架的每个同类挂点，推导出的规格合法，开 60 秒不爆。
3. 极端组合：随机 1000 辆（含 V8 摩托、拖拉机胎轿车、购物车轮房车、马桶驾驶座），物理不炸、不飞走（速度 < 300 km/h、不穿地）。
4. 手感差异（实测）：换发动机 i4 → v8 的轿车 0–100 至少快 30%；换轮胎 road → slick 柏油过弯极限至少 +12%，road → tractor 至少 −15% 且车高 +0.15 m；加装甲 + 撞角刹车距离至少 +8%；摩托装 v8 必须测到抬头；原厂轿车 0–100 在 12–20 s、极速 130–155 km/h（参考 DBH 公开数据的同级车）。
5. 规则：§3 每一条都有测试。
6. 旧的类型检查、单元测试、构建全部通过。

## 13. 身体：生存（照 Arctic Drive 的普通难度，2026-11-17）

规则在 `src/core/modcar/vitals.ts`（纯数据和算式，不碰画面）；数从 AD 普通难度起步，以后可以调。

- **六项**：
  - 生命 100：不会自己回。吃东西在 5 秒内回一点，止痛片马上回（20 / 35 / 50）。
  - 体力 100：冲刺（按住 Shift 并且在走）每秒 −6，跳一下 −12；停下 2 秒后每秒 +7.5。没体力就只能走。
  - 饱食 100：每秒 −0.035（约 48 分钟见底）；见底后每 10 秒 −2 生命。
  - 水分 100：每秒 −0.03（约 56 分钟见底）；每喝 0.1 L 水 +10；见底后每 3 秒 −3 生命。
  - 体温 37.5 °C：周围比“20 − 穿着的保暖”冷时往下掉（差几度 × 0.0005 °C/s，最低 28 °C），否则每秒回升 0.3 °C；低于 32 °C 冻僵：走路 ×0.75，每 5 秒 −1 生命，暖和回来后还要 30 秒才缓过来。车库里不低于 15 °C，开着的、有车厢的车里不低于 20 °C。衣服还没接上，保暖先按 9 算。
  - 膀胱 0–100：喝多少水涨多少，平时随身体里的水慢慢涨；按住 P 方便（每秒 −18，这时走得很慢）；满了就憋不住，自己尿了。
- **持续效果**：醉了 30 s（视角摇晃，不觉得冷）、精神抖擞 30 s（能量饮料，走跑快 1.5 倍）、闹肚子 / 肚子疼得厉害 30 s（隔一会儿掉水分）、身上暖和 180 s / 浑身发热 300 s（每分钟体温 +5 °C）、冻僵、淋湿了 60 s（保暖 −25）。
- **吃喝用药**（`player.ts` 的 `use`，动作在 `held.ts`）：拿在手上按 F 或右键。
  - 吃东西 3.9 s：0.7 s 拿到嘴边，五口，每口一声咔嚓，再放下；吃完东西从手上消失，饱食和生命在 5 秒内慢慢加上去。
  - 吃药 2.2 s：送到嘴边倒一下。暖身丸有几率上头或闹肚子（小作坊的一半，药厂的四分之一，登山队的 5 %）。
  - 喝是按住喝：瓶口凑到嘴边，瓶身朝前翘起，0.5 s 后开始流（每样有自己的流速，大瓶水每秒 0.3 L），松手就停，没喝完的留在瓶里，信息卡的液体条跟着动。罐子和瓶子第一次打开有拉环或拧盖的声音。
- **屏幕上**（`vitalsHud.ts`，位置照 AD，边框是我们的卡通边框）：
  - 左上角一个圆，中间是体温，左半边绿弧是生命，右半边蓝弧是体力，顶上一个小三角指着气温。
  - 旁边三格：饱食、水分、膀胱，每格底下一条颜色条，饿了渴了变红。
  - 下面一排正在起作用的效果。
  - 体力快没了画面四周变暗，受伤闪红，冷了四周结霜。
- **声音**（`foley.ts`，程序合成）：咬、包装袋、拉环、拧盖、药片、吞咽、受伤、布料（背包背上取下）；喘气、心跳（生命低于 25）、方便时的循环声。
- **倒下**：
  - 快捷栏或背包里有急救包就自动用上，站起来（旧的 10、普通的 25、好的 50 生命，饱食和水分至少回到一半）。
  - 没有的话，存档的页面弹出“你倒下了”：列出恢复点（`restore.ts`：每玩 5 分钟存一个，留最近 6 个），点一个就从那时接着玩；或者“从头开始”。
  - 倒下时不存档，不能操作；开着车倒下会松油门、踩刹车。
  - 不存档的测试页面直接以 50 生命站起来。
- 辅助开关（F2）里可以关掉“生存：会饿、会渴、会冷”，关掉后只剩体力。
- 测试：`harness/sim/modcar_vitals.test.ts`（各项的快慢、掉血间隔、效果、急救）；实机 `harness/shots/modcar_vitals.mjs`（冲刺 5 m/s 和体力消耗、没体力只能走、吃、喝、方便、醉、止痛片、存档读档、急救包、恢复点、关掉生存）。

## 14. 车库：发电机、回收台、制作台（照 Arctic Drive，2026-11-17）

规则在 `src/core/modcar/workshop.ts`（发电机、回收台、锤子的数）和 `crafting.ts`（材料、回收能得多少、配方）；场景、操作和声音在 `src/game/modcar/workshop.ts`，制作台的清单在 `craftUi.ts`。模型照零件的做法程序化建模：`tools/blender/machines/`（发电机、回收台、制作台）、`tools/blender/parts/tools_craft.py`（三把清理铲、锤子）。

- **材料**：废料、有机物、化学品三种，是全局的数，不是拿在手上的东西（存在存档里）。回收进来或制作花掉时，仪表下面弹出一行“+20 废料 共 78”。
- **发电机**（门外，从院子看车库门的右手边墙根）：
  - 新开一局时停着，油箱里有 3 L 柴油，车库没电：灯不亮，充电器不充，回收台和制作台不能用。
  - 按住 E 拉启动绳（0.6 s 一下）：冷车可能要拉两下，最多三下一定着。着了以后整机抖、排气管冒烟、指示灯亮，车库的灯带着一点闪亮起来。
  - 油箱 10 L，每秒烧 0.001 L（3 L 转 50 分钟，和 AD 开局那台一样），不管带多少东西都一样。没油了咳几声熄火，车库停电。
  - 加油和给车加一样：空手按 E 拧开油箱盖，拿柴油桶对着油箱口按住 E 加，按住右键抽回来。汽油占三成以上打不着（“突突两下就熄”）；混一点点能转，但更费油。
  - 关机：看着启动绳或开关按 E。
  - 一根电缆从发电机穿墙进来接到灯的开关盒，再沿地面到回收台，从门上方绕过去到制作台。
- **回收台**（车库里，门左手边的油桶前）：
  - 拿着东西对着进料口按 E，或者直接放进料斗。没电时说“回收台没电”，放在料斗里的东西等来电了自己绞掉。
  - 每件 2.4 s：前 30% 滑到进料口上方，后 70% 被两根刀辊往下绞 0.3 m，越绞越小；可以几件一起绞。机器上方飘出“+20 废料”，边绞边往上数（每 5 一跳，咔哒一声）。
  - 回收能得多少：
    - 物品照 AD，例如材料箱 8–24 废料。
    - 零件按种类和星级：旧发动机 20、V8 180，车门、引擎盖 2–6，轮子算轮毂加轮胎。
    - 工具：油桶 3，清理铲 3 / 7 / 10，喷漆罐 1 或 5（§16）。
    - 装着液体的，每 0.5 L 多 1 有机物。
    - 物品、零件、工具的信息卡都写着“回收能得”。
- **制作台**（车库里，门右手边靠墙）：
  - 按 E 打开：视角移到台前，右边是配方清单。最上面是现有材料，然后是类别（全部 / 工具 / 喷漆 / 零件 / 衣物 / 吃喝药）和每样的价钱；选中一样，看它的图、介绍、要多少材料（不够的标红）、要敲几下锤子。
  - 现在只开放“塑料清理铲”（70 废料），别的都显示锁着：以后找到图纸才能做，价钱照 AD。
  - 点“制作”：材料一次扣掉，台上出现青色的虚影和 1–3 个锤子圆圈（每 25 材料一下，最多 3 下）。点圆圈（或按 E / 空格）敲：抬锤 0.3 s、落下 0.1 s、收回 0.22 s，敲中迸火花。最后一下之后 1 s 东西做好，摆在台面上，“叮”一声，视角回来。
  - 没电时说“制作台没电”。
- **清理铲**：塑料（刀口 10 cm）、金属（22 cm）、金色（25 cm）。刮车窗、车身上的泥和锈下一批接上。

## 15. 脏、泥壳、锈和清理（照 DBH 的分层和工具，AD 的冰铲，PowerWash 的手感，2026-11-17）

规则在 `src/core/modcar/tools.ts` 的 `CLEANERS`（每种工具一遍刮掉多少、刀口多宽、能用多久）；遮罩在 `src/game/modcar/grime.ts`，着色在 `src/game/render/carMaterials.ts`，刮的操作在 `player.ts`（`Scrub`），游戏这边的收尾、声音、碎屑在 `ModGame.ts`、`flakes.ts`、`scrubHud.ts`，存档里的遮罩在 `grimeStore.ts`（浏览器的 IndexedDB）。

- **三层**（从上到下）：
  - **浮灰和泥点**（`dirt`）：越开越脏。普通公路两个多小时到“很脏”（0.8），土路、碎石路快一倍，下雨的软路面再快一些；车身下半截、轮拱、车尾最多。
  - **泥壳**（`crust`，新加）：老车、废车、在谷仓里放了多年的车上才有，开车不会长。厚的一块块糊着，车窗上是一整层：先是看不见里面的厚壳，薄了是一层能隐约看见车里的雾。
  - **锈斑**（`rust`）：泥壳刮掉以后露出来的锈坑。现在只出现在捡来的旧件和老车上，不会自己长（“只长在漆掉了的地方”等有了磕碰再做）。
- **工具**（拿在手上，对着车身或零件按住左键：视角停住，鼠标直接带着工具在表面上走；松开停下）：

  | 工具 | 刀口 | 一遍刮掉（浮灰 / 泥壳 / 锈） | 能用 |
  | --- | --- | --- | --- |
  | 海绵 | 14 cm | 0.85 / 0.05 / 0（浮灰一遍就掉，留下一道湿亮的痕迹，十几秒后干） | 24 m² |
  | 塑料清理铲 | 10 cm | 0.6 / 0.3 / 0.03 | 60 m² |
  | 金属清理铲 | 22 cm | 0.6 / 0.34 / 0.04 | 140 m² |
  | 金色清理铲 | 25 cm | 0.65 / 0.4 / 0.05 | 320 m² |
  | 钢丝刷 | 11 cm | 0.3 / 0.2 / 0.34（三遍刷到见金属） | 40 m² |

  - 谷仓车的泥壳（0.62）塑料铲两遍刮掉；车窗也是两遍：第一遍刮掉厚壳、留下一层雾，第二遍透亮（照 AD 的冰铲）。
  - 一辆车外面大约 12 m²，一把塑料铲大约刮两辆车。“能用”按刮过的面积（刀口宽 × 走过的距离）算，用完写“用坏了”，不能再刮，可以丢进回收台。
  - 刀口带着走过的方向转：一条带子总是刀口那么宽。工具贴在表面上，跟着笔画微微晃。
- **遮罩**：每个开始清理的零件（整车车身算一个，车窗跟着车身；车门连它的玻璃）有一张自己的遮罩（`mask_px` 见方，RGBA8：剩下多少浮灰、泥壳、锈，以及哪里是湿的）。第一次有工具碰到它时按它当时的脏度铺满，之后每一笔只改刀口下面那一条（贴着表面 2.5–3 cm 以内都算：一块玻璃的两面一起干净），所以刮过的地方是边缘清楚的一条带子，没刮的地方原样不动。这个零件清理时单独画，不和别的零件合批。开车时脏度涨了，遮罩跟着整片涨上去。零件拆下来、放到地上、拿在手上、装到别的车上，遮罩跟着它。
- **进度和收尾**（照 PowerWash）：
  - 每个零件分成几块各算各的：车身是车头、车尾、左侧、右侧、车顶，加上前挡风玻璃、后窗、左右车窗；一个零件是它的漆面和它的玻璃。
  - 从这几块各自朝外的方向看（车的其他部分挡着的不算，底下不算），比较“现在还看得见多少脏”和“没刮之前有多少脏”。刮的时候工具旁边一个圆圈写着这一块的名字和干净了百分之几。
  - 一块干净到 92% 以上就自动收尾：剩下的小点一起消失，这一块白光一闪，“叮”一声，上方写“前挡风玻璃 · 干净了”（泥壳刮掉了还有锈：“还有锈：用钢丝刷刷”）；锈刷干净另有一声。
  - 整个零件都干净了，它的脏度归零、遮罩释放；整辆车都干净了，放一段完成音，写“里里外外焕然一新！”。
  - 按 H，两秒内把还剩下的脏（浮灰、泥壳、露出来的锈）标成橙色。
- **满足感**：刮下来的东西照它的颜色往下掉（泥壳是深褐色的碎片，浮灰是浅色的渣，刷锈掉橙色的屑，海绵是泡沫），落在地上停一会儿再消失。声音按刮的快慢、刮的是什么变化：玻璃“吱”、漆面“嚓”、锈和泥壳“咔啦”、软泥“噗”、钢丝刷“沙沙”、海绵的水声（声音单独合成，见 `docs/MODCAR_AUDIO.md`）。
- **对玩法的影响**：
  - 车窗糊着泥壳，从车里真的看不出去：厚的地方窗户画两遍，第二遍不透明，后面的东西连轮廓线都被挡住。
  - 大灯脏了变暗（浮灰最多暗四成，泥壳更多），清理中的大灯按量出来的剩余算。
  - 车身脏本身只影响好不好看。
- **开局**：教学的谷仓车（方糖）浮灰 0.5、泥壳 0.62（车门、引擎盖、尾门、保险杠、灯、后视镜、轮毂各自上下浮动）、锈 0.1，车窗全糊死；不是教学的那辆泥壳轻一些（0.32）。教学黑板在“在制作台做一把清理铲”之后加了一步“拿清理铲刮干净挡风玻璃”：没拿铲子时标记指着铲子，拿着时指着挡风玻璃。
- **存档**：遮罩太大，不放进存档本身；存档时把改过的遮罩压缩后存进浏览器的 IndexedDB（一辆车几百 KB），零件上记一个 `grime` 标记；读档时按标记取回（连同已经“叮”过的块，不会再叮一次）。取不回来就按零件原来的脏度显示。新开一局时一起清掉。
- **模型**：见 §6 的 `MASK` 展开（`tools/blender/lib/modcar.py mask_uv`，车架 `frames/_kit.py mask_frame`，零件在 `parts/_kit.py finish()` 里）。
- 测试：`harness/sim/modcar_grime.test.ts`（各工具几遍刮干净、刀口和寿命、用坏了、车身和零件怎么分块、对三角形的射线和 three 的一致）；实机 `harness/shots/modcar_grime.mjs`（谷仓车糊着、车里看不出去、黑板上的新步骤、塑料铲刮挡风玻璃：一遍留雾两遍干净、黑板这一步打勾、铲子会磨损、海绵擦不掉泥壳而铲子能、H 高亮、地上的轮毂、存档读档后遮罩原样回来）。

## 16. 喷漆（照搬 Arctic Drive，2026-11-17）

规则在 `src/core/modcar/paint.ts`（三种罐、颜色、一层漆怎么上、罐子怎么用完）；喷的操作在 `player.ts`（`PaintAim`、目标 `paint`），游戏这边的上色、闪光、声音在 `ModGame.ts`（`paintCast`、`spray`、`stepSpray`），手上罐子的姿势在 `held.ts`（`aimSpray`、`shake`），雾和漆点在 `sprayMist.ts`，车库喷枪在 `garageMachines.ts`。

- **罐子**：一罐一个颜色，罐身就是这个颜色，罐身上的标签条（小罐一条宽的，中罐两条，大罐三条）。容量、喷速照 AD：

  | 罐 | 容量 | 喷速 | 喷好一个部件 | 一满罐喷几个 | 星 | 重 | 回收 |
  | --- | --- | --- | --- | --- | --- | --- | --- |
  | 小喷漆罐 | 10 | 0.25 | 4 秒 | 2.5 个 | 1 | 0.35 kg | 1 废料 |
  | 喷漆罐 | 50 | 0.35 | 2.9 秒 | 17.5 个 | 2 | 0.35 kg | 1 废料（八种基本色），5 废料（其余颜色） |
  | 大喷漆罐 | 100 | 0.5 | 2 秒 | 50 个 | 4 | 0.4 kg | 5 废料 |

  - 喷的时候每秒用掉 1 单位。一辆轿车有 11 个能喷的东西（车身、四扇门、引擎盖、尾门、两个保险杠、两个后视镜），一中罐能把一辆轿车整车换色再多喷几件。
  - 捡到的罐子不是满的：小罐 2–10、中罐 15–50、大罐 50–100（整数，均匀抽）。做出来的是满的。
  - 喷空的罐子留在手上（快捷栏那格的条见底，写“罐子空了：丢进回收台”），按下去只“噗噗”两声。
- **颜色**：27 种。八种基本色（炭黑、钴蓝、苔绿、粉、梅紫、樱桃红、白、向日葵黄）小罐只有这八种，大罐是其中七种（没有黄），中罐 27 种都有（一共 42 种罐，和 AD 一样）。比原来的 24 色多了云杉绿、银灰、钴蓝。
- **能喷什么**：车身算一个（车窗也算车身的，对着车窗喷就是喷车身）；每扇门、引擎盖、尾门、前后保险杠、两个后视镜各算一个；拆下来放在地上的车门、盖子、保险杠也能喷。发动机、座椅、轮子、车灯不能喷（对着它们写“不能喷漆”）。铁丝网车门没有蒙皮，不能喷；装甲门、冰箱门喷了以后就是喷的颜色。
- **怎么喷**（照 AD）：
  - 拿着罐子对准一个能喷的东西，按住 E 或左键：它的颜色从现在的颜色均匀地渐变到罐子的颜色，准星外的圈跟着走；整个部件一起变，不是喷到哪染到哪。
  - 每一刻先上漆，再扣罐子里的漆，而且只在这一层还没上满的时候扣：已经是这个颜色的东西喷了不耗漆（写“已经是樱桃红了”）。
  - 喷到一半松手，它就停在中间色，下次接着喷；换一罐别的颜色喷，从它现在的颜色重新开始。喷到一半的颜色会存档。
  - 车身单独算：车身第一次换颜色时，原来跟着车身颜色的车门、盖子、保险杠、后视镜留住自己现在的颜色，要一件一件喷。整辆车（车身和所有能喷的东西）都喷成同一个颜色时，写“从头到尾都是樱桃红了！”（AD 的成就“Class Above All”）。
  - 对准能喷的东西时，E 和左键只管喷：门不会在喷嘴底下打开，东西也不会被捡起来（AD 的锁）。
  - 喷漆盖不住脏和锈（漆是部件本身的颜色，浮灰、泥壳、锈照样在上面）：对着脏的部件喷时写“脏东西和锈盖不住：先刮干净再喷”。
- **画面**：
  - 喷的时候罐子抬到眼前，喷嘴转过去对着喷的地方。
  - 喷嘴前一道窄扇形的彩色雾团（每秒四五百团，0.15–0.5 秒散掉，往前飘、边飘边变大，颜色是漆色暗一点、淡一点，照 AD）；喷的地方再有一层淡淡的漆雾和一些溅在表面上的漆点。
  - 一个部件喷满时白光一闪，“叮”一声（`paint_done`），上方写“左前车门 · 喷成樱桃红了”。
  - 快捷栏那一格下面一条剩余漆量，是漆的颜色；物品卡上有剩余漆量、颜色、喷好一个部件要几秒、还能喷几个。
- **声音**（单独合成，`docs/MODCAR_AUDIO.md` §3.2）：拿起罐子时摇一摇（`spray_rattle`，里面的钢珠咔啦咔啦，同一罐 30 秒内不再摇）；按下去“嗤”地打开阀门（`spray_start`），按住是喷气的嘶嘶声（`spray_hiss`，罐子越空声音越低一点）；喷空了咳几声停下（`spray_sputter`）。
- **去掉的东西**：原来的“滚轮换颜色”和屏幕上那排色点；喷漆不再有 1.2 秒的固定时间。
- **车库**：AD 的开局车库有两个小罐（樱桃红、钴蓝，都不满）；我们还没有能捡罐子的世界，先在旁边多放一个中罐（青绿）和一个大罐（白）。压缩机上的喷枪：拿着一罐漆按 E，整辆车所有能喷的东西一起上漆，比手喷快一倍，用的是罐子里的漆、规矩一样（已经是这个颜色的不耗漆，漆不够就喷到一半停下）；它前面写着大概要多少漆。
- **制作台**：“喷漆”一类，27 个配方，每种颜色一个中罐，20 有机物 + 10 废料（AD 的价钱），现在都锁着（AD 也是默认锁着，要找到图纸）。
- **模型**：`tools/blender/parts/tools.py` 的 `spray_s` / `spray` / `spray_l`（和别的工具一样程序化建模：罐身 `paint`，标签条 `paint_b`，罐底、罐肩、阀座是金属，喷嘴朝 +X；小罐矮粗，大罐又高又粗），`public/models/modcar/tools/spray_s.glb`、`spray.glb`、`spray_l.glb`。
- **开发者面板**：工具页的“喷漆罐”一组，42 罐（三种大小 × 各自的颜色），都是满的。
- **以后可以升级**：遮罩做好了（§15），可以改成“喷到哪染到哪”；要不要以后再说。
- 测试：`harness/sim/modcar_paint.test.ts`（三种罐的数、渐变和用量、已经是这个颜色不耗漆、喷到一半停住和换色、喷空、捡到的罐子不满、名字和模型、回收、配方、能喷什么、车身单独换色时车门留住颜色）；实机 `harness/shots/modcar_paint.mjs`（车库里的四罐、对准车门的提示、喷嘴底下不开门、喷 1.4 秒一半颜色和雾、松手停住、喷满用掉 2.9 单位、再喷不耗漆、车身单独换色、小罐喷空、发动机和车灯不能喷、地上的保险杠、喷枪整车喷、喷到一半存档读档）。

## 17. 车库在世界里（照 AD 的无缝衔接，2026-11-17）

做法在 `src/game/modcar/seamless.ts`（世界的选项、车库和世界拼起来的地面）、`garageOutdoors.ts`（院子：水泥地坪、碎石车道、草地、篱笆、老树，以及它作为世界一块地的高度）、`src/core/world/terrain.ts`（`WorldOptions`：公路从哪里开始、起点后面没有路、调用方的平整地块）、`spine.ts`（`SpineOptions.start`）；`ModGame.ts` 里 `seamless` 打开时车库和世界同时存在。

- **一个世界**：车库是世界里的一个地方，公路从车库院子的大门口开始（`x = 26`，和院子一样高），一直往 +x 延伸（前 160 m 是直路，然后照常弯弯曲曲）。起点后面没有路：车库后面就是田野。离车库 1.25 km 以内没有别的建筑和废车（AD 是 500 m）。
  - 从车库门口往外看，碎石车道穿过篱笆的大门接上公路，公路一直通到天边；从路上回头看，红色的谷仓车库就在路的尽头。
  - 院子（篱笆以内和外面一圈，约 53 × 46 m）是世界的一块平地：世界的地形在这里按院子的高度铺，不长世界的树、不立电线杆、不长世界的草（院子自己的草地和树还在）；出了这块地，世界的草地、树林、山就接上了。
  - 车轮和脚踩的地面：院子里是车库自己的（地坪、车道、草地、工作台），院子外面是世界的；两边在院子边上一样高。
- **开出去、开回来**：开过大门就是在公路上，没有黑屏，没有传送；车库、车库里别的车、地上的零件和工具都留在原处。掉头开回来，车库还在路的尽头。离开院子时写一句“上路了。想回车库，掉头开回来就是。”
- **“在车库还是在路上”**：只看人（开车时看车）在不在院子这块地上，每帧算一次（教学的“开出车库”一步、开发者面板的里程、存档里的地点都用它）。室内（谷仓里面）不下雨、不低于 15 °C；院子里是室外。
- **灯光和阴影**：车库里的灯、窗户进来的光照旧；眼睛离车库 60 m 以内时，大阴影图固定在车库上（窗户投下的光斑清楚），再远就跟着人走（和在路上一样）。进出大门时曝光照旧在门口一米半里慢慢变。
- **开局**：加载画面会等车库周围的世界（地形、公路、树、草）建好再进游戏（最多 15 秒）。新开一局（连按两次 F9、开发者面板的「从头开始」）换一个随机的世界种子；同一局里世界不变。第一次打开游戏用固定的种子。
- **存档**：存整个世界里的位置——每辆车、地上的每样东西、人在哪里、坐在哪辆车里，加上世界的种子（`world: { seed }`、`seat`）。读档回到同一个世界、同一个地方；在路上存的档，读回来还坐在那辆车里，车库还在路的起点。旧的“在路上”存档（只存了里程和一辆车）照旧能读。
- **不变的**：老版游戏的世界一点没变（这些选项只在 ModCar 里打开）；`?start=road` 的测试和截图照旧；`?garage=stub` 的简易车库还是单独的场景。
- 测试：实机 `harness/shots/modcar_seamless.mjs`（新开一局是一个世界、公路从大门口开始且和车道一样高、皮卡开出大门上路没有黑屏也没丢东西、开到 160 m 外、掉头开回院子、东西都还在、再开出去在路上存档、读回来同一个世界还坐在车里、位置不差 1 m）。

## 18. 轮胎磨损和爆胎（照 DBH 的四个阶段，2026-11-17）

做法在 `src/core/modcar/tyres.ts`（阶段、每米磨多少、还能跑多远、爆胎的几率、湿地的抓地）、`systems.ts`（开着车磨、爆胎、雨天打滑）、`parts.ts`（每种胎的寿命）；仪表盘的四个小胎在 `ui.ts`，胎面磨平的样子在 `carMaterials.ts`。

- **四个阶段**，每个阶段是轮胎寿命的四分之一：全新（胎纹 75 % 以上）、有点磨损、很旧、听天由命（25 % 以下）。物品卡写着现在是哪个阶段、离“听天由命”（或离磨平）还有多少公里、新胎在柏油路上能跑多远。
- **寿命**（柏油路，公里）：普通胎 40（一个阶段 10 km）、白边胎 36、越野胎 46、雪地胎 34、光头胎 16、拖拉机胎 70、摩托胎 30、卡车胎 60。
  - 碎石路、土路、沙地磨得快：普通胎 1.3 倍；越野胎反而慢（0.7 倍），拖拉机胎 0.6 倍，光头胎 2.2 倍。雪和冰上 0.6 倍，草地 0.8 倍。
  - 打滑（甩尾、原地烧胎、急刹抱死）磨得是滚动的 6 倍。
- **爆胎**：只有“听天由命”阶段的胎会爆，越秃越容易——刚进这个阶段每公里 2 %，磨平了每公里 15 %；碎石路、土路上再乘 2.5。爆了就扁了：那个角塌下去，车往那边偏，屏幕上写“砰！左前胎爆胎了。”，声音是一声闷响加漏气声，接着开起来瘪胎“啪嗒啪嗒”拍地（一圈一下），胎甩掉了就是钢圈磨地的声音和火花。
- **下雨**：旧胎在湿的柏油路、碎石路上抓地变差，磨平的胎最多少 35 %；新胎、干路面不受影响。
- **看得见**：仪表盘右边四个小方块是四个轮胎（从上往下看：左前、右前、左后、右后），颜色是阶段（绿、黄绿、橙、红），爆了的闪，没装胎是虚线框。胎面磨平了，滚动的那一圈变得光滑、发灰、有点反光；胎侧不变。
- 测试：`harness/sim/modcar_tyres.test.ts`（四个阶段、40 km 和每阶段 10 km、路面和胎种的快慢、打滑 6 倍、只有最后阶段会爆、湿地抓地、真开着车磨到爆胎）；实机 `harness/shots/modcar_wrecks.mjs` 的第 6 步（仪表盘四个胎的颜色）。

## 19. 路边废车当宝箱（照 DBH 的事故车、AD 的弃车，2026-11-17）

做法在 `src/core/modcar/wrecks.ts`（一辆废车剩什么、是什么星级、什么成色、车里留下什么）和 `src/game/modcar/wrecks.ts`（废车在世界里出现、消失、记住、被拿走，稀有零件的闪光）；世界摆废车的位置不变（`src/core/world/sites.ts`），只是 ModCar 里不再画世界自己的那个废车壳子（`WorldView.skipObject`），也不再用它的碰撞盒。

- **每辆废车都是一辆真车**：走到离它 230 m 以内，它就变成我们的一辆车（轿车、皮卡、房车，偶尔是摩托），停在世界摆它的地方，物理上落地停稳；可以拆零件、开车门和引擎盖、翻后备箱和车斗、抽油、刮泥、喷漆；走开到 420 m 以外它就消失。同一辆废车每次来都一样：剩什么、什么成色都由它的编号决定。
- **剩下什么**：车门、引擎盖、后备箱盖、保险杠、灯、后视镜大多还在；每个轮子六成还在（放了很久被拆过的只剩两成，常常是架在轮毂上）；其余的（发动机、变速箱、散热器、电瓶、油箱、排气、座椅、方向盘……）剩 3 到 8 样（被拆过的 1 到 4 样）。零件大多是这车原厂的，有时候差一点（锈门、三挡变速箱），有时候是别的车同档次的；一辆车的轮子是一套。
- **好东西（发现）**：在普通零件之外，有的废车上有 ★3 到 ★5 的好零件——V8、平对六缸、五挡变速箱、涡轮、铝合金轮毂（整套）、雪地胎或光头胎（整套）、赛车座椅、引擎盖进气口、装甲门……
  - 离车库近的地方大约四辆里有一辆有好东西，★4 以上的十辆里不到一辆，★5 一百辆里一辆；越往远走越多，一百公里外差不多每辆都有一样，★5 大约十五辆里一辆。
  - 十二辆里有一辆“不一般”的车，多两样好东西。
- **成色**：零件 25 % 到 85 %，又脏又锈，盖着泥壳；轮胎磨到 5 % 到 70 %，四分之一是瘪的；发动机里剩一点机油，散热器一点水，电瓶快没电；四成的车油箱里还有 1 到 8 升油（是它发动机用的那种）。车身和每块板子常常各是各的颜色，拼凑感。
- **车里留下的东西**：七成的车里有 1 到 3 样东西（被拆过的只有四成，而且只有一样）——吃的、喝的、药、杂物、零件箱、衣服，偶尔是背包、头灯、大锤，越远越好；还有时候是一罐喷漆、一个底下有点油的油桶。放在后备箱或车斗里（AD 式的装箱）。摩托上没有东西。
- **发现它**：没被盖住的稀有零件（★4 以上、不是这车原厂的）隔几秒闪一下光（★5 是金色），45 m 以内看得见；走到 4 m 以内能听到一点细碎的叮叮声。第一次打开一辆废车的引擎盖：锈铰链“吱呀”一声，屏幕上写下面是什么和几颗星（“引擎盖下面：直列四缸柴油 2.4 ★★★”），是好东西就响一声提示音，越好越亮；后备箱里有东西就列出来。物品卡上 ★4、★5 的星是金色的。
- **动过的车会记住**：拆了零件、装了零件、拿走了东西、刮了泥、喷了漆、抽了油、推开了 1.5 m 以上，走开时就照原样记住，再来还是那样；存档里有（`wrecks.kept`）。坐进去，或者把它拖走/开走 15 m 以上，它就归你了：从此是你自己的车，走多远都不会消失（`wrecks.gone`）。
- **代价**：同时最多两三辆废车在场，一次只生成一辆；旁边站着一辆废车，一帧约 5 ms。
- 测试：`harness/sim/modcar_wrecks.test.ts`（同一个编号永远是同一辆车、好东西的多少随距离变、剩多少零件、摩托和汽车的零件不混、双胎只在原来是双胎的地方、轮胎成色和瘪胎比例、油箱里的油是发动机那种、车里的东西、每辆废车都能算出车况）；实机 `harness/shots/modcar_wrecks.mjs`（30 km 里的废车、走过去它就在那儿并且停稳、世界的碰撞盒没了、车里有东西、好东西会闪、打开引擎盖说下面是什么、拆一个零件走开再回来还是那样、存档读回来还记得、坐进去就归你、一路走过去废车来了又走既不落下也不重复、仪表盘的轮胎）。

## 20. 沿途的地点：进门、翻柜子、加油、在路上制作（照 AD 的建筑，2026-11-18）

做法在 `src/core/modcar/loot.ts`（每种柜子、箱子里有什么，路边散放的东西是什么，加油站有多少油）、`src/game/modcar/places.ts`（地点在身边时出现：能翻的柜子、加油机、地上的东西，走远了收起来，翻过的、拿走的、加油机剩多少油都记住）；修车铺的机器在 `ModGame.makeRoadWorkshop`（用车库同一套 `workshop.ts`）；地点的分布在 `src/core/world/sites.ts`（`WorldOptions.placeOdds`、`secondPlace`，只在 ModCar 里打开）。

- **地点更密**：老版世界大约 3 km 才有一个地点；ModCar 里几乎每段路（1.25 km）都有一个，八成的路段还有第二个（离第一个至少 300 m，不会是加油站），平均 1.2 km 一个，再加上路边的废车和箱子，几百米就有东西可停。加油站的间隔不变（最多 22 km 一个，开局几公里内就有）。
- **翻柜子**：对着柜子、箱子、货架、柜台、工具箱、铁桶按住 E 翻找（0.8 秒，听得到翻东西的声音），然后弹出里面东西的清单（和 Tab 看车里东西是同一个清单），选中按 E 拿到手上。翻过一次就记住了：再看就是“还剩几样”，空了就写“空了”。一成左右的柜子是空的（“有人先来过了”）。
- **什么地方有什么**：
  - 厨房的碗柜：吃的、喝的、杯子盘子之类的杂物，偶尔有药。
  - 衣柜：衣服，偶尔有背包、枕头。
  - 加油站柜台：零食、饮料、止痛药、机油壶，偶尔有头灯、喷漆。
  - 商店货架：吃的、喝的，一点药、营养品箱。
  - 工具箱：零件箱、喷漆罐、清理铲、修理包、小零件（钥匙门、喇叭、档杆、手刹、车灯、后视镜、收音机）、机油壶、海绵、钢丝刷。
  - 修车铺的零件架：大件——发动机、散热器、电瓶、变速箱、排气、带胎的轮毂、轮胎、涡轮、座椅、方向盘、保险杠……
  - 路边的木箱：杂物、零件箱、吃的喝的、旧衣服、偶尔一罐喷漆。铁桶里多半是杂物，常常是空的。
  - 越往远走越好：和废车一样，远处更容易翻到 ★3 以上的东西（★5 的发动机、好修理包、好止痛药……）。
- **地上的东西**：老版世界在地点里散放的东西，在 ModCar 里换成我们的物品：轮胎、油桶、机油壶、吃的喝的、电瓶，其余的变成这个地点该有的可回收杂物（民房是杯子、枕头、台灯，加油站是路锥、水桶、招牌，修车铺是漆桶、塑料筐……）。捡走或挪动过就是你的了，不会再出现。
- **加油站**：每台加油机不是汽油就是柴油（第一台汽油，第二台柴油……），每个加油站有 90–200 L 汽油、50–150 L 柴油，用完就没了。拿着油桶对着加油机按住 E 灌油（每秒约 2.8 L）；把车停到加油机旁边（4.5 m 以内），空手对着加油机按住 E，进度环满了油箱就加满（听得到油枪拿起、电机嗡嗡、加满时“咔哒”一声），屏幕上写加了多少升。加的时候车的加油口盖自己打开，油枪从加油机的挂钩上取下来插进加油口，一根油管从加油机垂下来连到油枪上；加满后过一会儿油枪挂回去（`siteArt.ts` 的 `stepPumps`）。
- **修车铺能用**：路边的修车铺里有和车库一样的制作台（原来那张旧工作台的位置）、旁边的回收台，墙外一台柴油发电机（油箱里有 3 L 柴油，拉绳启动）。在路上就能回收杂物换材料、做东西，不用开回家。每个修车铺的发电机各是各的，油量和开关都记住。
- **记住的**：翻过哪些柜子、柜子里还剩什么、每个加油站还剩多少油、拿走了哪些地上的东西、每个修车铺发电机的状态，都在存档里（`places`）。
- **车开进房子里**（`src/game/modcar/floorGround.ts`）：房子立在比地面高一截的平台上（十几二十厘米）。现在车轮在平台范围里就以平台顶面为地面，修车铺举升机上的废车就停在地板上。以前车轮按平台下面的地面算，车身陷进平台，被物理一把推出门外好几米。开车进门时会颠一下，跟上马路牙子一样。比路沿高的台面（门廊、码头栈桥）还是挡着车。
- **我们自己的画法**（`src/game/modcar/siteArt.ts`、`buildingKit.ts`、`doors.ts`，模型在 `tools/blender/places/`）：
  - **家具和杂物**：68 个模型（碗柜、衣柜、床、桌椅、冰柜、柜台、各种货架、工具箱、举升机、工作台、加油机、雨棚、招牌杆、铁桶、轮胎堆、木箱、长椅、柴堆、晾衣绳、菜地、信箱、栅栏、帐篷、码头、观景台、望远镜、护栏、管道、水塔、筒仓、房车、购物车……），按地点里东西的尺寸和种类选用：商店靠墙的货架和中间的岛架不一样，修车铺是铁架子，放在工作台上的是矮工具箱，招牌杆按高度有三种，栅栏和护栏按 2 m 一节重复、末端补一根柱子、三节里偶尔有一节坏的，码头一节节铺到水上、最后一节带梯子和系缆桩。每个地点的东西合成一个网格（几个绘制调用）。颜色：加油站的东西都是它的牌子色，家里的家具各有各的漆，帐篷是露营的颜色；屋里的只落灰，露天的更脏、铁的会锈；油漆是哑光的，不像车漆那样反光。
  - **翻过的柜子是开着的**：碗柜、衣柜、抽屉柜、工具箱、木箱、桶这些有门、抽屉、盖子的，开始翻找时门打开、抽屉拉出、盖子掀开（0.45 秒），翻过以后一直开着；走远了再回来，翻过的还是开的。一眼就能看出这间屋里哪些翻过了。
  - **建筑**：42 块建筑套件（墙、墙角柱、墙脚、檐口、门框、过梁、窗台、窗、百叶窗、三种门、卷帘门、坡屋顶、屋脊、山墙、单坡屋顶的三角墙、平屋顶、女儿墙、封檐板、柱子、横梁、雨篷、台阶、烟囱、地板、水泥地、招牌和十个图标），照建模给的装配规则拼成路边的每一栋房子：墙在门窗四周留口，门框、过梁、窗台包住口子；坡屋顶按坡度剪切（铁皮的厚度、波纹、封檐板不变形），五分之一左右的屋面板是锈的；农舍有前廊、烟囱、百叶窗和天花板，商店是平顶、女儿墙、条纹雨篷，招牌立在女儿墙上，加油站小屋和修车铺是单坡或平顶，修车铺的卷帘门卡在半中间（人和车都能从下面过），小棚子是两扇木板门。开口的位置、门的宽度、屋顶高度都和老画法一样，所以墙的碰撞、屋里的柜子都对得上。什么都不镜像。
  - **门能开关**：民房的木门、商店和加油站的玻璃门（一对的话两扇一起开）、小棚子的两扇木板门，都挂在门框上，空手对着按 E 开或关（民房的门吱呀一声，商店的门响铃铛），往屋里转 95°。关着的门挡人也挡车。大多数门是关着的，小棚子的门四成开着；开过关过的都记在存档里（`places.doors`）。
- 测试：`harness/sim/modcar_siteart.test.ts`（每个地点的每样东西要的模型都有、文件都在、各种变体都用上了）、`harness/sim/modcar_buildings.test.ts`（每栋房子的每块构件都是套件里的、文件都在、没有一块是镜像的、门正好在墙留的口子里、和口子一样宽、关上时贴着墙的中线、没有东西伸出屋檐前廊雨篷之外）；实机 `harness/shots/modcar_places.mjs` 还查了碗柜、衣柜、木箱、工具箱翻找时门和抽屉打开、走开再回来还开着。
- 测试：`harness/sim/modcar_loot.test.ts`（同一个柜子永远一样、各种柜子装的东西对、越远越好、地上东西的换法、加油站的油量）；实机 `harness/shots/modcar_places.mjs`（80 km 里的地点、加油站的柜台翻出东西拿到手上、油桶在加油机灌满、皮卡停在加油机旁加满（加的时候加油口盖开着、油枪的枪头离加油口不到 8 厘米，加满后挂回去）、地上的东西捡走后不再出现、走开再回来翻过的还是翻过的、存档里有、民房和修车铺的柜子、修车铺的发电机拉着、回收一个杯子得到废料、打开修车铺的制作台）。

## 21. 手感实验室：每个零件都要有差别（第 8 条，2026-11-18）

做法在 `harness/sim/modcar/part_matrix.ts`（把每个零件装到它该在的车上，和原厂件比，量出变化最大的指标）、`harness/sim/modcar/feel.ts`（已有的全物理测量：0–100、极速、刹车、定圆侧向 G、侧倾、爬坡、油耗），测试在 `harness/sim/modcar_part_matrix.test.ts`。

- **规则**：任何零件换上去，至少有一项指标变化 10% 以上。
  - 开起来的零件（发动机、变速箱、排气、涡轮、轮毂、轮胎、方向盘、手刹）看怎么开：0–100、60–100、极速、100–0 刹车、定圆侧向 G、爬坡、油耗，再加两项新测量：
    - **转向响应**：60 km/h 打半圈方向，横摆角速度到稳定值三分之二要多久、稳定值多大。
    - **手刹甩尾**：50 km/h 打四分之一方向、拉 0.6 秒手刹，车身侧滑角最大多少度。
  - 其余零件看它本身是什么：换挡时间、坐姿高低、舒适度、车身防护、前后保险杠和车顶的撞击力、风阻、重量、油箱、散热、电瓶、车灯、机舱进气、车顶灯、太阳能、离地间隙、轮胎寿命、驾驶室密封。
  - 收音机、喇叭、点火开关、尾灯、后视镜不算（它们就是用来响、亮、启动的）。
- **这次量出来不够、调过的**：
  - **手刹**：原来手刹不管什么杆都是把后轮抱死，漂移长杆手刹和普通手刹完全一样。现在手刹有力度（拉力是后轮静载的几成）：普通手刹在柏油路上只是刹车，碎石路、雪地上才抱死；漂移长杆在哪儿都抱死，尾巴甩得出去。车停着（不到 1.5 m/s）一律抱死，驻车照旧。只在 ModCar 里生效，老版四辆车的物理一位不差。
  - **方向盘**：原来转向比只影响方向盘画面上转几圈。现在快比的运动方向盘同样的手打得更多、反应更快（响应快 15%，转得更猛），船舵又慢又懒。
  - **五速近比变速箱**：齿比更密、换挡更快（0.22 秒，原厂 0.32 秒），0–100 快约 6%。
  - **排气**：运动排气扭矩 +10%，侧排 +14%（0–100 快 11% / 14%）。
  - **铝圈**：轮胎在大圈上跑得更扁（侧壁 72%），抓地 +6%，转向更跟手。
  - **长条座椅**舒适度 0.7（更软），**白边胎**寿命 34 km。
- 全部 86 个零件 4.5 秒测完。
- **游戏里的实验室**（开发者面板的「手感」页，`src/game/modcar/devLab.ts`；测量的代码搬进了 `src/core/modcar/lab/`，测试照旧从 `harness/sim/modcar/` 引用）：
  - 坐进一辆车或走到车旁边，「量这辆车」：在一块平坦的柏油试车场上测这辆车现在的样子（复制一份来测，路上那辆不动），列出全部 34 项：加速、中段加速、极速、刹车、侧向 G、侧倾、推头、爬坡、油耗、转向响应、手刹甩尾、单边冰起步，还有重量、风阻、油箱、散热、灯光、离地间隙等。
  - 「试装对比」：选一类、选一个零件，换到这辆车上所有同类的位置（轮胎装到每个轮毂上，涡轮装到能带涡轮的发动机上），每一项列出现在、换上和变化；变好的绿色，变差的红色，变化 10% 以上的加粗，并说出变化最大的是哪一项。
  - 「这一类全试一遍」：这一类的每个零件都换上去测一遍，按变化大小排好；不到 10% 的标红（多半是这辆车原来就装着的那个）。
  - 测量时画面会停一下（一个零件约零点一秒）。
  - 测试：`harness/sim/modcar_lab.test.ts`（试装的零件装到所有同类位置、原车不动；V8 换进轿车变化最大的是加速）；实机 `harness/shots/modcar_lab.mjs`（坐进「方糖」打开手感页、量出 34 项、试装 V8 说出变化最大的一项、全部发动机试一遍并排好、路上的车一点没变）。

## 22. 悬挂、刹车、差速器（第 8 条的三类新零件，2026-11-18）

做法在 `src/core/modcar/frames.ts`（`withAxles`：每根轴的悬挂、刹车装配位，驱动轴的差速器，位置从车架模型的轮毂算出来）、`src/core/modcar/parts.ts`（13 个新零件）、`src/core/modcar/derive.ts`（零件怎么改弹簧、减震、行程、防倾杆、车身高度、刹车力和前后分配）、`src/core/vehicle/sim.ts`（`splitDrive`：差速器怎么把劲分给左右轮，只在 ModCar 里生效）；画法在 `src/game/modcar/carView.ts`（`pairUp`）。

- **一套是一根轴的**：悬挂和刹车一次换一根轴（左右两边一起），两边的减震柱和刹车盘装在各自车轮的转向节上，跟着车轮上下跳、跟着方向转，但不跟着车轮转。差速器在驱动轴中间。摩托车的前叉和后减震是车架自带的，它只有前后两个碟刹。
- **装在哪儿、怎么拆**：刹车在车轮里面，先拆车轮才看得见、拿得到（拿着刹车件时，前后轴两头都出现全息影子）。减震柱在车轮内侧，从轮拱里能看到。这些都不在发动机盖、尾箱盖下面，不用开盖。
- **悬挂**（左右一套）：
  - 原厂悬挂：车架原来的调校，一点不变。
  - 软悬挂 ★1：弹簧软 30%，减震软 30%，防倾杆只剩一半，车身低 2 cm。过坑舒服，过弯侧倾大三成以上。
  - 运动悬挂 ★4：弹簧硬 70%，减震硬 55%，行程短四分之一，防倾杆加倍，车身低 4.5 cm。侧倾少一半。
  - 越野加高悬挂 ★3：行程长 60%，车身高 10 cm（离地多六成），防倾杆略软。
  - 加强钢板弹簧 ★3：弹簧硬 80%，车身高 3 cm，载重用，空车颠。
  - 拆掉了：那根轴直接坐在橡胶限位块上，又硬又短，车身往下掉，又颠又蹭底。
- **刹车**（左右一套）：鼓刹 ★1（制动力 −28%，百公里刹停长三成多）、盘刹 ★2（原厂）、通风盘刹 ★3（+26%）、运动刹车 ★4（打孔盘红卡钳，+42%，到轮胎抓地的极限）、摩托碟刹。前后制动力按两根轴装的东西重新分配：只装后刹车就只剩后轮在刹；一个都没有，刹车踩下去什么也不会发生。
- **差速器**：
  - 开放式 ★2（原厂）：两边的扭矩一样大，一边打滑，另一边也只能拿到差不多一样少的劲（车轮离地或者一边在冰上，车就走不动）。
  - 限滑 ★4：抓地的一边最多拿到打滑那边的 2.8 倍，离地的时候也有一点劲。
  - 锁止 ★3：左右轮锁在一起，劲全给抓地的那边；代价是转弯时两个轮子一起转、互相拧，车转得少。
  - 拆掉了：传动轴空转，劲到不了车轮，自检说“没有差速器”。
- **原厂车一点不变**：车架原来的重量里本来就算着它的悬挂、刹车和差速器；现在它们成了零件，车架自己的重量、重心和转动惯量相应减掉，原厂车的总重、重心、惯量和以前完全一样（测试精确到毫克）；原厂件也不改弹簧和刹车的任何数字。老版四辆车不用这些代码，一位不差。
- **老存档**：存档里的车如果一个这三类零件都没有（这次之前的存档），读档时自动装上它车架的原厂件，磨损程度跟着车身。
- **在哪儿找**：修车铺的零件架、路边废车（废车上这三样多半还在，难拆、没人先拿）。
- **零件卡和比较卡**：悬挂写弹簧、减震、行程、防倾杆、车身高度；刹车写形式和制动力；差速器写形式和锁止比。拿着零件对着车时的比较卡新增三项：百公里刹停、离地间隙、侧倾；车辆卡也写百公里刹停和离地间隙。
- **手感实验室**（§21）加了一项测量：**单边冰起步**——左边两轮在冰上、右边在柏油上，全油门起步到 30 km/h 要多久。原厂开放式差速器要 18 秒左右，限滑快 72%，锁止快 77%。全部 99 个零件都过了“至少一项变化 10%”这条规则。
- 测试：`harness/sim/modcar_axles.test.ts`（每辆车的装配位、原厂车的重量重心惯量和以前完全一样、原厂件不改车架的数字、老存档补装、没差速器开不动、没刹车、没悬挂、加高和降低的高度、三种差速器单边冰起步的快慢、锁止差速器转弯拧）；实机 `harness/shots/modcar_axles.mjs`（拆下前轮看到刹车盘和减震、空手对着是“拆下盘刹”、拿着运动刹车时前后轴的影子、装上、加高悬挂车身高 10 cm、拆掉差速器打着火也不走、自检说没有差速器、装回去能开、老存档读回来补上了）。
- **模型**（`tools/blender/parts/chassis.py`，13 个，2026-11-18）：原厂减震柱（黑弹簧、灰减震筒、镀铬活塞杆），软悬挂（生锈的弹簧，防尘套裂开露出活塞杆），运动绞牙避震（车身色弹簧、铝绞牙筒、带扳手槽的锁环），越野加高（粗筒、外挂副油壶、编织油管），钢板弹簧（叠片、U 型螺栓、吊耳、斜装减震）；鼓刹（带散热筋的鼓），盘刹和通风盘刹（黑卡钳），运动刹车（打孔盘、铝盘帽、车身色四活塞卡钳），摩托的花瓣打孔碟；开放式差速器（钢壳、黑色带筋后盖、黑色半轴管），限滑（车身色后盖、七道铝散热片），锁止（加一个铝气缸、一盘黑气管、一块小吊牌）。没上漆的车身色件是砖红色，喷漆罐能喷。
- **车架自带的那套拿掉了**：四个车架模型原来自己画着刹车盘、卡钳、鼓刹、减震、弹簧、钢板弹簧和差速器壳，跟零件重复（拆了刹车还看得见一个盘，装了加高悬挂两个盘差 10 cm）。现在车架上只剩车架、横梁、摆臂、扭杆、转向拉杆、传动轴、轮拱内衬；后桥的半轴管在中间留出差速器的位置，传动轴正好接上差速器的法兰。摩托车只拿掉了前碟刹和后鼓刹，前叉、后摇臂、减震不动。
- **轮毂跟着车轮走**：每个轮毂的转向节（轮毂法兰、螺栓、轴头、连到摆臂的那块）拆成单独的件，挂在车轮的转向节上，跟刹车、减震一样跟着车轮上下跳、跟着方向转（原来是钉死在车身上的，悬挂一动就错位）。刹车盘的位置改成从车轮的安装面往里量（原来从轮毂中心量，房车后面的双胎差了 3 厘米，刹车盘顶进了内侧轮胎）。
- **刹车会热、会软**（`src/core/modcar/brakeHeat.ts`，`systems.ts` 的 `heatBrakes`，2026-11-18）：每个刹车把车速变成热（刹车力乘车轮转速；车轮抱死时热进了轮胎，不进刹车），一边往空气里散，车开得越快散得越快。热过了它那一种的限度，刹车片发釉，越来越刹不住：
  - 鼓刹最先软（闷在鼓里，散热慢），实心盘其次，通风盘、打孔运动盘最后。卡片上写着各自「过热变软」的温度：鼓刹约 160 °C，实心盘约 290 °C，通风盘约 360 °C，运动刹车约 420 °C（20 °C 的天）。
  - 从 100 km/h 一次接一次猛刹：鼓刹第三次就开始软，到第六次刹车距离差不多翻倍；实心盘第四次开始；运动刹车五六次还几乎不变。
  - 8% 的长下坡一直踩着刹车压在 60 km/h：鼓刹两分半钟左右开始软，实心盘要三分半以上，通风盘、运动刹车不会软。
  - 软了以后开起来就慢慢凉：60 km/h 开一分半到三分半钟（看哪种刹车）又能刹住。停着凉得慢。
  - 刹车一软，车上会说一次「刹车过热，越踩越软」；热的刹车从轮毂冒白烟，越软烟越大。换上新刹车是凉的。
  - 游戏里的山坡比真的短，所以刹车吸进的热按三倍算，短坡也能像长坡一样把刹车刹热。只在 ModCar 里生效，老版四辆车不变。
  - 测试：`harness/sim/modcar_brakeheat.test.ts`（热进热出、不会低于气温、过了限度才软；凉的时候原厂车刹车距离照旧；连续猛刹鼓刹先软、实心盘其次、运动刹车几乎不变，刹车距离越来越长；长下坡鼓刹软、通风盘不软；开一段又能刹住；软了只说一次；换上的新刹车是凉的；没有刹车就没有热）；实机 `harness/shots/modcar_brakeheat.mjs`（皮卡换上鼓刹，在公路上从 90 km/h 连续猛刹六次：刹车距离从 66 米长到 120 米左右，车上说刹车过热，轮毂冒烟；接着 60 km/h 开三分半钟，刹车恢复）。
- 还没做：刹车片磨损。

## 23. 第一人称的手感：座椅震动、扬尘、开门进风、不同路面的轮胎声（第 8 条，2026-11-18）

做法在 `src/game/modcar/seatShake.ts`（座椅震动，叠在头部晃动后面）、`src/game/modcar/wheelDust.ts`（车轮扬尘）、`src/game/modcar/ModGame.ts`（`kickDust`、`engineFelt`、`stiffnessOf`、`cabinOpen`）。

- **头部惯性**是共用的第一人称相机本来就有的（`src/core/camera/rig.ts`：加速往后靠、刹车往前冲、转弯往外甩、过坡上下沉，车身的俯仰侧倾只跟一部分，地平线稳）。老版游戏也用它，所以一点没动；新加的都在 ModCar 自己这边，叠在它后面。
- **座椅震动**：
  - 路面：柏油路高速时是细细的颤，碎石路、草地上是硬硬的抖，越快越厉害，悬挂忙（搓板路、坑洼）也加。硬悬挂把路面传上来更多（运动悬挂比软悬挂抖），拆了悬挂坐在限位块上最抖。
  - 发动机：在机脚上晃。单缸、双缸怠速时整个驾驶室都在抖，六缸、八缸几乎不动；转速一高反而平顺。磨坏的发动机偶尔缺一下缸，车身跟着顿一下。打着火那一下车身一哆嗦，熄火时一顿。
  - 撞击：压到路沿、接缝、坑边，悬挂撞到限位块，飞起落地，底盘蹭地，撞到硬东西，头都会被顶一下、点一下，半秒内平复。
  - 座椅：软座吃掉一部分颠簸，硬座照单全收。以原厂桶椅为准，沙发椅少三成，长条座椅、办公椅少一成，赛车座椅多一成，马鞍座多两成，马桶座多三成，木箱多四成；座椅卡上写着「开车颠簸 少 / 多 xx%」。
  - 只在第一人称驾驶时有。开发面板「画面」页的「座椅震动」能调：0 完全不抖（容易晕车可以关掉），2 是加倍。
- **扬尘**：
  - 车轮在碎石、土路、沙地、干草地上滚，后面扬起一团团尘土，慢慢变大、散开，被风吹走。越快越多，车速快时后面拖出一长条尘云；轮子空转、侧滑时一下子扬起一大团。雪地上扬的是白色的雪粉。
  - 柏油路和冰上没有。地面湿了越来越少，湿透了就没有；沙子干得最快，有点潮还会扬。
  - 颜色跟着地面：碎石灰黄，土路土黄，沙子沙黄，雪是白的。主要被太阳照亮，天空的蓝只带一点，远了被空气冲淡，跟炉子的烟一个画法。
  - 最多同时 720 团；离镜头 180 米外的车不扬。摩托车前后各两个着地点，各算一半。
- **车门开着进风**：开车时车门开着，风声、雨声跟拆了门一样直接进来，关上就闷下去。原来只算拆掉的车门，开着的门不算；发动机声早就是这样算的。
- 测试：`harness/sim/modcar_seat.test.ts`（停着、熄火时一点不晃；同样车速碎石路比柏油路抖得多，越快越抖，但不会抖出撞击那么大；硬悬挂比软悬挂抖；撞一下立刻顶起、一秒内平复，撞墙更大；单缸怠速比八缸抖得多，转速高了反而小；打火一哆嗦、熄火一顿；调成 0 完全不动；扬尘只在松软的路面上有，湿了没有，越快越多、打滑更多、走得慢不扬，尘团会消失，不会超过上限）；实机 `harness/shots/modcar_seat.mjs`（沙漠里开皮卡后面扬起一片尘土；开回柏油路上一点不扬；地面湿透再上沙地也不扬；草原上越野比柏油路抖得多；单缸摩托怠速比房车的六缸抖得多）。
- **不同路面的轮胎声**（`src/game/modcar/foley.ts` 的 `roll_*`、`skid_*`，全部用代码合成，没有录音；`src/game/modcar/tyreSound.ts` 每帧按车轮混）：
  - 滚动：柏油路是平稳的胎噪和一点花纹的嗡声；湿路面在上面加一层水声和溅水（越湿越响）；碎石路是石子一阵阵咯吱、从胎底下崩出来，偶尔有小石子打在轮拱上；土路是闷闷的、带点沙砾的隆隆声；草地是一簇簇的唰唰声，偶尔折断草茎；沙地是又沉又软的闷响和沙子的沙沙声，沙子扑在轮拱上；雪地是密密的嘎吱声和冷雪的吱吱声；冰面几乎没声，偶尔一点细碎的裂响。
  - 打滑：柏油路是真正的尖叫（音高会飘、会抖），过了轮胎的抓地极限才叫，四轮抱死刹车叫得最响，一个轮子空转只有一半；碎石路是石子被铲起来、噼里啪啦打在车底；土路是沙沙的刮擦和溅起的土；草地是草皮被撕开的声音；沙地是软软的嘶声和扬沙；雪地是一串串吱吱声；冰面是嘶嘶的刮声，几乎不叫。
  - 声音跟着车轮自己的转速走（越快越响越亮），抱死的轮子滚动声停下、换成打滑声；碎石和雪在很慢的时候也还在响；四个轮子在两种路面上，各占一半。
  - 坐在关着门的驾驶室里，轮胎声隔着车底闷下去，碎石、沙子、雪打车底的声音更清楚一些；开着门就跟在外面一样亮。站在路边听车开过，离远了变小。
  - 原来那层共用的路面噪声（老版游戏也用，`src/core/audio/mix.ts`）在松软路面上调小，免得盖住这些声音，老版游戏听起来一点不变；原来那个通用的打滑嘶声只留给车身、空轮毂拖地。
  - 全部离线检查，没有外放：渲染成音频文件，看频谱图和响度。
  - 测试：`harness/sim/modcar_tyresound.test.ts`（50 km/h 柏油路滚动声正好是一倍；越快越响越亮；很慢时碎石比柏油响；湿路面的水声跟湿度成正比；两种路面各占一半；四轮抱死刹车叫得最响、一个轮子空转一半、正常行驶不叫；松软路面一滑就响；关门闷、开门亮、车外不闷；共用路面噪声在草地上只剩 15%，不给比例时和原来完全一样）、`harness/sim/modcar-audio.test.ts`（每个声音能渲染、循环接缝无缝、碎石和雪有颗粒感、柏油路尖叫有明确的音高、越快越亮、闷音开关）；实机 `harness/shots/modcar_seat.mjs` 读出车在沙地、柏油路、草地上各自响的是哪种轮胎声（探针不开声音）。
- **雨刷和挡风玻璃上的灰**（`src/game/render/carMaterials.ts` 的 `rtWiperIn`、`rtWipeRegrow`，`src/game/modcar/carView.ts` 的 `wiperArc`）：
  - 两片雨刷各刮出一个扇形。扇形就按车架模型里雨刷的样子量出来：转轴、停放的方向、胶条从哪儿到哪儿、转多大角度。所以每辆车的扇形都跟它自己的雨刷对得上。
  - 下雨时雨刷自己开。刮过的地方雨珠没了，再一颗一颗慢慢长回来：雨越大长得越快，大雨里 0.6 秒，小雨 2 秒多。扇形外面的角落、上沿一直挂着雨珠。在车库里（屋顶底下）雨淋不到玻璃，雨刷不动。
  - 雨刷连着雨把扇形里的灰也刮掉，泥壳刮不掉，泥壳还得用清理铲。刮多少记在车上（`Build.wiped`，存档里也有），以后路上落的灰会在扇形里重新积起来。
  - 玻璃上的灰原来从车里几乎看不出来，现在是一层发白的雾，越往玻璃下沿越厚，被外面的光照亮。车很脏时，从驾驶座能看出挡风玻璃上两个干净的扇形。
  - 测试：实机 `harness/shots/modcar_wipers.mjs`（脏方糖开到路上：不下雨时雨刷不动、灰一点没少；下雨 3 秒雨刷自己开始刮；10 秒后扇形里的灰刮干净；雨停了雨刷停回去，刮掉的灰不会回来；车库里下雨雨刷也不动）。

## 24. 手柄（第 8 条，2026-11-18）

做法在 `src/game/modcar/pad.ts`（ModCar 自己要的按键）；摇杆、扳机、十字键原来就由共用的 `src/game/input.ts` 读（老版游戏也用它，只改了一处：擦洗、倒油时右摇杆不再转视角，这个开关只有 ModCar 会用到）。

- 标准布局的手柄（Xbox 式）插上就能用，提示一句「手柄已连接」；按键卡（F1 或手柄的菜单键）里有手柄的按键表。
- **走路**：左摇杆走，按下左摇杆跑，右摇杆环顾。RT 等于鼠标左键（拿起、装、喷漆、擦洗），LT 或 B 等于右键（拆、吃、抽回油桶），X 是 E，按住 Y 放下，A 跳，LB / RB 换快捷栏，视图键打开背包或车里的东西，按下右摇杆显示 / 隐藏物品卡，十字键下看哪里还脏。擦洗时右摇杆移动工具（跟鼠标一样）。
- **清单里**（背包、车里的东西）：十字键上下选，X 拿出来，B 关掉。**工作台**：十字键选、左右换分类，A 制作（打铁时敲），B 离开。
- **开车**：左摇杆转向，RT 油门，LT 刹车 / 倒车，A 手刹（按一下松开驻车，跟空格一样），十字键上下拨挡杆、按住左打火、右车灯，Y 手动挡切换；X 下车，LB 喇叭（按住），RB 换视角，B 双闪，视图键翻车时扶正，按下右摇杆按看着的车内按钮和拉杆。
- **震动**（手柄有马达就用，浏览器的「双马达震动」）：坐在车里就跟着车震，哪个视角都一样。
  - 大马达（又低又沉）：压到路沿、悬挂撞到限位块、飞起来落地、撞上东西，跟座椅震动的「顶一下」是同一个来源。
  - 小马达（又快又细）：路面的颤（碎石、草地比柏油明显得多）、发动机在机脚上抖（单缸怠速最明显）、转速撞到断油时一顿一顿地麻手、刹车抱死时轮胎一抖一抖。
  - 下车就停。开发面板「画面」页的「手柄震动」能调，0 关掉，2 加倍；它跟「座椅震动」分开调，关掉画面抖动也还有震动。
- 测试：`harness/sim/modcar_pad.test.ts`（每种场合下每个键做什么、按住的一直算、按一下只算一次、扳机过半才算、右摇杆有死区、插拔会提示）；实机 `harness/shots/modcar_pad.mjs`（一个假手柄：认出来、按键卡上有；左摇杆走了 2.7 米；RT 拿起电瓶；RB、LB 换快捷栏；按住 Y 放下；上车 A 松手刹，RT 开到 13 km/h，LT 刹住；RB 换视角再换回来；坐着发动机着车时手柄在震，X 下车，下了车就不震了）。

## 26. 轮胎到 14 种、涡轮分三档（第 8 条，2026-11-18）

做法在 `src/core/modcar/parts.ts`（参数）、`blurbs.ts`（星级和一句话）、`tools/blender/parts/wheels.py`（轮胎模型）、`tools/blender/parts/turbos.py`（涡轮模型）。

- **六种新轮胎**。每种都有自己的花纹，单独放着一个模型，装在每种轮圈上各一个（胎圈正好坐在轮圈上）。下面的数字都是换上原厂轮胎的方糖、在实验室量的：
  - **省油胎**（★2）：五条直纹，又安静又滚得轻。胎寿长三成，油耗少一点，抓地差一点。
  - **运动胎**（★4）：矮而宽，V 字形花纹，胎肩是大块。柏油路上过弯的侧向 G 高 18%，手刹几乎甩不出去，胎寿短三成多，土路上不行。
  - **全地形胎**（★3）：错开排列的方块花纹，带锯齿沟和刀槽。碎石坡多爬 25%，胎寿长三成，哪儿都能凑合。
  - **泥地胎**（★3）：长短交替的大块花纹伸到胎侧，沟又深又空。碎石坡多爬 36%，离地高 25%，一边在冰上起步也更稳；柏油路上嗡嗡响，加速慢一成。
  - **钉胎**（★3）：雪地花纹上每节镶三颗钢钉。一边在冰上起步快一倍多，碎石坡多爬 14%；胎寿短四分之一，柏油路上咔咔响。
  - **越野摩托胎**（★3）：圆胎冠上一颗颗高胶粒。摩托车在土路、草地上抓得住，柏油路上过弯的侧向 G 少两成。它标的是「摩托用」（`for:moto`），废车里只会在摩托车上找到，不会装在汽车上。
- **涡轮分三档**，接口和小涡轮完全一样，哪台带涡轮的发动机都能换：
  - **小涡轮**（★3，原来就有）：2600 转醒，等 0.7 秒。0–100 快 22%。
  - **中号涡轮**（★4）：增压 1.45 倍，3000 转醒，等 1 秒。0–100 快 28%，中段加速快 36%。压气机出口上一个红帽的泄压阀，进气口接红色的蘑菇头空滤。
  - **大涡轮**（★5）：增压 1.7 倍，3600 转以下像没装，等 1.5 秒；一上来中段加速快 39%。压气机口很大，罩着镀铬网，涡轮端包着隔热棉，外置泄压阀。
  - **声音也分大小**：小涡轮的哨音细而高（1.5 kHz 一路升到 5 kHz 以上），大的低、慢、响，气流的呼呼声更重；松油门的泄压声小的短促清脆，大的长、闷，尾巴上带着压气机喘振的「咕咕」声。离线渲染量过：大涡轮的哨音在 2.2 kHz 左右，小的在 4 kHz。
- 测试：`harness/sim/modcar_part_matrix.test.ts`（手感实验室的规矩：每个零件换上去，至少有一项变化 10% 以上，新加的 8 个都过）、`harness/sim/modcar_core.test.ts`（每个零件装在每辆车每个位置上都能开、不炸）；模型用 `tools/blender/parts/verify.py` 查过（面数、材质、法线朝外、胎圈半径）。

## 27. 新车型：面包车、越野车、旅行车、小跑车、货车、四门皮卡、越野卡车（第 8 条，2026-11-18）

做法在 `tools/blender/frames/<车>.py`（车身模型：跟原来四辆一个画法，全是代码搭的）、`src/core/modcar/frames.ts`（重量、悬挂、刹车、转向、风阻）、`src/core/modcar/parts.ts`（`stock:<车>`：出厂零件）、`palette.ts`（出厂颜色）、`blurbs.ts`（一句话）、`cargo.ts`（能放东西的地方）、`wrecks.ts`（路边的废车是哪种车）。

- **面包**（面包车）：方头平脸的老面包车，芥末黄配奶油白，车头一个面包形的小标。驾驶座在前轮上面，大玻璃、平放的大方向盘。

  - 门：两扇前门，侧面一扇大门（游戏里门只能转着开，所以做成前边铰接、往外开 95°），尾门往上掀。发动机盖竖在车尾，盖着的时候换不了发动机。

- **山羊**（越野车）：陶土红配白顶，通气管、前绞盘、尾门上挂备胎、轮眉外扩，车头一个山羊头小标。

  - 前桥是整体桥：差速器偏到传动轴那一侧，齿轮头朝后对着分动箱（游戏按车架给的位置放差速器，齿轮头朝着变速箱）。发动机坐在前桥上面，跟老越野车一样，所以机舱抬高了；原来想用的 4.2 升直六柴油太高，盖不上引擎盖，换成了 V6。柴油机硬装进去也行，引擎盖就合不上了。
  - 手感：1877 kg，0–100 9 秒，极速 170 km/h，碎石坡能爬 49%（方糖 21%），侧倾 5.8°/g。
- **旅人**（旅行车）：4.8 米长的老旅行车，云杉绿配驼色腰线，车顶有行李架。
  - 动力：3.0 升直六，后驱。四扇门，尾门连着后窗往上掀，后备箱很深。
  - 手感：1434 kg，软悬挂，0–100 8 秒，极速 179 km/h，侧倾 6.1°/g。跑长途的车：快，但不爱急弯。

  - 动力：柴油四缸，在两个座位中间的机舱里，机舱盖在驾驶室里，后轮驱动。原装鼓刹、卡车胎、大号后视镜。
  - 手感：2266 kg，0–60 9 秒，0–100 要 47 秒，极速 102 km/h，刹车 100→0 约 70 米。货厢地板 1.6 × 2.9 米，什么都装得下。

  - 动力：4.2 升直六柴油，四轮驱动（前桥整体桥，差速器偏到传动轴一侧），大水箱，越野钢圈配全地形胎。引擎盖是前铰的，从风挡那头掀起来。
  - 能放东西的地方：车斗（不用开门，从上面放）、后排长凳、副驾驶座。
  - 手感：1942 kg，前后 57 : 43，0–60 6 秒，0–100 15 秒，极速 121 km/h，刹车 100→0 50 米，侧向 0.76 g，侧倾 5.2°/g，碎石坡能爬 52%。拉得多、爬得动，转弯慢一点。

  - 手感：3989 kg，前后 50 : 50，0–60 6 秒，0–100 17 秒，极速 106 km/h，刹车 100→0 82 米，碎石坡能爬 56%，离地 27 cm。又大又慢，什么都过得去。
