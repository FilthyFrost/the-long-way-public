# ModCar 夜间进度报告与早上的试玩清单

分支 `feat/modcar`（只在本机提交，没有推送）。打开方式：

```bash
npm run dev      # 打开 http://127.0.0.1:5173 —— 新游戏：车库开局
                 # http://127.0.0.1:5173/classic.html —— ModCar 之前的旧版
```

F1 随时打开按键卡。

## 做了什么

**游戏流程**：你站在一间老木头谷仓车库里，旁边是一辆缺件的「方糖」轿车。左上角清单（墙上黑板也写着）一步步带你做完，屏幕上的小菱形指着下一样东西：

1. 打开引擎盖
2. 装电瓶
3. 装两个车轮
4. 装发动机
5. 用汽油桶加油
6. 按门边按钮开大门
7. 坐进驾驶座
8. 按住 K 打火
9. 松手刹开出去

开出大门后画面淡出，接上原来的公路世界，继续往前开。

**模块化车辆**（`docs/MODCAR.md`）：
- 4 个车架：轿车「方糖」、皮卡「骡子」、摩托「燕子」、房车「鲸鱼」。
- 95 个零件，分 26 类，覆盖发动机、变速箱、散热器、电瓶、油箱、排气、涡轮、轮毂、轮胎、方向盘、座椅、车门、引擎盖、尾箱、前后杠、灯、后视镜、车顶、装甲、喇叭、收音机、手刹、挡杆、点火开关。
- 任何零件都能装到任何车架上同类的挂点。例如把 V8 装进摩托，把马桶当驾驶座，换拖拉机轮胎、尖刺撞角、钢板装甲。
- 每次换件都会重新推导整车：重量、重心、悬挂下沉、抓地、油耗、动力曲线都会变，手感和速度有质的区别。
- 少了关键件就开不了：没发动机、没变速箱、没方向盘、没电、没油、加错油都不行。

**幽灵与属性卡**（最重要的那条）：
- 手里拿着零件时，4 m 内所有能装它的挂点都亮起青白色全息幽灵：空位是实的，已有零件是淡的「替换」，车在动是橙红色。
- 准星对准的那个更亮，被车身挡住的部分也能透出来。
- 旁边的属性卡列出 0–100、极速、油耗、重量、抓地、操控，旧值 → 新值；变好绿色，变差橙色。
- 引擎盖关着时，盖下的件装不上也拆不下，E 会直接变成「打开引擎盖」。

**第一人称操作**：
- 拿起的东西真的拿在手上：小件在右手，大件双手抱着，走路会晃，转身会拖一下。
- 装上的零件会「落」进位置，轮子顺着轮轴滑上去。
- 车里可以用鼠标直接扳手刹杆、拨挡杆、拧钥匙、开收音机、按喇叭、开车门；手刹杆、挡杆、钥匙、启动按钮护盖都会动。
- 车门、引擎盖、尾箱、油箱盖按模型里的铰链开合，仪表指针、雨刷都会动。

**喷漆与清洗**：
- 喷罐对准零件或车身按住左键，滚轮换颜色，24 色调色板。
- 海绵擦掉灰；车开得越久越脏；捡来的旧件带锈。
- 谷仓里的车和零件已经积了一冬的灰。

**画面**（`specs/art/CAR_LOOK.md`）：
- 车漆、镀铬、玻璃、车灯是专门做的动漫车着色：地平线反射带、硬边高光、描线，阴影进阴影图。
- 夜里车灯照亮路面，大灯光束从实际装着的灯射出。
- 每辆车的静态件自动合批，地上的零件也合批：车库约 550 次绘制，GPU 上一帧约 4–5 ms。

**声音**（`docs/MODCAR_AUDIO.md`）：
- 发动机声是用开源 Engine Simulator（MIT）离线录的 8 台发动机，按转速和负载交叉混合，带涡轮、回火、排气差异、车内外。
- 机械声全部是合成的：扳手、拿起放下按重量、车门按材质、钥匙、手刹、换挡、三种喇叭、喷漆、擦洗、倒油。
- 没用参考游戏的任何资源。

## 早上试玩清单

1. 打开首页，看按键卡，点击画面开始。
2. 按清单走一遍：开引擎盖 → 电瓶 → 两个车轮 → 发动机 → 加油 → 开大门 → 上车 → 打火 → 开出去。
3. 拿起零件时看幽灵和属性卡；试试拿马桶对准驾驶座，拿 V8 对准发动机位。
4. 试试拆件（按住右键）、互换件、喷漆（喷罐 + 滚轮）、擦洗（海绵）。
5. 上车后用鼠标点手刹杆、挡杆、钥匙、收音机；L 开灯，H 按喇叭。
6. 上路后：C 切车外视角，开一段，感受手感和发动机声。
7. 也可以直接在公路上试别的车：`?start=road&build=stock:moto`，或 `stock:pickup` / `stock:rv`；改装车示例：`?start=road&build=stock:moto;engine=eng_v8`。
