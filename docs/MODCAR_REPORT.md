# ModCar 夜间进度报告与早上的试玩清单

分支 `feat/modcar`，只在本机提交，没有推送。打开方式：

```bash
npm run dev      # 打开 http://127.0.0.1:5173：新游戏，从车库开局
                 # http://127.0.0.1:5173/classic.html：ModCar 之前的旧版
```

随时按 F1 打开按键卡，按 F2 打开辅助开关。

**存档：** 进度会自动存在浏览器里，每半分钟存一次，切走页面时也会存。刷新或关掉页面再打开，会接着上次继续：车库里的车和零件原样都在，在路上就接着在路上。想从头开始，连按两次 F9。带 `?start=road` 之类参数的试车不会存档。

## 做了什么

### 游戏流程

开局你站在一间老木头谷仓车库里，旁边是一辆缺件的「方糖」轿车。左上角的清单一步步带你做，墙上黑板也写着同样的清单，会跟着打勾。屏幕上的小菱形指着下一样东西；隔着墙时菱形会变淡、不显示字。清单步骤：

1. 打开引擎盖
2. 装电瓶
3. 装两个车轮
4. 装发动机
5. 用汽油桶加油
6. 关上引擎盖
7. 按门边按钮开大门
8. 坐进驾驶座
9. 按住 K 打火
10. 松手刹开出去

开出大门后画面淡出，接上原来的公路世界，可以继续往前开。车库里另一辆旧皮卡也能开出去，或者拆它的零件。

### 模块化车辆（`docs/MODCAR.md`）

- **车架：** 4 个，轿车「方糖」、皮卡「骡子」、摩托「燕子」、房车「鲸鱼」。
  - 摩托的前叉随转向转动，前叉下管随悬挂伸缩，后摇臂和两根减震跟着后轮动，边撑在骑上去时收起。
- **零件：** 95 个，分 26 类，覆盖发动机、变速箱、散热器、电瓶、油箱、排气、涡轮、轮毂、轮胎、方向盘、座椅、车门、引擎盖、尾箱、前后杠、灯、后视镜、车顶、装甲、喇叭、收音机、手刹、挡杆、点火开关。
- **互换：** 任何零件都能装到任何车架上同类的挂点。例子：
  - V8 装进摩托会抬头，最高 49°；V8 装进轿车，0–100 从 15.6 s 降到 7.2 s。
  - 马桶当驾驶座：视线会抬高，但不会穿出车顶。
  - 割草机发动机，轿车最高只能跑 40 km/h。
  - 拖拉机轮胎：车身抬高 0.22 m，抓地从 0.77 g 降到 0.62 g；换光头胎则升到 0.97 g。
  - 尖刺撞角、推雪铲、钢板装甲、冰箱门、车顶灯排（开远光时一起亮）。
- **重新推导：** 每次换件，重量、重心、悬挂下沉、抓地、油耗、动力曲线都会重新算，手感和速度有明显差别。
- **缺件就开不了：** 没发动机、没变速箱、没方向盘、电瓶没电、没油、加错油都不行。电瓶会被车灯和收音机耗光。
- **装甲与冰箱门：** 装甲车门、装甲引擎盖、装甲尾箱盖上会铆一层钢板；冰箱门带冰箱把手。
- **路上会撞：** 车和人都不能再穿过路边的墙、油泵、废车、路牌和护栏；箱子、长椅会被撞开。撞得重时，那一头的零件会坏：
  - 先坏保险杠，装了尖刺撞角能替后面的大灯挡下大半，装甲也能挡一部分。
  - 正面重撞会撞裂水箱，开始漏水，之后会开锅。
  - 屏幕上会提示撞坏了什么，并有撞击声；大灯撞碎了就不亮。
- **东西可以装车带走：** 把东西放到车上方，它会落在车上（皮卡货斗、座椅、车顶、引擎盖），跟着车走，也能开到路上。比如备用汽油桶、备胎、零件，到路上下车可以再拿下来。

### 幽灵与属性卡（最重要的那条）

- **幽灵：** 手里拿着零件时，4 m 内所有能装它的挂点都会亮起青白色全息幽灵。
  - 空位显示为实心。
  - 已有零件的位置显示为半透明的「替换」。
  - 车在动时显示为橙红色。
  - 准星对准的那个更亮；被车身挡住的部分会透出来。
- **属性卡：** 列出 0–100、极速、油耗（L/100km）、重量、抓地、操控，格式是旧值 → 新值，变好显示绿色，变差显示橙色。还开不动的车直接写「缺发动机」之类的原因。
- **引擎盖：** 关着时，盖下的件装不上也拆不下，E 会变成「打开引擎盖」。

### 第一人称操作

- **拿东西：** 小件拿在右手，大件双手抱着。走路会晃，转身时手里的东西会拖一下。
- **装件：** 装上的零件会「落」进位置，轮子顺着轮轴滑上去。
- **车里的控件：** 用鼠标可以直接操作：
  - 扳手刹杆、拨挡杆、拧钥匙、按喇叭、开车门。
  - 开收音机：左键开关，右键换台。

  手刹杆、挡杆、钥匙、启动按钮护盖、收音机旋钮都会动。
- **会动的车身部件：** 车门、引擎盖、尾箱、油箱盖按模型里的铰链开合，仪表指针和雨刷会动。
- **骑摩托：** 视角会稍微往下看，能看到仪表和车把。

### 喷漆与清洗

- 喷罐对准零件或车身按住左键，滚轮换颜色，共 24 色。车库角落的喷枪可以整车换色。
- 海绵擦掉灰；车开得越久越脏；捡来的旧件带锈。
- 谷仓里的车和零件已经积了一冬的灰。

### 车库

车库是一间 14 × 10 m 的红木谷仓。

- **布置：** 工作台和台钳、货架、轮胎堆、举升机、扒胎机、喷漆角、水槽、烧柴火炉和水壶、墙上的旧车牌、黑板清单。
- **会动的东西：**
  - 阳光光柱和浮尘。
  - 烟囱冒烟。
  - 三只燕子，晚上回巢。
  - 墙上的钟走游戏时间。
- **能用的设备：**
  - 大门按钮、电灯开关、电瓶充电器、水槽（给水壶装水）。
  - 举升机：能把车举起来。
  - 扒胎机、喷枪。
  - 收音机：放五首电台歌。
- **夜里：** 吊灯下是暖色光池，角落发暗。

### 画面（`specs/art/CAR_LOOK.md`）

- **专门的动漫车着色：** 车漆、镀铬、玻璃、车灯都有。车漆上有地平线反射带和硬边高光，有描线，阴影进阴影图。
- **玻璃：** 有天空反射，下雨时车外车内都看得到水珠。
- **车灯：** 夜里照亮路面，光束从实际装着的灯射出。
- **性能：** 每辆车的静态件自动合批；车库约 470 次绘制，GPU 上一帧约 5 ms。

### 声音（`docs/MODCAR_AUDIO.md`）

- **发动机：** 用开源 Engine Simulator（MIT）离线录了 8 台发动机，按转速和负载交叉混合，带涡轮、回火和排气差异，分车内和车外两种听感。
- **机械声：** 全部是合成的，包括扳手、拿起放下（按重量）、车门（按材质）、钥匙、手刹、换挡、三种喇叭、喷漆、擦洗、倒油。
- **收音机：** 五首曲子是程序合成的（拨弦吉他、贝斯、刷鼓、口哨或口琴），声音处理成老式 AM 收音机的效果，调台时有沙沙声。坐在车里听得清，站在车外听是闷的。
- **素材来源：** 没用参考游戏的任何资源。

## 早上试玩清单

1. 打开首页，看按键卡，点击画面开始。
2. 按清单走一遍：开引擎盖 → 电瓶 → 两个车轮 → 发动机 → 加油 → 关引擎盖 → 开大门 → 上车 → 打火 → 开出去。
3. 拿起零件，看幽灵和属性卡。试试拿马桶对准驾驶座，拿 V8 对准发动机位。
4. 试试这几样：
   - 拆件：按住右键。
   - 互换件。
   - 喷漆：喷罐 + 滚轮选色。
   - 擦洗：海绵。
   - 车库设备：举升机、扒胎机、喷枪、收音机。
5. 上车后用鼠标点手刹杆、挡杆、钥匙、收音机（右键换台）。L 开灯，H 按喇叭，B 开双闪。
6. 上路后按 C 切车外视角，开一段，感受手感和发动机声。
7. 也可以直接在公路上试别的车：
   - 原装车：`?start=road&build=stock:moto`，或换成 `stock:pickup` / `stock:rv`。
   - 改装车：`?start=road&build=stock:moto;engine=eng_v8`。
