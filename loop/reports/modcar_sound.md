# ModCar 声音子代理进度（modcar/sound）

## 2026-11-16

- 01:00 Engine Simulator（AngeTheGreat，MIT）本机用 VS 2026 Build Tools 自带的 CMake + Ninja 从源码编译成功：无窗口、无声卡的无头录音器 `tools/enginesim/esim_render.cpp`，补丁只有两处（渲染器头文件换空壳；piranha 的 Boost 路径换 std::filesystem）。录音直接写 WAV，从不经过扬声器。
- 01:20 八台发动机脚本（`tools/enginesim/engines/*.mr`）全部能启动、上测功机出扭矩。坑：点火曲线采样点必须比 1000 rpm 的滤波半径密，否则点火角塌掉；轻飞轮小单缸的怠速窗口极窄，熄过火的发动机再也点不着 → 所有稳态都让测功机按住转速录（怠速 = 关油门按在怠速转速上）。
- 01:30 音色库：每台 14–19 个转速档（相邻比 1.13，回放变调 ≤ 约 ±6%）× 全负载 / 滑行，外加起动机空转、着车、熄火、憋熄火、撞断油器。柴油（i4d、d6）近似：高压缩 + 快燃 + 早点火，滑行断火；离线叠加敲缸和喷油声。二冲程（2t）：“1+4、2+3 共管的直列四缸”近似 180° 二冲程双缸，离线叠加轻负载缺火（ring-ding）、散热片余振、上管共振。
- 02:00 运行时 `EngineVoice`、机械声 `Foley`（全部合成）、无头 Chrome 渲染检查 `harness/audio/modcar_render.mjs`、Node 检查 `harness/sim/modcar-audio.test.ts`（50 项）。
- 02:30 质量迭代（全靠测量，没有试听）：
  - 循环接缝：Chrome 自己解码、循环三圈，接缝处二阶差分 ≤ 正常 99.9 分位的 1.07 倍（48k 和 44.1k 都测），0 个咔嗒；有损编码的接缝误差在加载时“愈合”。
  - 相邻循环相关度 0.3–0.8：随机起播时中点电平在 −3.7～+2.1 dB 之间乱跳 → 改成**同相起播**（清单记每个循环的发动机循环相位）+ 按相关度保持功率的交叉混合。慢扫转速时的电平抖动（两个发动机循环窗）从 0.3–1.2 dB 降到 0.08–0.25 dB（2t 滑行 0.32，是故意的缺火）。
  - 2t 四个脉冲长得一样，周期细化会锁到四分之一循环 → 限定在整数循环 ±0.1 内。
  - 断油器从 2.5 Hz 的“咚—咚”改成 35–50 ms 断火的连续弹跳；割草机和柴油是调速器，不弹跳。
  - 收油回火、泄压阀原来永远不触发（按帧差判断收油）→ 改成相对衰减中的油门峰值；现在运动排气每次收油 2–3 响，侧排更多，涡轮车换挡和收油“噗嗤”。
  - 电平：怠速比全负载高转低 10–14 dB；起动机和怠速同级；车厢关闭时 −5 dB 且低通，缺门 −2 dB。
- 体积：Opus 4.6 MB + AAC 5.4 MB ≈ 10 MB（预算 25 MB）。`npm run check`、`npm test`（829 项）全绿。
