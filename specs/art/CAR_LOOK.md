# 车的画法（ModCar 车漆与材质）v1

本文件是 ModCar 车辆（`docs/MODCAR.md`）画面的标准，补充 [`STYLE.md`](STYLE.md)：背景是“颜料”，人和车是“赛璐璐 + 描线”。
代码在 `src/game/render/carMaterials.ts`（着色器）与 `src/game/render/carMerge.ts`（合批）；预览页 `viewer.html`（`src/game/modcar/viewer.ts`）。

## 0. 一句话

**动漫工业风的亮漆车，画在我们的赛璐璐世界里**：车身是干净饱和的颜色，亮面 / 暗面两档、交界干净；
上面叠着“画出来的反射”——一条硬边的亮天空带压在一条暗地面带上面，沿车身侧面走、随视角滑动；
一个小而白热的太阳斑，折线处一道亮线，边缘一圈天光；铬就是这些反射带本身；玻璃深色带斜条纹；描线照旧。
**反射是画家按规矩画上去的，不是照片**：不做实时反射、不用环境贴图、不贴写实的脏污照片。

## 1. 管线

```
GLB（Blender 导出，材质只有名字）
  → applyCarMaterials(root, opts)  返回 CarLook：一辆车一套材质，所有网格共享
  → 每个名字按“族”着色：PAINT / METAL / MATTE / GLASS / LENS / GAUGE / EMIT
  → 走世界共用的光：rtShadow（阴影贴图）、rtHeadlight（车灯光束）、rtFog、车厢灯
  → 不透明件写描线 id（alpha < 0.23），帧收尾按 id 画暗暖色线（frame.ts）
```

- 一个名字 = 一个材质（同一辆车里共享）；只有几何带的属性不同（有无 AO、`aPaint`、`aWear`、`aPartId`）时才分出变体，程序数约 17–20 个。
- 不认识的名字按 `plastic_int` 画，并列在 `CarLook.unknown` / 预览页左下角“未知”。

## 2. 材质名一览

| 名字 | 族 | 画法要点 | 默认色（线性） |
| --- | --- | --- | --- |

| `ceramic` | PAINT | 白色亮釉，反射带弱一点、软一点 | 0.86, 0.87, 0.85 |
| `chrome` | METAL | 全是反射带：蓝天、地平线白线、近黑暗带、暖灰地面；强太阳斑 | 0.92, 0.94, 0.97 |
| `steel` | METAL | 灰色赛璐璐上叠一半软的反射带 | 0.36, 0.37, 0.39 |
| `alu` | METAL | 浅灰，反射带更多、更软 | 0.62, 0.63, 0.64 |
| `trim` | MATTE | 近黑塑料/胶条，宽软高光，轻微颗粒 | 0.028, 0.03, 0.034 |

## 3. 车漆模型（最重要）

1. **赛璐璐漫反射**：受光 = 车漆色 ×（天光 + 太阳），背光 = **单独调的暗色**（更深、更饱和，被天光染冷：红车的影子是深红偏紫，不是灰）。交界在 N·L ≈ 0，宽度约 0.06，干净。
2. **AO**：顶点色烘焙的 AO 压暗天光；缝里（AO < 0.6）连太阳也挡住——板缝、饰条下面才读得出线。
3. **画出来的反射**（`rtCarEnv`，按反射向量的仰角 R.y 分区，全部硬边、一像素抗锯齿）：

   | 区 | R.y | 车漆上怎么画 |
   | --- | --- | --- |
   | 开阔天空 | > 0.3 | 一点点天光（带车漆色调），云按一半强度透出来 |
   | **亮带** | 0 – 0.3 | **最亮**：天空近地平线的颜色，按车漆色调染（红车上是浅红，不是粉） |
   | 地平线细线 | 0 – 0.02 | 一道细亮线（铬上最明显） |
   | **暗带** | −0.45 – 0 | 远处的地，**把颜色压向暗色**（不变灰） |
   | 地面 | < −0.45 | 稍暗，带一点地面的光 |

   - 地平线不是直的：远山的轮廓按方位角轻轻起伏（固定在世界里）。
   - 亮带朝太阳那边更亮、背着太阳更暗：同一条带沿车身有变化，不像贴的胶带。
   - **侧面按车身高度“画内倾”**：近竖直的面查反射时不用真实法线的竖直分量，而用按高度给的倾角（离地高度在车身高度的 35% 以上朝天、以下朝地；车身高度 = 漆面最高点离地），所以平平的车门也有“上亮带、中暗带、下地面”，并随视角上下滑动。车身高度默认从 `paint`/`paint_b` 网格量（车顶货物不算），也可以 `bodyHeight` 指定。
   - 反射是“加上去的光”和“压下去的暗”，**不是用灰色把车漆冲淡**；蓝天加在红漆上在 sRGB 里会变粉，所以亮带与天空都按车漆色调染色（亮带 82%，天空 62%）。
4. **太阳斑**：清漆里的太阳，半径约 4°，白热（会被泛光抓到），外加一圈软晕。
5. **折线高光**：法线在屏幕上变化快的地方（折线、紧的圆角），朝天的一侧加一道亮线——动漫里勾车身线条的那道光。
6. **菲涅尔边缘**：背向视线的边缘一圈天光。
7. **夜里**：同一套反射，颜色来自夜空（暗蓝），月光斑很小；其他车的车灯光束照亮车漆并在亮漆上留一个硬的灯斑。

## 4. 脏、锈、褪色（手绘遮罩，不用写实贴图）

- **泥**：从地面溅上来的一圈，上沿参差（大尺度噪声 + 笔触），越脏越高（0 → 车高 0.6 m 左右）；深褐两档。
- **尘**：车身其余部分一层淡土色，下面厚、缝里（AO）厚，侧面有雨水冲出的竖向条痕；两档硬边，不是模糊的渐变。
- **锈**：从缝里、板件底部、轮拱开始，长成大块斑；内部两档锈色（暗锈皮 + 橙色锈花），边上一圈起泡的浅色漆。
- **褪色**：发白、发灰、失去光泽，上表面更多，成片。
- 图案在**零件自己的坐标**里（跟着零件走），高度在**车的坐标**里（`setCarFrame`）。
- 每辆车一个 uniform（`setWear({dirt, rust, wear})`），合并网格里每个零件另有顶点属性 `aWear`，两者相加。每种材质有上限（例如玻璃只积尘、不锈；内饰不脏）。

## 5. 玻璃与车灯

- 玻璃深色半透明，看得见车里（座椅、方向盘带描线，和老车一致）；斜着看主要是天空（掠射角反射比真实玻璃多，这是“画”的玻璃）；两道斜条纹随视线轻轻滑动。
- 透明件用**预乘混合并保留 alpha 通道**（描线 id、颜料收尾遮罩不被改）；不进阴影贴图（`carShadows` 会跳过）。
- 车灯：灯罩后面要有**反射杯几何**（`chrome`），灯罩关着时是带色的透明玻璃，看得见反射杯和灯泡；开灯时灯罩自发光（近光 3.2、远光 4.2，尾灯 1.1、刹车 +3.0、转向 3.0，超过泛光阈值 1.5）。
- 灯的角色看它在车上的位置（车架坐标）：车后半的 `lens_head` 是倒车灯（`reverse`），左边的 `lens_amber` 随左转向灯闪，右边随右；`lens_tail` 全车一起（尾灯 + 刹车）。

## 6. 幽灵（装配预览）

- `ghostMaterial(kind)` / `applyGhost(root, kind, focused)`：`empty` 青白实心、`replace` 更淡、`blocked` 橙红；准星对准的用 `focused`（亮 1.6 倍）。
- 加色混合，菲涅尔亮边 + 形体折线 + 世界坐标横向扫描线（缓慢上移，偶尔一条亮线扫过）+ 呼吸。
- 每个网格先画一遍只写深度的影子，再画颜色：幽灵是一层“皮”，不是所有层叠成一团白。
- alpha 用 MIN 混合写 0.5：颜料收尾不涂它，车身的描线 id 不被破坏。不进阴影贴图。

## 7. 高亮（看着已装的零件）

- `CarLook.setHighlight(object | partId | null)`：单独画的零件换成“高亮孪生材质”（同一程序，只是 uniform 不同）；合并网格里按 `aPartId` 只亮那一个零件。
- 青白色呼吸的填充 + 亮边；不改描线。

## 8. 描线

- 不透明件写 `0.04 + 0.17 × fract(材质种子 + 颜色散列 × 0.43)`：不同材质种子错开，相邻的漆、铬、胶条、橡胶之间必有线；同色同材质的板件之间靠板缝几何读线。
- 透明件不写 id（车里的线透过玻璃可见，与老车一致）。

## 9. 合批与性能

- `mergeCarParts(parts, frame)`：静态零件按材质合成一个网格（车架坐标），`aPaint`（仅 paint/paint_b）、`aWear`、`aPartId` 进顶点；镜像件自动翻正。会动的（门、盖、车轮、方向盘、指针）单独画。
- 测试车：原样 37 次绘制，合批后 32 次（20 种静态材质 + 4 轮 × 3）；两辆整车合进同一组网格仍是 32 次。目标 ≤ 40。
- 每个像素：一次云立方体采样、几次噪声采样（只有带脏锈的族）、阴影 3×3 PCF；无循环外的额外通道。

## 10. 给建模的人（Blender 约定的补充）

1. 材质只靠名字（§2）；同名多个材质（`paint.001`）也认。
2. 顶点色 `Col` = 烘焙 AO（0–1 灰）；**转动的件（车轮）单独烘**，别让轮拱在胎上留一块暗斑。
3. `lens_*` 和 `gauge` 要有 UV：**灯心 / 表心在 (0.5, 0.5)**，边在单位圆上（圆灯按径向展开，方灯每面 0–1 即可）。没有 UV 的灯罩会均匀发光。
4. 灯罩后面放 `chrome` 反射杯和灯泡，并且**它们要在车身外面**（或者车身开孔），否则透过灯罩看到的是车漆。
5. 板缝 4–6 mm、深 6–10 mm 的 V 形槽或真缝；AO 会把它画成线。
6. 侧面最好有一点内倾和腰线（反射带会更好看）；完全平的侧面也能看（§3 的“画内倾”）。
7. 车顶货物、天线不要用 `paint`（会抬高“车身高度”）；或者给 `bodyHeight`。
8. 透明件（玻璃、灯罩）法线朝外；双面画。

## 12. 要 / 不要

**要**
- 颜色饱和、干净；反射带边缘硬、位置随视角滑动。
- 下半车身比上半暗；亮带在腰线下面一点。
- 铬对比强烈；玻璃深；灯开着时泛光，关着时看得见反射杯。
- 脏和锈是大块、有笔触边的形状。
- 夜里车漆仍读得出反射带（暗蓝天空 + 月光斑）。

**不要**
- 不要用灰白把车漆冲淡（红车变粉、蓝车变灰 = 错）。
- 不要细碎噪点（脏、锈、磨损都不能像豹纹或沙粒）。
- 不要实时反射探针 / 立方体贴图 / PBR 粗糙度渐变；不要写实照片贴图。
- 不要给每个零件新建材质（一辆车一套）。
- 不要让透明件写颜料遮罩或进阴影贴图。
- 不要改老车的材质（`materials.ts` 的 `surfaceMaterial` 等保持不动）。

## 13. 评审清单

- [ ] 前 3/4、后 3/4、正侧：侧面能看到“亮带在上、暗带在下”，且不是一条贴死的胶带（沿车身有明暗变化）。
- [ ] 换一个机位（抬高 / 降低），反射带上下滑动；引擎盖、车顶反射天空和云。
- [ ] 红、蓝、黄、白四种漆：颜色不发粉、不发灰；暗面更深更饱和。
- [ ] 铬：天空 / 白线 / 暗带 / 地面清楚；太阳斑在铬和车漆上都有，白热不发糊。
- [ ] 玻璃：深色，看得见内饰；斜看是天空；条纹不抢眼。
- [ ] 夜：近光开 / 关、刹车灯、转向灯；灯开着有泛光，关着能看到反射杯；光束落在地上。
- [ ] 脏 0 / 0.5 / 1、锈 0.5 / 1：大块形状，下重上轻，缝里先脏先锈；没有噪点。
- [ ] 幽灵三种：一层皮、亮边、扫描线、呼吸；看得出“替换”更淡、“不能装”橙红。
- [ ] 高亮：只亮看着的那一个零件。
- [ ] 真实世界里（`stage=world`，白天 / 黄昏 / 夜）：和草、路、天空在同一张画里，描线一致。
- [ ] 整车绘制 ≤ 40 次（`telemetry().modelCalls`），合批后颜色、脏锈不丢。
- [ ] 老车截图与改动前逐像素一致。
