## 2. 造型：圆润的平头老式房车

设计文档对 T3 的手感设定是“高高在上，前面是一整面大玻璃；方向盘 44 cm 公交车式；大柴油远在脚下；驾驶座后面就是厨房”。
所以它是**平头（forward-control）的一体式房车**，不是带引擎盖的 C 型：

- 整体：一个圆角长盒，长约 6.5 m（x ≈ −3.30 … +3.45，保险杠到 +3.55），宽 2.2，顶高 2.86（车顶件另算），离地间隙 0.40。
- 车头：近乎直立、略向后倾的大挡风玻璃（左右两片，中间一根细柱；玻璃下沿离地约 1.35，上沿约 2.45，宽约 2.0）；玻璃上方是鼓出的“额头”（车内是一条置物搁板，放卷好的毯子、书和一盏提灯）；圆大灯两只（离地约 1.0）、小转向灯、一条镀铬细保险杠、格栅只是几道横条。
- 车身：两色涂装——下半奶油白（约 `#ece2c8`），腰线一条青绿色（约 `#5f9f95`，和小货车的漆是一家）与一条橘色细线（约 `#d98a3d`）组成的“波浪”腰带，在车头两侧向下卷成一个弧（自己设计的图形，**不要画任何真实品牌的标志或条纹**）。车顶是略浅的白。裙边、轮拱唇、保险杠是深灰 `#393d45`。
- 侧面：左侧有驾驶门（x ≈ 1.5–2.35）和三扇侧窗（厨房窗、工作台窗、上下铺小窗）；右侧有起居室入口门（x ≈ 0.6–1.4，带一级外踏板和门上小窗）、卡座大窗、爱好角窗。窗框深色，窗内能看到窗帘（车内件）。
- 车尾：一整面横向大后窗（下沿离地约 1.45）、左右竖尾灯、通向车顶的梯子（偏右）、车尾槽位（见 4）。
- 车顶：前段行李架、中段太阳能板、后段露台（三个车顶槽位，见 4）；一只带罩的天窗（在厨房上方——真的开洞，让太阳能照进车里）；一根烟囱短管。
- **生活痕迹**（参考作品的主题是“set dressing … to look lived in”）：收起的遮阳棚卷筒（右侧窗上沿，可展开，见 5）、窗台花箱、门边挂的提灯、车身上的几张贴纸色块、晾衣绳或挂着的毛巾、车尾挂的折叠椅、绑在梯子旁的水桶、泥点和下沿一圈较深的旧色。这些要读得出来，但不能把车身轮廓淹没——轮廓永远先是“一条圆润的鲸鱼”。
- 风格：按 `STYLE.md` 的赛璐璐 + 描线。用 `kit.ts` 的 `vehicleMaterials()`：外壳用 `body`（`flat + ink + spec`），车内一切用 `cabin`（`flat + ink + cabin`）。颜色只用少数几个调好的色，暗部交给着色器，不要自己画“阴影色块”。圆角用倒角的斜面（一两段），不追求曲面。

外观尺寸集中写在 `rv.ts` 顶部的一个 `const DIM = { … }` 表里（长、宽、各高度、窗位、门位、玻璃角点），后面的建模代码只引用它。

## 3. 驾驶室与通道（自己设计，要和外观自洽）

- 起居室地板离地 0.80；驾驶室两个座位各自落在比它低 0.18 的脚坑里（离地 0.62），这样座垫高 1.07、坐姿眼高正好是 1.85。
- **两座之间是发动机盖形成的一条“中脊”，顶面与起居室地板齐平（0.80）、宽约 0.45**：它就是驾驶室与起居室之间的通道——从起居室一路平着走到仪表台前，坐下时向侧下方迈进脚坑。中脊上可以有一个检修盖的缝和一只固定的保温壶托。
- 仪表台：很深的一块平台（x ≈ 2.45–3.20，顶面离地约 1.30，车身漆色或木色），上面是生活痕迹：一盆小植物、摊开的地图、**小收音机**（`props.ts` 里的 `radioBuddy`，方向朝司机，放在司机右前方）、一只摇头小摆件。
- 方向盘：直径 44 cm，公交车式大而平——轴线与水平面夹角约 60–65°，两辐（`spokes: 'bus'`），从眼位看盘的远侧上沿出现在画面下部；仪表（`buildCluster`）在盘的远侧上方、不被盘圈挡住表心。
- 司机正前方的视野：眼位向前、向下 20° 以内不能有任何实体挡住路面（除了方向盘圈和仪表小罩）；向上能看到至少 20° 的天空。
- 左右后视镜（长条货车镜，立在车头两侧）、车内中央后视镜、挂件（`buildCharm`，挂在中央镜下）、遮阳板。
- 雨刷：两支，铰点在玻璃下沿（`buildScreen`）。
- 两个前座是带扶手的独立座椅；副驾座可以原地转 180° 朝向起居室（做成一个 mover，见 5）。

## 4. 起居室布局与槽位

内宽约 2.08（z ∈ [−1.04, 1.04]），内高 1.98（地板 0.80 → 天花 2.78），起居室 x ∈ [−3.15, 1.45]。过道沿中线偏左，最窄处 ≥ 0.55 m。

默认状态：`storage`、`stove`、`water`、`bunks`、`map` 已装，其余为空（展示两种状态）；URL 参数 `slots=all|none|default` 可切换。

为了省 draw call：所有槽位的可见几何**合并成一个网格**（槽位状态很少变，变了就重新合并一次），不要每个槽位一个网格。

座位与机位（`VehicleParts.views`，`seat: true` 是能坐的位置）：`passenger`、`dinette1…4`、`sofa`、`bunkLow`、`bunkHigh`（躺姿，看后窗）、`deck1`、`deck2`（车顶躺椅）；
拍照用机位（`seat: false`）：`roomFront`（站在 x≈1.0 朝后看整个车厢）、`roomRear`（站在 x≈−2.3 朝前看到驾驶室和挡风玻璃外的路）、`galley`、`overDash`（从中脊上方越过仪表台看路）。
车内可行走区（`VehicleParts.walk`）：若干矩形的并集，包含主过道、门内平台、通向驾驶室的中脊、车尾沙发前。净高 1.98。

## 5. 会动的部件（`VehicleParts.movers`，每个 `set(t)`，t = 0 关 … 1 开）

- `door`：右侧入口门向外开 100°；
- `awning`：右侧遮阳棚从卷筒展开成一块斜布 + 两根撑杆（宽约 3.2、伸出 2.2）；
- `passengerSeat`：副驾座转向车内；
- `curtain`：驾驶室与起居室之间的布帘（拉上后夜里车厢的光不照进驾驶室）。

“开营”状态（URL `camp=1`，或游戏里停车后按键）= door、awning 打开。

## 7. 自动验收（门禁）

Vitest（Node，无浏览器）`harness/sim/vehicle-models.test.ts`，对注册表里每一辆已建模的车：

1. 能在 Node 里构建（无 `document`）；`VehicleParts` 的必填字段齐全。
2. 包围盒：外壳 x、z 范围与本规格第 2 节的尺寸相差 ≤ 0.15 m；房车外壳顶高 2.80–2.95 m（不含车顶件）；与碰撞盒两端的差 ≤ 0.5 m。
3. 轮拱：四个车轮在静止位置的包围圆柱（半径 +2 cm、宽 +2 cm）内没有外壳或车内几何的三角形顶点。
4. 眼位：从司机眼位向前半球 9 个方向（正前、上下左右各 10° 与 20°）发射线，命中的第一个东西要么是挡风玻璃、要么距离 > 0.45 m；向正前、向下 5°–20° 的射线穿过玻璃之前不命中车身（方向盘、仪表、雨刷除外）。眼位六个轴向 0.12 m 内没有实体。
5. 每个 `seat: true` 的机位：头部（眼位周围半径 0.11 m 的球）不与任何几何相交；向它的默认朝向 0.3 m 内没有实体。
6. 行走区：每个矩形内每隔 0.15 m 取点，从地板以上 0.05 m 到 1.90 m 的竖直线段不与车内几何相交（门内平台与中脊按各自的地板高算）；各矩形连通；过道最窄处 ≥ 0.55 m。
7. 槽位：id 与本规格第 4 节一致；每个槽位的空位与已装几何都非空，包围盒在车身之内（车顶与车尾槽位除外）。
8. 预算：整车三角形 ≤ 90 000；网格数（draw call 上界，含四个车轮）≤ 32。
9. 小货车：三角形数与改动前相同（记录在测试里的常数）。

渲染门禁 `specs/render/vehicles.json`：截图失败 0、控制台报错 0、试车场镜头 draw call ≤ 110、三角形 ≤ 150 000（世界镜头沿用世界组的预算，单列）。
`npm run check && npm run measure && npm test && npm run judge` 全绿；`driving` 截图组全绿。

## 8. 评审标准（独立评审按这几条打分，1–5）

1. **轮廓**：远看一眼认得出是“一辆圆润的老房车”，与小货车是一家人（漆色、描线、车灯的画法）。
2. **比例与结构自洽**：轮子在轮拱里、门够人进、窗与车内家具对得上（窗外看到的是那一侧该有的东西）、车顶件不悬空、梯子通到露台。
3. **驾驶位**：大玻璃、深仪表台、大而平的方向盘；路面看得清；仪表读得出；像“高高坐着开一间屋子”。
4. **车厢是一个想待着的家**：有层次（地毯、木台面、布帘、灯）、有生活痕迹、色彩温暖不脏；空位木框一眼看得出“这里将来有东西”。
5. **通道与动线**：从驾驶座回头能看到整个车厢；从车厢向前能看到路；过道走得通。
6. **剖面图**：剖开后像一张讲得清布局的剖面插画。
7. **风格**：赛璐璐色块 + 暗暖描线，没有脏的渐变、没有 z-fighting 闪烁、没有悬空或穿插的零件、没有纯黑或荧光色。
8. **夜晚**：车内灯亮起后是暖的、看得清、不过曝；从外面看窗是亮的。

合格线：各项 ≥ 3，均分 ≥ 3.5。
