# 面包车「面包」(T1) 与越野车「山羊」(T2) 模型规格 v1

状态：2026-11-14 立项。写法照 `specs/vehicles/rv_model.md`：外观尺寸集中在各自文件顶部的 `DIM` 表（`src/game/vehicle/van.ts`、`offroad.ts`），建模代码只引用它。
相关文档：`docs/DESIGN_V2.md` 第 5 章（5.1 车系、5.2 下表“不在物理里的设定”、5.4 槽位与各车布局、5.7 车上的位置）、`specs/art/STYLE.md` 2.3 与 4 节。

## 0. 不能动的东西

- 底盘已定案：`src/core/vehicle/spec.ts` 的 `T1_VAN`、`T2_OFFROAD`、`sim.ts`、`specs/driving/` 都不改，模型适应底盘。
- 房车和小货车的画面不变（`rv_*`、`truck_*` 截图 draw call 与三角形数不变，`harness/shots/pixdiff.py` 对照改动前的渲染）。
- 原创外观：不画任何真实品牌的车标、格栅或标志性图形；两车不是任何量产车的复刻。
- 程序化建模（`ModelBuilder` 拼色块），赛璐璐 + 暖暗描线，外壳用 `body`，车内用 `cabin` 材质。

车身坐标：+x 向前，+y 向上，+z 向右，原点在重心；离地高 h 换算 y = h − 重心高。

## 2. T2 越野车「山羊」——短而方的四驱，别人去不了的地方它能去

底盘：轴距 2.50（前轴 x = +1.175，后轴 −1.325），轮距 1.46 / 1.44，轮半径 0.37（块状胎 `knobs`），重心 0.74，司机眼位 (0.25, 0.68, −0.36) = 离地 1.42，碰撞盒 x ∈ [−2.1, 2.1]、半宽 0.86、离地 0.28–1.84。

| 项 | 值 |
| --- | --- |
| 车身 | x −1.98 … +1.98，保险杠到 −2.04 / +2.10（绞盘保险杠）；半宽 0.84（外扩的轮眉到 0.92）；车身下沿 0.50；腰线 1.18；平顶 1.84 |
| 形体 | 平引擎盖（h 1.14–1.16，x 0.96–1.96），直立略后倾的挡风玻璃（下沿 (0.94, 1.14)、上沿 (0.84, 1.74)）；方盒车身，小圆角；短前后悬，高离地 |
| 涂装 | 褪色砖红 `#a5553f`，奶油车顶 `#ece2c8`，深灰轮眉、保险杠、门槛 |
| 车上 | 前保险杠 + 绞盘槽位；侧铰尾门上挂备胎；右侧 A 柱的通气管；左后侧油桶架；车顶行李架、车顶帐（两个车顶槽位） |
| 门窗 | 两扇前门（只画缝，x −0.12 … 0.86）；后侧大窗 x −1.78 … −0.30；尾门窗 |

**驾驶室**（5.2：直立坐姿，方正的引擎盖摆在眼前）：方向盘 38 cm、粗圈、Y 形三辐（`spokes: 'Y'`）；仪表在司机正前方的小罩里；仪表台中间一只机械倾角仪；换挡杆旁一根分动箱拉杆；副驾前方仪表台上一根扶手；后视镜下挂一只小铜铃（`charm`）。

**车厢**（全车系最挤）：四座——`passenger`、`rearLeft`、`rearRight`（后排略高）；后排座椅之后是货舱（x −1.90 … −1.10，地板 0.60）：

| 位置 | 内容 | 槽位 id（kind） |
| --- | --- | --- |
| 货舱底层，全宽 | 抽屉厨房：一只长抽屉，拉出来伸出尾门 0.9 m，上面是双头炉、砧板、调料 | `kitchen` (stove) |
| 货舱上层右 | 冷藏箱 | `cooler` (cooler) |
| 货舱上层左 | 箱子与网兜 | `storage` (storage) |
| 车顶前 | 平台式行李架 + 沙板 | `roofRack` (roof) |
| 车顶后 | 车顶帐：收起是一只硬盒，展开向右翻出成一间帐篷，配一架梯子 | `roofTent` (roof) |
| 前保险杠 | 绞盘（卷筒、钢缆、钩子） | `winch` (winch) |

默认已装：`storage`、`kitchen`、`roofRack`。床就是车顶帐。拍照机位：`room`（从副驾回头看车厢与货舱）、`tailgate`（站在车尾看拉出的抽屉厨房）；座位 `tent`（躺在展开的车顶帐里向外看；`needs: roofTent`，`open: ['tent']`）。

**会动的部件**：`rearDoor`（侧铰尾门向右外开 100°，备胎随门）、`drawer`（抽屉厨房拉出 0.9 m，装了才有）、`tent`（车顶帐展开，装了才有）、`bonnet`（引擎盖以挡风玻璃下沿为轴掀起 55°，露出发动机舱）。开营 = 尾门 + 抽屉 + 帐篷。

## 3. 两车共同的做法

- 每个外观尺寸都在 `DIM` 表；墙上有真开口的窗；外壳与车内都投影；车内用 `cabin` 材质和顶灯（`lamps`）。
- 剖面：右侧外壁、右侧玻璃、车顶及车顶件在 `cut` 组（`cutaway=1` 隐藏），剖开后看得懂布局。
- 省 draw call：会动的部件不单独成网格，而是作为“摆放件”合并在所属网格里（`kit.ts` 的 `PoseMesh`：外壳、车内、玻璃各一个），动件变化时重新合并；随动的槽位件（抽屉、帐篷、铺开的被子）进 `SlotMesh` 的 `moving` 列表。
- 槽位两种状态都建（空位木框 + 图纸卡片 / 设施本身），全部槽位合成一个网格。

## 5. 自动验收（`harness/sim/vehicle-models.test.ts`，按车各自的数字）

1. Node 里能构建；必填部件齐全。
2. 外壳包围盒与第 1/2 节尺寸差 ≤ 0.15 m，与碰撞盒两端差 ≤ 0.5 m；顶高：面包 1.90–2.00、山羊 1.80–1.90。
3. 轮拱：静止车轮的包围圆柱（半径 +2 cm、宽 +2 cm）内没有外壳或车内顶点。
4. 眼位视线（同房车规格 §7.4）：九个方向首先遇到挡风玻璃或远于 0.45 m；正前与向下 5–20° 先穿过玻璃（方向盘、仪表、雨刷除外）；向上 20° 是玻璃；眼位六向 0.12 m 内无实体。
5. 每个座位头部（半径 0.11 m）不碰几何、正前 0.3 m 内无实体（座位要求的槽位与动件就位后检查）。
6. 不走动：没有 `walk`。
7. 槽位 id/kind 与第 1/2 节一致；两种状态都非空；车内槽位在车内（车顶、绞盘除外）；默认已装如上。
8. 预算：每车网格 ≤ 28（含四轮），三角形 ≤ 60 000（全部槽位装上）。
9. 动件名与开营列表如上；每个动件打开时确有几何移动，关上后完全复原。

渲染门禁沿用 `specs/render/vehicles*.json`（试车场 draw call ≤ 110、三角形 ≤ 150 000；世界组沿用世界预算）。

## 6. 评审标准（1–5，合格：各项 ≥ 3，均分 ≥ 3.5）

1. **轮廓**：一眼认出“圆润的小面包车”和“方正的小越野车”，与小货车、房车是一家人（漆色、描线、车灯画法）。
2. **比例与结构**：轮子在轮拱里，门够人进，窗外看到的是那一侧该有的东西，车顶件不悬空。
3. **驾驶位**：面包——坐在轮子上、大而平的盘、路就在脚下；山羊——直立、引擎盖方正地摆在眼前、粗盘、倾角仪。路面看得清，仪表读得出。
4. **车厢**：面包是一间想待着的小屋（床、灶、窗帘、灯）；山羊挤而整齐，货舱一眼看懂。
5. **剖面**：剖开后讲得清布局。
6. **风格**：赛璐璐色块 + 暗暖描线，无 z-fighting、悬空或穿插，无死黑。
7. **夜晚**：车内暖光、读得出、不过曝；开营的车从外面看是亮的、有人气的。
