## 从图里读到的东西（建模依据）

- **车型**：C 型房车——带短斜引擎盖和大倾角挡风玻璃的厢式车驾驶室，后面是比驾驶室更高、略宽的方盒车厢，车厢向前探出一截“额头卧铺”压在挡风玻璃上方，额头两角是切角面。前轮在 A 柱根部下方，驾驶门在轮拱之后；后悬很长。
- **涂装**：车身暖奶油色，额头与车顶是更浅的暖白；侧面通长两条色带（上棕下橙），车厢上沿一条细橙线；车顶边缘垂着几道浅色密封胶“冰凌”。
- **末日改装**：窗上钉着木板（驾驶门窗、车厢侧窗、额头侧面）；挡风玻璃外罩一张钢筋焊的护网；额头右前切角上钉着一块 STOP 牌；引擎盖右后角一根鞭状天线；车头保险杠上缠着铁丝网、绑着五根削尖的木桩。
- **车顶**：前部一口带底座的大卫星锅（馈源杆顶端是红色），中部天窗盒，后部一块斜支的太阳能板，旁边是盖着篷布的圆筒探照灯。
- **车尾与侧面**：左后挂着带花体字的备胎罩，两块木板拼的后保险杠、车牌和拖钩，竖长圆角尾灯；右侧入口门铰链在后沿、向外开，门内挂着灭火器，门下有折叠踏板，靠后有一个低位检修口。
- **剖面里的内饰**（只作灵感，我们的内饰自己设计）：车尾是卫生间，中段是抽屉柜、微波炉、摊着地图的小桌和圆凳，驾驶室两把座椅，额头上是铺着枕头的卧铺，沿车顶一侧有一条长搁板。

## 我们怎么用

- 任务书已下发给车模线（Opus 子代理）：把 `src/game/vehicle/rv.ts` 从暂定的“圆润平头房车”改成这辆 C 型房车的正式版；手感数值不动，只允许改 `T3_RV.eye` 与 `T3_RV.body` 两项去适应新的驾驶室与车壳。
- 截图组 `vehicles` 增加三张与参考图同机位的对照（`rv_ref_front34`、`rv_ref_cutaway`、`rv_ref_model`），`harness/shots/compare_rv.py` 把它们与参考图并排输出到 `loop/shots/_compare/`（该目录不入库）。
- 与游戏基调的两处取舍：① 挡风玻璃护网做成可以支起来的活动件——开车时支起，停车和下冰雹时放下；② 车头的铁丝网和尖木桩单独成组、可以一键关掉——这个世界没有敌人，是否保留由用户决定。封窗木板在每扇窗上至少留出六成玻璃，不挡后视镜。
