## 从图里读到的东西（风格依据）

- **题材**：被植物收回的工业设施——奶油白的混凝土墙与扶壁，墙上挂着成排的青绿色管道和设备箱，藤蔓从墙头垂下来，树冠探过墙。
- **颜色**：四个主色——奶油白（墙）、青绿（漆过的金属）、黄绿（叶）、天蓝；点缀是边角的铁锈橙和褪色的黄色模板字。没有纯黑，暗部是偏蓝的冷灰。
- **笔触**：大面是平涂，上面压着看得出走向的宽笔触和磨损；金属件的棱边掉漆露出浅色，接缝和螺栓处有锈水往下流；混凝土的边角缺损处露出暖色。
- **光**：高处来的强日光，硬边投影，影子里带天光的蓝；叶片透光发亮。
- **图形**：墙上的编号（A-02）、设备名和斜纹警示带都是褪色的浅色油漆，不抢画面。

## 我们怎么用

- `harness/judge/style_compare.py` 的风格统计已经把它纳入对标平均值（门禁里与 Painted Valley 的几张对标图一起算）。
